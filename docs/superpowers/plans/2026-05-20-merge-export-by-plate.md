# 按车牌合并导出方案

> 日期：2026-05-20
> 状态：已确认

## 需求

导出 Excel 时可选择按车牌合并，同车牌的多条保单（交强险/商业险/非车险）合并为一行，保费、保单号等差异字段按险种拆分为独立列，用户可自由配置显示哪些列。

## 险种分类

基于现有 `_get_policy_type_code()` 的分类：
- `compulsory`（交强险）→ 前缀「交强险」
- `commercial`（商业险）→ 前缀「商业险」
- `accident` + `non_vehicle`（驾乘险/非车险）→ 前缀「非车险」

## 字段拆分规则

### 共享字段（不拆分，多条记录互相补充）
- 承保公司、车牌、投保人、被保人、业务员、跟单人、出单渠道

### 差异字段（按险种拆分为 3 列）
| 原字段 | 商业险 | 交强险 | 非车险 |
|---|---|---|---|
| 保单号 | 商业险保单号 | 交强险保单号 | 非车险保单号 |
| 保费 | 商业险保费 | 交强险保费 | 非车险保费 |
| 签单日期 | 商业险签单日期 | 交强险签单日期 | 非车险签单日期 |
| 起保日期 | 商业险起保日期 | 交强险起保日期 | 非车险起保日期 |
| 终保日期 | 商业险终保日期 | 交强险终保日期 | 非车险终保日期 |
| 佣金率 | 商业险佣金率 | 交强险佣金率 | 非车险佣金率 |
| 佣金 | 商业险佣金 | 交强险佣金 | 非车险佣金 |
| 采购费率 | 商业险采购费率 | 交强险采购费率 | 非车险采购费率 |
| 公司利润 | 商业险公司利润 | 交强险公司利润 | 非车险公司利润 |
| 跟单人利润 | 商业险跟单人利润 | 交强险跟单人利润 | 非车险跟单人利润 |

### 特殊字段
- 车船税：不拆分，单独一列（只有交强险有）
- 险种：合并后不保留（已通过列名前缀区分）

## 开关机制

### 系统设置页（默认值）
- 在「导出列配置」tab 顶部新增「按车牌合并导出」开关
- 开启时，自动往 `export_columns` 的列配置中补充上述差异字段（如不存在）
- 用户可自行调整这些字段的顺序、可见性、名称

### 导出弹窗（临时切换）
- 导出弹窗中显示「按车牌合并」开关，继承设置页的默认值
- 用户可临时开启或关闭，不影响设置页的默认值

## 合并逻辑（导出时）

```
1. 按车牌号分组
2. 每组内，按险种分类（compulsory/commercial/accident+non_vehicle）
3. 共享字段：遍历组内记录互相补充（A 没有的取 B 的）
4. 差异字段：按险种前缀填入对应列
5. 按用户的 export_columns 列配置输出
```

## 数据存储

复用 `user_field_config` 表：
- `config_type = 'export_columns'`，`config_key = 'merge_by_plate'`，`config_value = '1'` 或 `'0'`
- 列配置仍使用 `config_key = 'columns'`，差异字段作为普通字段项存在其中

## 合并差异字段常量定义

```python
# 差异字段（需按险种拆分的原始字段）
MERGE_SPLIT_FIELDS = ["保单号", "保费", "签单日期", "起保日期", "终保日期",
                       "佣金率", "佣金", "采购费率", "公司利润", "跟单人利润"]

# 险种前缀
MERGE_PREFIXES = ["商业险", "交强险", "非车险"]

# 自动生成的差异列：商业险保单号, 交强险保单号, 非车险保单号, 商业险保费, ...
MERGE_EXTRA_COLUMNS = [f"{prefix}{field}" for field in MERGE_SPLIT_FIELDS for prefix in MERGE_PREFIXES]
```
