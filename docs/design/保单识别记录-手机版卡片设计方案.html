🎯 卡片结构（收起 → 展开）

  • 头部：车牌号（无车牌降级显示被保险人/文件名）+ 险种标签 + 文档类型 + 状态徽标
  • 提示条（按需）：多保单合并 / 缺失字段警告 / 已标记正常原因 / 失败原因
  • 核心摘要（默认可见）：被保人、承保公司、保费、终保日期（2×2 网格）
  • 展开全部字段：按「文件 / 保单信息 / 人员 / 车辆 / 日期金额 / 来源」分组展示桌面列表的全部列；跟随用户「页面列配置」，勾选哪列显示哪个字段，空值显示 —
  • 底部：时间·来源（一行）+ 状态差异化主操作 +「⋯」更多菜单

📱 页面级交互

  • 顶部搜索 + 筛选抽屉（保司/险种/日期范围，复用桌面高级搜索参数）
  • 状态 Tab 横向滑动：全部 / 成功 / 需人工补充 / 非保单 / 失败
  • 卡片流触底自动加载下一页（替代分页器）
  • 右下角悬浮「+」手动上传保单
  • 长按卡片进入多选模式 → 底部批量操作栏（批量导出 Excel / 批量导出保单 / 批量重新识别）
  • 展开态中点击字段值可编辑（复用现有行内编辑逻辑），日期字段调起日期选择器

🛠 实现方式（确认后执行）

  • 在现有 insurance.html 内实现，不新建页面：<768px 媒体查询隐藏表格、显示卡片流，共用同一份 Vue 数据（records、visibleListColumns、recordTabs、筛选条件），无需后端改动
  • 展开区字段遍历 visibleListColumns 渲染，按预设「字段→分组」映射归类；未归类的新字段自动落入「其他」分组，避免遗漏
  • 展开状态记录在每条 record 的临时属性（如 _mExpanded），切页/刷新后默认收起
  • 超管专属字段（所属企业、识别方式、置信度、内部备注）按角色渲染在对应分组
