# 比例规则（按条件取值）功能

**时间**：2026-07-18 23:21
**方案**：docs/review/公式条件取值方案.html（已确认实施）

## 需求说明

客户（文十七科技-TZ014 群）：前海保司交强险费用比例取决于是否带驾乘险出单——带驾乘险 22%、驾乘险 30%，不带驾乘险 20%。需要做成前端随时可配置的通用能力。

**设计定位**：只设置比例，计算仍走现有普通公式。新增「比例规则」层，按条件算出比例字段的值（如「应付费率」= 0.22），普通公式（`应付费用 = 保费 × 应付费率`）照常引用，公式引擎零改动。

## 功能内容

1. **比例规则**：新配置类型 `ratio_rule`，key 格式 `比例字段:保司:险种`（与公式一致），支持：
   - 固定比例：`{"value": 0.30}`
   - 条件分支：`{"branches": [{"conditions": [...], "value": 0.22, "note": "带驾乘险出单"}], "default": 0.20}`
2. **条件类型**：
   - 字段条件（type=field）：本单任意字段比较，10 种操作符（等于/不等于/包含/不包含/大于/大于等于/小于/小于等于/为空/不为空）
   - 关联单条件（type=related）：同车牌/车架号/投保人在前后 N 天内（默认 7 天）是否存在某险种的其他保单（覆盖"带驾乘险出单"场景），批量预取防 N+1，自动排除自身记录
3. **前端「比例规则」页签**（模板配置页）：规则总览（搜索/按保司筛选/编辑/删除）、规则编辑器（固定比例/条件分支切换、分支排序）、批量导入（粘贴 5 列表格：比例字段,保司,险种,条件,比例；支持 22% 和 0.22 写法；同 key 自动合并分支、重复覆盖）
4. **生效时机**：与公式一致（列表/详情/导出实时计算，不落库）。驾乘险后入库时，交强险的比例在下一次查询/导出自动更新
5. **百分比显示**：注入的比例字段名含"率/比例"时自动转百分比显示（22%）

## 数据库变更

**无表结构变更**。比例规则存现有 `user_field_config` 表（config_type='ratio_rule'），跟随模板与 global/enterprise/user 三级作用域，无迁移。

## 兼容与防护（重点）

- **所有新逻辑全部 try/except 包裹**：单条条件、单条规则、整体应用、ctx 预取各层独立兜底，任何异常只跳过比例注入，别名/日期/公式等现有流程不受影响
- 未配置比例规则的用户：`config_has_related_ratio_rules` 返回空集、apply_ratio_rules 直接返回，零开销零变化
- 手动修改过的比例字段不被规则覆盖（沿用 _manual_fields 机制）
- 规则未命中时比例字段留空，公式按缺字段 0 处理（与现有行为一致）
- 老版本前端不发送 ratio_rule → 保存时不动已有比例规则（save_full_template 只保存传入的 config_type）
- 关联单条件 ctx 缺失/异常时按「不存在」处理，不阻塞渲染

## 测试

纯函数级 sanity 测试 30 项全部通过（scratchpad/test_ratio_rules.py）：
- 端到端：前海交强险带驾乘险 950×22%=209、不带 980×20%=196、费率显示 22%/20%
- 关联条件：存在/排除自身/超时间窗/无车牌/ctx 缺失
- 回归：无 ratio_rule 配置时老公式行为不变；坏配置（非 dict value、空 key、非法比例）不影响公式计算
- 手动修改的费率不被覆盖

## 使用说明（前海案例）

1. 导出列配置：添加自定义列「应付费率」「应付费用」
2. 自动计算公式：`应付费用 = 保费 × 应付费率`（保司/险种选全部，配一次即可）
3. 比例规则页签，批量导入粘贴：
   ```
   应付费率	前海	交强险	带驾乘险	22%
   应付费率	前海	交强险	默认	20%
   应付费率	前海	驾乘险		30%
   ```
4. 保存模板即生效；后续调整比例直接在总览里改
