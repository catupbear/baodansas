# 2026-07-18 10:45 更新记录 — 群内补充关键词可配置 + 全局跳过关键词黑名单

## 需求说明

1. **群内补充关键词可配置**：群成员发「车牌 + 关键词：值」文本按车牌回填保单字段的功能，原先关键词规则写死在代码里（`_FIELD_PATTERNS`），每加一个关键词需改代码发版。现改为在「字段配置 → 群内补充」标签页可视化配置：
   - 指定「关键词 → 目标字段」映射，目标字段可选系统识别字段或自定义列（选中识别字段时提示会覆盖识别值）
   - 同一字段可配多个关键词（别名），值类型支持 文本/数字/手机号/百分比
   - 配置后「一键复制发送格式」（车牌行留空、每行取第一个关键词），发群里让成员照填
2. **全局跳过关键词黑名单**：内部管理员在「监控配置管理」页维护，群消息文本包含任一关键词时跳过全部关键词触发链路（保险报价/政策回填/台账导出），仅正常存档，全局对所有企业生效。
3. **缺项/空值不处理**：成员发送时缺哪个关键词、或带了关键词没填值（含同行粘连下一个关键词），对应字段不写、不清空、不覆盖原值。

## 核心设计：双轨制（不影响线上客户）

- 写死逻辑 `_FIELD_PATTERNS` / `parse_policy_quote_text` **一行未改**；新引擎只在「企业显式保存过规则」时接管，未配置企业执行路径与升级前完全相同
- `fetcher.py:383` 的「群公告」硬编码过滤原样保留，黑名单在其后叠加（默认空数组 = 零行为变化）
- 前端未配置企业不展示任何默认规则（留空，客户按需自行添加），点「保存规则」后该企业才切换新引擎
- 群消息回填按**企业**生效：运行时只读企业管理员（scope=enterprise）保存的规则，员工个人保存不参与（前端有提示）
