# 监控页群聊发送消息（FlowBot 通道）

> 2026-07-19 13:00

## 需求说明

在 `https://wxbot.wuhuxiche.com/monitor/chat` 消息监控页的聊天区底部增加发送消息功能：

- 通过 FlowBot 机器人向群聊发送文字消息（复用台账告警机器人，须已在目标群内）
- **参考微信体验**：点击发送后消息先乐观上屏（右侧绿色气泡），旁边转圈等待确认
- FlowBot `sendTask` 返回 200 仅代表"指令已接收"，**真实送达以回调（mode=callBack）为准**：
  - 回调 success → 转圈消失，视为发送成功
  - 回调 fail / 60 秒无回调 → 显示红色 ❗ + 「重发」按钮，点击手动重发（不自动重试）
- 仅群聊会话显示输入栏（FlowBot 按群名称定位群，不支持私聊）
- 刷新页面后发送记录不丢失（合并最近 7 天记录进聊天时间线，带「机器人」角标）；会话存档拉到同文本消息后自动隐藏，避免重复显示

## 数据库变更

`flowbot_push_log` 表新增 2 列（启动时自动迁移，幂等）：

| 列 | 类型 | 说明 |
|----|------|------|
| `source` | VARCHAR(16) DEFAULT 'notify' | 来源：`notify`=群通知（失败自动重发3次）/ `monitor`=监控页手动发送（失败等用户手动重发） |
| `roomid` | VARCHAR(128) DEFAULT '' | 目标群 roomid（供聊天记录合并显示） |

新增索引 `idx_fbl_room (roomid, created_at)`。

## 代码变更

| 文件 | 变更 |
|------|------|
| `insurance/db.py` | `flowbot_push_log` 建表 DDL 增加 source/roomid 列 + 旧表幂等 ALTER 迁移 |

| `insurance/flowbot_callback.py` | `_handle_task_result` 按 source 分流：monitor 来源**首次失败自动兜底一次**（直连企微 API 强制刷新最新群名 → 回写 wecom_groups → 用新群名重发）；兜底后仍失败只标记 status=2 等手动重发，不钉钉告警。新增 `register_flowbot_contacts()` 注册通讯录管理器 |
| `main.py` | 启动时把主企业+额外企业的 ContactsManager 注册到 FlowBot 回调（群名刷新兜底用） |
| `web/api.py` | 新增 4 个接口（见下） |
| `web/templates/index.html` | 底部输入栏（Enter 发送 / Shift+Enter 换行）、右侧绿色气泡乐观上屏、2 秒状态轮询、失败重发按钮、60 秒超时兜底、发送记录合并时间线 + 同文本去重；文件消息（含 PDF）取消内嵌预览，统一小卡片展示（文件名+大小+下载按钮），点击卡片新窗口预览 |

### 新增 API（均需 JWT 登录）

| 接口 | 说明 |
|------|------|
| `GET /api/monitor/send/config` | 发送功能可用性（机器人未配置时前端隐藏输入栏显示提示） |
| `POST /api/monitor/send` | 发送消息 `{roomid, message}`，返回 `{log_id, task_id}`；2000 字上限。群名以 `wecom_groups` 统一群信息表为权威（前端显示名可能是手动改的备注，不用于发送；表中无记录时才退回前端传的 group_name） |
| `GET /api/monitor/sends?roomid=` / `?ids=` | 查发送记录（roomid=最近7天合并显示；ids=批量查状态供轮询） |
| `POST /api/monitor/send/retry` | 手动重发 `{log_id}`，原 payload 重新提交，状态回到推送中；重发前按 roomid 从 `wecom_groups` 刷新最新群名（首发失败可能就是群名变了） |

## 部署步骤

1. 上传以下文件到服务器 `/home/wxbot/` 对应路径（gunicorn --reload 自动生效）：
   - `insurance/db.py`
   - `insurance/flowbot_notify.py`
   - `insurance/flowbot_callback.py`
   - `web/api.py`
   - `web/templates/index.html`
   - `main.py`
2. 数据库列迁移在进程重载后首次建表初始化时自动执行（幂等，无需手动 SQL）
   - 若未触发 init，可手动执行：
     ```sql
     ALTER TABLE flowbot_push_log ADD COLUMN source VARCHAR(16) NOT NULL DEFAULT 'notify' COMMENT '来源: notify=群通知(失败自动重发) monitor=监控页手动发送(失败手动重发)' AFTER robot_id;
     ALTER TABLE flowbot_push_log ADD COLUMN roomid VARCHAR(128) NOT NULL DEFAULT '' COMMENT '目标群roomid（监控页发送时记录，供聊天记录合并显示）' AFTER source;
     CREATE INDEX idx_fbl_room ON flowbot_push_log(roomid, created_at);
     ```
3. 前置条件确认：
   - `insurance_config` 中 `flowbot_fail_notify.robot_id` 已配置（复用台账告警机器人）
   - FlowBot 回调地址已注册到 `https://wxbot.wuhuxiche.com/flowbot/callback`
   - 机器人已加入需要发送消息的目标群

## 注意事项

- FlowBot 按「群名称」模糊定位群：发送用的群名取自 `wecom_groups` 权威表（task_group_sync 维护），与页面上手动改过的显示名无关；若群刚建还未同步、或群名与微信实际不符，会发送失败，失败原因显示在 ❗ 悬浮提示中
- 机器人发出的消息几分钟后会被会话存档拉取入库，前端已做 ±10 分钟同文本去重，短期内偶尔看到重复属正常
