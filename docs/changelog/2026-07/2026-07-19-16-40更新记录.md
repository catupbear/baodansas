# 群内补充信息「待匹配池」——延迟提醒 + 识别成功自动补录

> 2026-07-19 16:40

## 需求说明

客户在群里发补充信息（车牌 + 业务经理/业务专员/保险公司经办人等）时，同车牌保单可能还在识别队列中（PDF 识别较慢），系统按车牌命中 0 条就**立即**发「⚠️ 补充信息未录入」群提醒，造成误报。

本次改为：

1. 命中 0 条时不立即提醒，补充信息进入**待匹配池**（MySQL 持久化，重启不丢）
2. **延迟 10 分钟**（可配置）后仍未匹配才发「未录入」群提醒，**同时推一条钉钉通知**给技术客服
3. 保单识别成功时按 群+车牌 自动匹配池中条目，补充字段自动回填到系统台账记录（不涉及钉钉多维表同步——该功能已停用），条目移除
4. 若已发过「未录入」提醒后才匹配上 → 群里补发「✅ 补充信息已录入」通知闭环；10 分钟内静默匹配不打扰
5. 条目 48 小时（可配置）未匹配自动过期作废，避免车牌填错的脏数据长期滞留误匹配

设计文档：`docs/design/2026-07-19-群内补充待匹配池设计.md`

## 数据库变更

新表 `policy_fill_pending`（首次启动自动创建，无需手工执行 SQL）：

- 群 id/群名、发送人/发送人名、企业 id、归一化车牌、补充字段 JSON、原始文本
- 状态机：`pending`（待匹配）→ `notified`（已提醒仍待匹配）→ `matched` / `expired`
- `notify_at` / `expire_at` 提醒与过期时间点（DB NOW() 计算，多机时钟无关）
- 索引：`(roomid, plate, status)`、`(status, notify_at)`

## 代码变更

| 文件 | 变更 |
|------|------|
| `insurance/fill_pending.py` | **新增**：建表、入池（同群+同车牌+同发送人合并去重）、识别成功匹配回填（matched 后 10 分钟宽限期兼容多保单 PDF 交强+商业两条记录）、30 秒扫描线程（延迟提醒 + 过期作废，条件 UPDATE 抢占保证多 worker 不重复通知） |
| `core/notify.py` | 新增 `notify_fill_pending_miss`：「未录入」提醒同时推钉钉（复用系统告警机器人） |
| `core/fetcher.py` | 命中 0 条分支改为入池（入池时解析好群名/发送人名存库）；删除原立即提醒函数 `_notify_policy_fill_miss`（文案模板迁至 fill_pending.py，配置键不变） |
| `insurance/handler.py` | `_process` 与 `_copy_recognition_result`（秒传复制路径）在字段映射/钉钉同步之前调用池匹配回填 |
| `main.py` | 启动时建表并启动扫描线程 |

## 配置说明（沿用 `insurance_config` 表 `quote_fill_miss_notify` 键，无前端改动）

| 键 | 说明 | 默认 |
|----|------|------|
| `enabled` / `robot_id` / `tech_support_name` / `template` | 沿用现有（开关只控制提醒，不影响入池与自动回填） | — |
| `delay_minutes` | 新增：延迟提醒分钟数（0=立即） | 10 |
| `pool_expire_hours` | 新增：池子有效期小时数 | 48 |
| `template_matched` | 新增：补录成功文案（`{plate}` 占位） | 内置默认 |

## 测试

本机临时 MySQL 库端到端测试 22 项全部通过：入池/合并去重、静默回填、多保单宽限期、跨群隔离、延迟提醒（群+钉钉）、不重复提醒、补录成功通知、过期作废、开关关闭时仅回填不提醒。

## 部署步骤

1. 上传以下文件到服务器 `/home/wxbot/` 对应路径（gunicorn `--reload` 自动生效）：
   - `insurance/fill_pending.py`（新增）
   - `core/notify.py`
   - `core/fetcher.py`
   - `insurance/handler.py`
   - `main.py`
2. 无需手工建表（启动时自动创建 `policy_fill_pending`）
3. 无需改配置：`delay_minutes`/`pool_expire_hours` 缺省即 10 分钟 / 48 小时
4. 验证：群里发一条无对应保单的补充信息 → 立即不再提示 → 10 分钟后群提醒 + 钉钉通知；随后补发保单 → 识别成功后自动回填并群内提示「已录入」
