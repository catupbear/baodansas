# 2026-07-18 22:30 更新记录 — 导出记录审计功能（内部功能，仅超级管理员）

## 需求说明

记录系统所有客户的导出行为，方便内部复查：

- 覆盖全部 5 个导出入口：页面台账 Excel、企业经营报告、批量下载保单原文 ZIP、群内命令「发送台账」、续保任务导出
- 记录当时的完整导出参数（筛选条件、时间范围、字段模板、操作人、所属企业等）和数据条数
- 导出产物副本同步上传 COS 指定审计目录（`export_audit/{年月}/{企业ID}/`），随时回看当时导出的真实数据
- 仅超级管理员（super_admin）可见，客户侧无任何感知
- **核心约束：审计绝不阻断客户导出主流程** —— 所有埋点均 try/except 包裹；副本上传在后台单线程队列异步执行，主流程只做一次毫秒级 INSERT

方案文档：`docs/review/导出记录审计方案.html`（已按确认结论实现）

## 数据库变更

新表 `export_records`（首次启动自动建表，幂等，无需手工 SQL）：

| 字段 | 说明 |
|------|------|
| user_id / user_name | 操作人（姓名冗余存储，防删号后无法追溯） |
| enterprise_id / enterprise_name | 导出数据所属企业（名称冗余） |
| export_type | ledger_excel / enterprise_report / batch_zip / ledger_cmd / renewal |
| trigger_way | web=页面 / cmd=群命令 |
| params | 导出时的完整参数 JSON |
| row_count | 本次导出数据条数 |
| filename / file_size | 导出文件名 / 大小 |
| cos_key / cos_url | 审计副本 COS 路径 / 地址 |
| copy_status | 副本上传状态 pending/done/failed/none（ZIP 等无副本类型为 none） |
| status / error_message | success / failed + 失败原因（无权限被拒等失败尝试也记录） |
| roomid / trigger_text | 群命令场景：触发群 ID / 原始命令文本 |

索引：enterprise_id、export_type、created_at。

## 代码变更

| 文件 | 改动 |
|------|------|
| `insurance/export_audit.py` | **新增**：统一审计封装。`record_export()` 写库 + 后台单线程 ThreadPoolExecutor 异步上传副本并回写 copy_status；查询函数 `query_export_records()`（分页 + 汇总统计）、`get_export_record()`；建表 `init_export_records_table()` |
| `main.py` | 启动时 `init_export_audit(db, cos_storage)`；新增页面路由 `/admin/export-records` |
| `insurance/api.py` | 埋点 3 处：台账 Excel 导出（`export_excel`）、企业经营报告（`export_enterprise_report`）、批量下载 ZIP（`batch_download_start`，只记 record_ids 不存副本）；新增 2 个超管接口：`GET /api/insurance/export-records`（分页查询 + summary 统计，@admin_required）、`GET /api/insurance/export-records/<id>/download`（302 跳转 COS 副本，支持 ?token= 鉴权） |
| `core/fetcher.py` | 群命令台账埋点 3 处：成功（复用群推送已上传的 `ledger_exports/` COS 文件作副本，不重复上传）、暂无数据（row_count=0）、无权限被拒（status=failed） |
| `insurance/renewal_api.py` | 续保任务导出埋点 |
| `web/templates/export_records.html` | **新增**：导出记录审计页面（Vue3，仅超管；4 张统计卡片含累计导出条数提醒、筛选栏、彩色标签列表、参数详情弹窗、副本下载多状态、分页） |
| `web/templates/insurance.html` | 右上角管理按钮区（客户管理旁）新增「导出记录」入口按钮，仅超管可见（仅此一处改动） |

兼容性：不改任何现有接口签名与响应结构，历史前端版本、群命令流程完全不受影响。
