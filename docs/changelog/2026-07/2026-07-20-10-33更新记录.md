# 2026-07-20 10:33 更新记录

## 需求说明

1. 导出的 Excel 需按用户在列表页所选的排序（如签单日期/起保日期等时间字段 + 升/降序）输出；
2. 列表页默认排序由「创建日期降序」改为「签单日期升序」。

### 原有问题

- 导出时前端重新查询数据但未传 `sort_by`/`sort_order`，走服务端默认「创建时间降序」；
- 不合并导出前有一段"车与车按上传 id 倒序"的重排，覆盖了任何用户排序；
- 按车牌合并导出时后端强制按车牌排序（`merged_rows.sort(key=车牌)`），同样覆盖用户排序。

## 数据库变更

无（后端列表接口原本已支持 sign_date 等字段排序）。

## 代码变更

- `web/templates/insurance.html`
  1. `collectRecordsExportData()`：导出查询带上 `sort_by`/`sort_order`，由服务端按用户所选排序返回；
  2. 不合并导出的"同车分组"重排：车与车之间改为按已排序结果中首次出现的先后（原为按 id 倒序），车内仍保持 商业险→交强险→非车险；
  3. 默认排序改为 `sign_date` + `asc`（`recordFilter` 初始值与 `clearAllFilters()` 重置值）。
- `insurance/api.py`（导出接口合并模式）
  1. 记录 invoices 传入顺序 `_order`，合并行取组内首条的顺序；
  2. 合并行排序由「按车牌」改为「跟随传入顺序」，输出前清除 `_order` 临时键；页面合并视图（return_json）与导出 Excel 顺序一致。

## 兼容说明

- 旧前端不传 `sort_by` 时服务端仍默认创建时间降序，接口行为向后兼容；
- 合并导出顺序变化：原按车牌字典序，现跟随列表排序（默认签单日期升序）。
