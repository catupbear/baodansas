## 需求说明

内部超级管理员在保单预览弹窗中，需要能看到「实际 OCR / PDF 提取的识别结果」，与目前列表展示的数据做逐字段对比，方便快速验证识别是否正确、判断列表值是来自识别还是手动修改/互补数据。

## 功能说明

预览弹窗顶部新增「识别对比」按钮（仅内部超级管理员可见，且仅识别记录预览时显示，手动上传预览不显示）：

- 点击后右侧展开对比面板（与「列表信息 / 查看原文 / 提取规则」面板互斥）
- 后端对该记录缓存的原文（优先 PDF 提取原文，其次 OCR 原文，都没有时从 COS 下载重新提取）重新跑一遍 `policy_parser`，得到**纯识别结果**（不含手动修改、不含跨保单/同车牌互补、不含公式字段）
- 面板逐字段展示三列：字段名｜列表值（当前展示值）｜提取值（纯识别值），并给出状态：
  - 红色高亮 = 两边不一致（重点核查）
  - 「未提取」灰色 = 提取值为空，说明列表值来自互补数据/手动填写/公式计算
  - 橙色圆点 = 该字段被手动修改过（沿用列表信息面板的标记）
- 顶部汇总「N 处差异 / 完全一致 ✓」，并标注原文来源（PDF原文/OCR原文），支持手动刷新
- 多保单 PDF：按保单号优先匹配当前记录对应的保单，匹配不到时按 policy_index 兜底，面板底部提示匹配方式
- 切换兄弟保单、重新识别后自动清空对比缓存（面板开着时切换会立即按新记录重新解析）
