# 识别记录列表手机版卡片视图 更新记录

**时间**：2026-07-16 18:55
**模块**：保单识别前端（/insurance 识别记录页）

## 需求说明

识别记录列表在手机上使用表格横向滚动，体验差。本次为 `<768px` 视口新增**卡片流视图**（设计方案：分组卡·默认收起，设计稿见 `docs/design/保单识别记录-手机版卡片设计方案.html`）：

- **卡片头部**：车牌号为主标题（无车牌降级显示被保人/文件名）+ 险种标签 + 文档类型 + 状态徽标 + 勾选框（批量操作用）
- **提示条**：同车牌合并、多保单、失败原因、需人工补充缺失字段、已标记正常原因
- **核心摘要**（默认可见）：被保人 / 承保公司 / 保费 / 终保日期（2×2 网格）
- **展开全部字段**：按「文件 / 保单信息 / 人员 / 车辆 / 日期与金额 / 来源」分组展示全部列
- **底部操作**：时间·来源 + 状态差异化主操作（成功→预览、需人工补充→标记正常、失败→重新识别/重新上传）+「⋯」底部弹出菜单（预览/重新识别/标记正常/撤销/报错/内部备注/删除）
- **页面级**：顶部快捷搜索（车牌）+「筛选」开关（复用原筛选卡，移动端默认收起）；滚动触底自动加载下一页（追加模式）；行内编辑复用桌面逻辑（点字段值即改）

**关键约束**：卡片字段**不写死**，完全跟随每个客户的「页面列配置」（`visibleListColumns`）——勾选哪些列卡片就显示哪些字段，未归入分组映射的新字段自动落入「📋 其他」分组，不会丢失。

桌面端（≥768px）表格视图完全不变。

无。

## 代码变更

仅改一个文件：`web/templates/insurance.html`

| 位置 | 变更 |
|------|------|
| CSS | 新增 `@media (max-width:767px)` 移动端规则：隐藏桌面表格/分页器/筛选卡，显示卡片流；新增 `.mrc-*` 卡片样式、`.m-record-toolbar` 工具栏、`.mrc-sheet-*` 底部操作菜单样式 |
| CSS | 预览弹窗头部移动端适配（`.preview-header/.preview-title-wrap/.preview-title`）：文件名单行省略，操作按钮换行为第二行、缩小尺寸 |
| 模板 | 识别记录页新增移动端工具栏（车牌快捷搜索 + 筛选开关）；筛选卡加 `record-filter-card` 类，移动端由 `mobileFilterOpen` 控制展开 |
| 模板 | 表格卡内新增 `.m-record-cards` 卡片流（与桌面表格共用 `filteredRecords`/`visibleListColumns`/`listEditing` 等全部状态）；新增「⋯」底部弹出操作菜单 |
| JS | `loadRecords()` 新增第三参 `append`（触底加载追加模式，兼容原有全部调用点） |
| JS | 新增移动端逻辑块：`mSummaryCols`/`mDetailGroups`（列配置动态分组）、`mCardTitle`/`mFieldDisplay`/`mFieldClick`（字段渲染与点击路由）、`mLoadMore`/`mOnScroll`（触底加载）、`openMSheet`/`closeMSheet`（操作菜单） |
| JS | 30 秒自动刷新守卫：移动端已触底加载多页时跳过静默刷新，避免追加数据被刷掉 |
