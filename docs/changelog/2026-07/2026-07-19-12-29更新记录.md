# 2026-07-19 群文本消息钉钉转发

## 需求说明

外部联系人（客户）在群里发的普通聊天文本，实时转发到指定钉钉群（消息转发机器人），内容包含：归属企业、消息所在群、发送人、时间、消息内容。

过滤规则（以下情况不转发）：

- **内部人员发的消息**：sender userid 非 `wm`/`wo`/`wb` 开头视为本企业内部员工（与 `contacts.get_name` 的内外部判断规则一致）
- **非文本消息**：文件、图片等只走原有链路
- **命令文本**：「发送台账+今日/本周/本月」台账导出命令、政策补充/报价回填文本（车牌+商业/交强/驾意）
- **「群公告」机器人广播**
- 单聊消息（无 roomid）不转发

与系统错误告警使用**独立的钉钉机器人**（webhook/加签独立配置），且逐条发送、不做 title 去重（错误告警的 15 分钟同 title 去重会吞掉转发消息）。

## 部署步骤

1. 上传以下文件到服务器 `/home/wxbot/` 对应路径：
   - `/home/wxbot/core/notify.py`
   - `/home/wxbot/core/fetcher.py`
   - `/home/wxbot/main.py`
2. 在服务器 `/home/wxbot/config.yaml` 中新增配置段：

   ```yaml
   # 群文本消息钉钉转发（外部联系人群聊文本；内部员工/文件/命令文本不转发）
   text_msg_notify:
     enabled: true
     webhook_url: "https://oapi.dingtalk.com/robot/send?access_token=ccfda216331e4dab4c704017dea33b71fb105bcba645a48858033859df19b9c0"
     secret: "SEC19ed750c1f2dfeeba392756fba2c71eeb689aa8c26431436ebc556d472f7d5a4"
   ```

3. `main.py` 改动需重启主进程（gunicorn `--reload` 对配置加载不生效时手动重启）
4. 验证：让外部联系人在任意群发一条文本，钉钉群应收到转发；内部员工发言不应转发
