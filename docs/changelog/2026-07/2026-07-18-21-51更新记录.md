# 2026-07-18 21:51 更新记录

## 需求说明

群内发送「发送台账今日」等命令时，若解析不出可用账号，原来一律回复「您当前账号无权限，请联系客服开通」。
但当根因是**该群的监控配置没有关联企业**（而非发送人个人权限问题）时，这个提示会误导用户去开通个人权限。

本次将两种失败原因区分提示：

| 场景 | 提示 |
|------|------|
| 群监控配置未关联企业（`enterprise_id` 为空） | 该群未配置，请联系客服配置 |
| 能定位企业，但发送人无个人绑定且企业下无启用的 enterprise 账号 | 您当前账号无权限，请联系客服开通 |
