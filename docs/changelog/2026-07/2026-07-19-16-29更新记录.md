# 2026-07-19 16:29 更新记录 — 台账车牌搜索归一化（繁体/带杠兼容）

## 需求说明

客户反馈：台账搜索车牌「粵B0U9U0」搜不到，去掉首字只搜「B0U9U0」才能搜到。

**根因**：客户输入法输出的是**繁体「粵」（U+7CB5）**，而库中存储的是**简体「粤」（U+7CA4）**，`LIKE` 无法匹配。另外库中同一辆车的车牌还存在带杠/不带杠混存（如 `粤E-R705I` 与 `粤ER705I`），互相搜不到。

## 修复内容

车牌搜索两侧归一化，兼容以下输入/存储差异：

| 场景 | 修复前 | 修复后 |
|------|--------|--------|
| 繁体输入「粵B0U9U0」 | 搜不到 | ✅ 命中 |
| 带杠输入「粤B-0U9U0」 | 搜不到 | ✅ 命中 |
| 小写输入「粤b0u9u0」 | 搜不到 | ✅ 命中 |
| 库里带杠「粤E-R705I」，搜「粤ER705I」 | 搜不到 | ✅ 命中 |

## 代码变更

仅改动 `insurance/db.py`（完整路径 `/Users/take/Downloads/yun/web/wxbot/insurance/db.py`）：
