# 列配置支持「默认排序」——页面列表初始排序 + 导出Excel默认排序可配置

## 需求说明

- 「导出列配置」新增**默认导出排序**设置：导出 Excel 时默认按配置的字段/方向排序（此前写死跟随页面所选排序、默认签单日期升序）
- 「页面列配置」同步新增**默认排序**设置：打开识别记录页时列表的初始排序
- 两处默认值均为**创建时间 升序**
- 排序配置随模板存储：系统模板（超管在字段配置页保存即写入 global 作用域）、企业模板、个人模板均支持；员工启用系统/企业模板时自动继承
- 保留既有行为：用户在识别记录页**手动切换过排序**后，导出仍跟随页面所选排序；未手动选过时才用导出列配置的默认排序
- 导出弹窗按命名模板（标准版/完整版等）选择导出列时，若该模板配置了默认导出排序则一并采用

## 数据库变更

无新表。复用 `user_field_config` 表，新增一类记录：

- `config_type` = `list_columns` / `export_columns`
- `config_key` = `default_sort`（与既有 `columns` 记录同模板、同作用域）
- `config_value` = `{"sort_by": "created_at", "sort_order": "asc"}`

排序字段取值与识别记录页排序下拉一致：`created_at`（创建日期）、`updated_at`（识别日期）、`plate_no`（车牌）、`sign_date`（签单日期）、`start_date`（起保日期）、`end_date`（终保日期）、`company_short`（保司）、`policy_no`（保单号）。

未配置时后端返回默认值（创建时间升序），无需数据迁移。

## 代码变更

### `insurance/field_config_db.py`

- 新增 `DEFAULT_SORT_CONFIG`（创建时间升序）与 `_normalize_sort_config()` 校验函数
- 新增 `get_default_sort(db, config_type, user_id, role, parent_id)`：查找优先级与 `get_column_config` 完全一致（按启用模板决定 scope，活跃模板 → 默认模板兜底）
- 新增 `save_default_sort(db, config_type, scope, scope_id, sort_config, template_name)`：与列配置同作用域同模板存储
- `delete_column_config()`：恢复默认时同步删除 `default_sort` 记录

### `insurance/api.py`

- `GET /api/insurance/column-config`：响应新增 `default_sort` 字段（含超管代管/system/enterprise 各来源分支）
- `POST /api/insurance/column-config`：请求体可选传 `default_sort`，随列配置一起保存（兼容旧前端不传则不动）
- 新增 `GET /api/insurance/default-sort`：轻量返回 `{list: {...}, export: {...}}`，识别记录页初始化用

### `web/templates/field_config.html`

- 「页面列配置」Tab 新增「默认排序」设置条（字段 + 升/降序）
- 「导出列配置」Tab 新增「默认导出排序」设置条
- 加载/保存列配置时同步读写 `default_sort`；从企业/系统模板复制新建模板时一并复制

### `web/templates/insurance.html`

- 页面初始化先请求 `/api/insurance/default-sort`，列表初始排序按「页面列配置」的默认排序（内置兜底创建时间升序，原为签单日期升序）
- 新增 `sortTouched` 标记：用户手动切换排序下拉/升降序按钮后置位；清空筛选时复位并恢复配置的默认排序
- 导出取数排序逻辑：`sortTouched ? 页面所选排序 : (命名导出模板的默认排序 || 导出列配置的默认排序)`

## 兼容性

- 旧前端 POST column-config 不传 `default_sort` → 不写入、不影响已存配置
- 未配置 `default_sort` 的模板 → 接口返回内置默认（创建时间升序）
- 行为变化提示：列表初始排序由「签单日期升序」变为「创建时间升序」（可在列配置中改回签单日期）
