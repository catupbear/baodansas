# 2026-07-21 群消息钉钉转发：展示优化 + 图片转发 + 会话深链

## 需求说明

1. **展示优化**：群文本消息转发钉钉的通知原为 6 行清单式（企业/群/发送人/时间/内容各占一行），视觉杂乱。改为紧凑三段式：
   - 第一行（标题）：`#### 💬 群名`
   - 第二行（元信息）：`**发送人** · 月-日 时:分:秒 · 企业`
   - 第三段（正文）：引用块 `> 消息内容`（多行文本每行带引用前缀）
2. **图片转发**：外部联系人在群里发的图片此前不转发，现在同样转发到钉钉，且图片本体直接显示在通知里（Markdown 图片语法），不只是"[图片]"提示。
3. **会话深链**：通知底部新增「查看会话记录 →」链接，点击进入 `https://wxbot.wuhuxiche.com/monitor/chat?roomid=xxx&corpid=xxx`，消息监控页自动切到对应企业并打开对应群的聊天界面；未登录时先到登录页，登录成功后原样回跳（深链参数不丢）。

### 图片转发链路与约束

- 复用 `insurance_handler.cos_storage` 与 fetcher 自带的 `finance_sdk/proxy/passwd/timeout`，COS 或 SDK 未配置时静默跳过（本地开发 SDK 降级不受影响）
- 过滤规则与文本一致：仅群消息、仅外部联系人（userid 以 wm/wo/wb 开头）
- 单张图片上限 20MB，超过不转发（只记日志）
- 预签名 URL 有效期 7 天，带 `response-content-type=image/jpeg` + `inline` 覆盖，避免存量下载头影响钉钉渲染；**过期后历史通知里的图片会加载失败**，通知文字仍在
- 下载/上传在独立 daemon 线程执行，不阻塞消息拉取主循环；任何异常只记日志

## 部署步骤

1. 上传到服务器 `/home/wxbot/` 对应路径：
   - `core/notify.py`、`core/fetcher.py`
   - `main.py`
   - `web/templates/monitor_login.html`、`web/templates/index.html`
2. gunicorn 带 `--reload`，传文件即生效，无需重启
3. 验证：
   - 外部联系人在任一存档群发一条文本 + 一张图片，钉钉「消息转发机器人」群应收到紧凑格式文本通知和内嵌图片通知，底部带「查看会话记录 →」
   - 未登录浏览器点通知链接 → 登录页 → 输密码 → 直达对应企业对应群的聊天界面；已登录则直接打开
