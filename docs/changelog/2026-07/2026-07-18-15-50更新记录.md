# 群通知链路修复：企业凭证归属 / 群名回退 / @对象与名称解析

## 需求与排查背景

下午测试群通知时连续暴露多个问题，逐一修复：

1. **@发送人显示空白** → FlowBot 按名字匹配群成员，解析失败回退成原始 userid
   时必然匹配不上；且机器人登录的微信号就是「技术客服（午虎保单台账系统）」本人，
   自己@自己不生效
2. **未开通群提醒"发送成功"但群里没收到** → `get_room_name` 解析失败时回退返回
   roomid，代码把 roomid 当群名传给 FlowBot；FlowBot `code=200` 仅表示指令已接收
   （异步），不代表真实送达
3. **群名解析失败报 301052（contract is over time）** → 通知代码误用了
   `handler.contacts`（主企业**车物家**的通讯录凭证，其会话存档合约已过期）去解析
   **午虎科技**的群；午虎自己的凭证一直正常（缓存里群名可解析）
