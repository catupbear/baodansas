# 2026-07-17 群同步任务：启动时强制全量同步群名

## 需求说明

原逻辑：全量刷新时，连续失败 ≥5 次且 24 小时内已尝试过的群会被退避跳过（unresolvable 同理）。
导致重启进程时，大批失败群不会被重新同步。

现改为：**每次进程启动时执行「强制全量刷新」，忽略退避规则，把表里所有群都重新同步一遍群名**。
定时的 6 小时全量刷新仍保留退避（避免长期空耗企微 API）。

## 数据库变更

无。

## 代码变更

- `storage/group_db.py`
  - `get_groups_to_sync()` 新增 `force` 参数：`full=True, force=True` 时不排除退避群，取全部群。
- `task_group_sync.py`
  - `run_sync()` 新增 `force` 参数并透传，日志标签为「强制全量刷新」。
  - `main()` 启动时的首轮全量改为 `force=True`。

## 部署步骤

```bash
# 上传两个文件到服务器 /home/wxbot/ 对应路径后：
ps aux | grep task_group_sync   # 找到旧进程 kill 掉
cd /home/wxbot && nohup python3 task_group_sync.py >> logs/group_sync.log 2>&1 &
```
