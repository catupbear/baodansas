# 2026-07-20 10:21 更新记录

## 需求说明

兼容国任财产保险「公路货物运输定额保险」电子保单的总保费提取。

样例保单：粤G06117D（保单号 6260828000909X017354），总保费应为 1,200.00 元，系统误提取为 100.00 元。

### 问题根因

该保单总保费格式为跨行：

```
总保费合计
（大写）人民币：壹仟贰佰元整 （小写）CNY：1,200.00
```

1. 通用保费规则均未命中（通用"小写"兜底模式不支持 CNY 后再跟冒号）；
2. 于是落入"紫金格式2"兜底（取"合计"标签上一行的金额），上一行为 `单车保费小计： 1,100.00`，且该兜底正则不含千分位逗号，从 "1,100.00" 中截取出 "100.00"。

## 数据库变更

无。

## 代码变更

- `insurance/policy_parser.py`
  1. `_extract_premium()` 新增国任专用优先规则：锚定 `总保费合计...（小写）CNY：金额`（跨行，支持 CNY/RMB 后跟冒号）；
  2. "紫金格式2"兜底正则支持千分位逗号，避免从 "1,100.00" 中截出 "100.00"。

### 验证结果

修复后样例保单提取：保费合计 = 1200.00，保单号 / 险种 / 车牌 / 保险期间等其余字段不受影响。
