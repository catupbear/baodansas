# 比例规则支持「设置固定值」（文本值）

**时间**：2026-07-26 18:21

## 需求说明

比例规则原来只能按条件写入数字比例（如 应付费率 = 22%）。本次新增「规则类型」选项：

- **设置比例**（默认，原有行为）：值按百分比换算（22% ↔ 0.22），命中后写入数字
- **设置固定值**：值为原样文本，不做任何百分比换算，命中条件后原样写入字段

典型场景：「同车牌 7 天内带驾乘险出单」→ 出单渠道 = 深圳前海；「使用性质 = 营运」→ 某备注字段 = 指定文案。

规则语义：

- 固定值规则同样支持「固定值 / 条件分支」两种取值方式，条件能力（字段条件 + 关联单条件）完全复用
- 条件分支的**默认值允许留空**：留空 = 都不命中时不写入该字段（保持原值/空）
- 手动改过的字段不覆盖（沿用 `manual_fields` 保护）
- 固定值写入的字段**不参与**末尾"率/比例"字段的百分比显示转换

## 数据库变更

无表结构变更。仍存储在 `user_field_config`（`config_type='ratio_rule'`），value 结构新增可选标记 `"vtype": "text"`：

```json
{"vtype": "text", "branches": [{"conditions": [...], "value": "深圳前海", "note": "带驾乘险"}], "default": ""}
```

不带 `vtype` 的旧规则完全不受影响（向后兼容）。

## 代码变更

### `insurance/field_config_db.py`（后端引擎）

- 模块头注释补充 `vtype: text` 结构说明
- 新增 `_text_val()`：文本取值（去首尾空格，空值返回 None = 不写入）
- `resolve_ratio_value()`：按 `vtype` 选择取值函数（`_text_val` / `_ratio_num`），返回值可为 str
- `apply_ratio_rules()`：文本值原样写入（不走 `f"{val:g}"` 数字格式化），且不进 `injected` 列表（该列表只用于"率"字段百分比显示转换）

### `web/templates/field_config.html`（前端配置页）

- 规则编辑弹窗新增「规则类型」切换（设置比例 / 设置固定值）；固定值模式下：写入字段、固定值、分支值、默认值均为文本输入，无 % 后缀
- 数据模型新增 `vtype` / `fixedVal` / `br.val` / `defaultVal`；打开旧规则编辑时自动补齐默认值（兼容旧数据）
- 校验：固定值模式必填固定值/分支值，默认值允许留空
- 序列化（`buildRatioConfig` / `applyRatioConfig`）：固定值规则跳过 `pctToDec` / `decToPct` 换算，原样存取文本
- 总览表格：固定值规则显示原样文本（默认值空显示"（不写入）"），新增 `fmtRuleVal` 展示函数；搜索支持匹配文本值
- Tab 说明文案补充固定值用法

批量导入暂不支持固定值规则（仍为比例专用），需要时在弹窗单条添加。

`run_ocr.py` 无需同步：本次未新增初始化逻辑与路由。
