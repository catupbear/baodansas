# 2026-07-18 21:19 更新记录

## 需求说明

台账「识别记录」页面，「全部」Tab 下混杂了电子标志、发票、缴款通知等非保单文档，日常查看和导出时干扰较大。本次新增「过滤非保单」勾选项：

1. **列表**：「全部」Tab 的 Tab 栏旁新增「过滤非保单」勾选框，**默认勾选**，勾选时列表排除已识别为非保单类型的记录（`doc_category` 非空且 ≠「保单」）；识别失败等 `doc_category` 为空的记录仍保留。其他 Tab（成功/需人工补充/非保单/失败）不显示该选项，行为不变。
2. **导出弹窗**：「全部」Tab 下打开「导出Excel」弹窗时，新增「过滤非保单」勾选项，**默认勾选**（每次打开弹窗重置为勾选）；勾选记录导出与按筛选条件导出两条链路均生效。
3. **批量操作口径一致**：「全部」Tab 无勾选记录时的「批量导出保单」「批量重新识别」按当前筛选条件查询，同样受该勾选项控制。
4. Tab 统计数不受影响：「全部 / 非保单」等计数仍按原口径显示，仅列表内容被过滤。

无。

## 代码变更

### 后端

- `/Users/take/Downloads/yun/web/wxbot/insurance/db.py`
  - `query_insurance_records()` 新增参数 `exclude_nonpolicy: bool = False`（默认关闭，**兼容历史调用方**，不传时行为不变）
  - 条件：`(doc_category = '保单' OR doc_category IS NULL OR doc_category = '')`
- `/Users/take/Downloads/yun/web/wxbot/insurance/api.py`
  - `GET /api/insurance/records` 新增查询参数 `exclude_nonpolicy=1`，透传给 `query_insurance_records`；内联 stats 统计不带该参数（保持 Tab 计数口径不变）

### 前端

- `/Users/take/Downloads/yun/web/wxbot/web/templates/insurance.html`
  - 新增状态 `filterNonPolicy`（列表，默认 true）、`exportFilterNonPolicy`（导出弹窗，默认 true）
  - Tab 栏：`recordActiveTab === 'all'` 时显示「过滤非保单」勾选框，切换即刷新列表
  - 导出弹窗：`exportPendingType === 'records' && recordActiveTab === 'all'` 时显示「过滤非保单」勾选项；`exportRecordsExcel()` 打开弹窗时重置为勾选
  - `loadRecords()` / `batchReocrSync()` / `collectBatchDownloadIds()`：全部 Tab 且勾选时追加 `exclude_nonpolicy=1`
  - `collectRecordsExportData()`：查询分支追加 `exclude_nonpolicy=1`；并对勾选记录导出分支做前端兜底过滤（`!doc_category || doc_category === '保单'`）
