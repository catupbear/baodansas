# 销售看板（第一期：仅内部超级管理员可见）

> 2026-07-19 11:07
> 方案与原型：`docs/review/销售看板方案.md`、`docs/review/销售看板原型.html`

## 需求说明

基于保单台账数据为企业生成销售看板，支持模板化配置与业绩目标管理：

- **权限（本期）**：仅内部超级管理员（super_admin）可见/可用，须选择企业后查看；后续放开企业管理员时只需调整 `_sales_dash_guard`（后端）与入口 `v-if`（前端）
- **看板**：时间筛选（本月/上月/本季度/今年/自定义）→ 指标卡 → 目标完成进度 → 趋势图/占比图/分布图 → 业务员业绩排行
- **模板化配置**：`global` 系统默认模板 → `enterprise` 企业自定义覆盖，可一键恢复默认；指标卡支持「聚合方式 + 统计字段 + 筛选条件（AND 叠加）」，如「车险保费 = 保费求和，条件：险种包含车险」；图表维度/指标/粒度、排行列均可配
- **业绩目标**：
  - 企业整体 / 条件目标（可带筛选条件）
  - 员工目标按「目标项」组织（同样可带筛选条件），目标项内支持「全员统一」一键设置 + 按人单独设置（单独值优先）
  - 周期：当月/当季/今年为滚动周期（自动按当前自然周期起算），自定义区间为一次性目标
  - 看板展示完成率：目标完成区进度条 + 排行表每人完成率列（展示哪些目标项在排行配置勾选）
- **数据说明**：每个指标卡/目标/图表/排行列带「?」悬停提示，展示后端生成的 `explain`（数据来源、筛选条件、统计范围、计算公式；公式字段附费率公式来源）
- **计算字段复用**：员工提成等直接读取现有 `fee_formula` 费率公式引擎结果（按被查看企业的管理员账号解析配置，与导出/列表同口径）

## 数据库变更

新增两张表（`main.py` 启动时自动建表，无需手工执行）：

- `dashboard_config` — 看板配置。`scope=global`（系统默认模板，scope_id=0）/ `scope=enterprise`（企业自定义）；唯一键 `(scope, scope_id)`；`enabled` 支持按企业开关
- `dashboard_targets` — 业绩目标。`target_type`：enterprise/condition/employee；员工目标 `employee_name=''` 表示全员统一值；唯一键 `(enterprise_id, target_type, name, employee_name)`

## API（挂 insurance Blueprint，复用 JWT 鉴权）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/insurance/sales-dashboard/data` | GET | 聚合数据（cards/charts/targets/ranking，均附 explain）；参数 enterprise_id、date_start、date_end |
| `/api/insurance/sales-dashboard/config` | GET / PUT | 配置读写；PUT 支持 `{config}`（企业）/`{scope:"global",config}`（默认模板）/`{reset:1}`（恢复默认）/`{enabled}`（开关） |
| `/api/insurance/sales-dashboard/targets` | GET / POST / DELETE | 目标 CRUD；POST 支持 `{target}` 单条 upsert 与 `{employee_batch}` 员工目标项批量（统一值 + persons 按人，person 传 null 删除单独设置） |
| `/api/insurance/sales-dashboard/fields` | GET | 可选统计字段（台账导出列 + 企业费率公式字段）与建议维度 |
| `/api/insurance/sales-dashboard/salesmen` | GET | 企业台账「业务员」去重名单 |

## 聚合口径

- 记录范围：本企业 `status='done'`、未删除、非「非保单」类记录
- 时间过滤：按配置 `time_field`（默认签单日期）对应 ISO 日期列，无值回退创建日期
- 金额清洗：支持「1,234.56元 / ¥1234 / 12.5%」等文本格式
- 目标完成率：滚动周期按当前自然月/季/年实时计算，与页面时间筛选无关；员工目标单独值优先于统一值
