## 需求说明

比例规则弹窗（模板配置 → 比例规则 → 添加/编辑比例规则）体验优化：

1. 「比例字段」命名不直观，无法体现"比例算出后写入哪个字段"的含义 → 改名为 **「比例写入字段」**（弹窗标签、规则总览表头、页签说明文案、必填校验提示同步更新）。
2. 弹窗顶部三个输入框（比例写入字段 / 保司 / 险种）原来是原生 `datalist`，各浏览器表现不一致、无下拉箭头提示 → 替换为**自定义模糊搜索下拉组件**：
   - 聚焦即展开全部选项，输入按"包含"模糊过滤（保司、险种均支持）；
   - 匹配片段高亮显示；
   - 支持键盘 ↑/↓ 选择、回车确认、Esc 关闭；
   - 仍允许直接输入选项之外的任意值（如新的保司简称）。
3. **无自定义字段时引导新建**：「比例写入字段」下拉为空时提示"暂无自定义字段，输入新字段名可直接新建"；输入不存在的名称时出现「＋ 新建「xxx」添加为导出列自定义字段」引导行，点击（或回车）即把该名称新建为自定义列（列表列 + 导出列双向同步，同名自动加 #2 后缀）并直接选中，无需先去「导出列配置」页签操作。
4. **条件类型说明**：条件分支编辑区顶部新增说明框，解释「字段条件」（看本条保单自己的字段值）与「关联单条件」（看是否存在另一张关联保单：按车牌号/车架号/投保人匹配、限定险种、前后 N 天）的区别及分支自上而下匹配规则；条件类型下拉与「＋字段条件 / ＋关联单条件」按钮补充悬停提示。

## 代码变更

- `/Users/take/Downloads/yun/web/wxbot/web/templates/field_config.html`
  - 新增全局 Vue 组件 `SearchSelect`（模糊搜索下拉，`search-select`），并注册到根应用；
  - 新增组件样式 `.ss-wrap / .ss-input / .ss-panel / .ss-item` 等；
  - 比例规则弹窗三个输入框改用 `<search-select>`，删除原 `datalist`（ratioFieldOptions / ratioCompanyOptions / ratioPolicyOptions）；
  - 新增计算属性 `ratioCompanyOptions`（全部 + 保司简称）、`ratioPolicyOptions`（全部/交强险/商业险/驾乘险 + 险种简称，去重）；
  - 「比例字段」文案统一改为「比例写入字段」（弹窗标签、总览表头、说明文案、校验提示）；
  - `SearchSelect` 组件新增 `empty-hint` / `create-label` 属性与 `create` 事件（新建引导行）；
  - 原 `addCustomCol` 拆出可复用的 `addCustomColByName(name, target)`（返回唯一 key），新增 `createRatioField`：从比例规则弹窗直接新建自定义列并选中；
  - 条件分支编辑区新增「字段条件 / 关联单条件」说明框与按钮悬停提示。

选项数据来源不变：比例写入字段取 `formulaFields`（导出列中的自定义列），保司/险种取简称映射（`companyShortList` / `policyTypeShortList`）。批量导入格式与已保存规则的数据结构均无变化，无兼容性影响。
