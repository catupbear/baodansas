## 联表查询示例
```sql
-- 按车牌号查保单记录
SELECT r.*, pf.plate_no, pf.policy_no, pf.insured
FROM insurance_records r
JOIN insurance_policy_fields pf ON pf.record_id = r.id
WHERE pf.plate_no = '京A12345';

-- 按投保人模糊查询
SELECT r.id, r.filename, pf.applicant, pf.policy_no
FROM insurance_records r
JOIN insurance_policy_fields pf ON pf.record_id = r.id
WHERE pf.applicant LIKE '%张三%';

-- 按保险公司统计保费
SELECT pf.company_short, COUNT(*) as cnt, GROUP_CONCAT(pf.total_premium)
FROM insurance_policy_fields pf
JOIN insurance_records r ON r.id = pf.record_id
WHERE r.status = 'done'
GROUP BY pf.company_short;
```
