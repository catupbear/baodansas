# 2026-04-26 保单识别集成 + 数据库迁移 MySQL

## 需求说明
1. 将 baoxianOcr 保单识别项目集成到 wxbot
2. 指定企微群收到的 PDF 自动触发保单识别
3. PDF 上传至 COS 存储桶（按群ID/发送人ID/文件名归类），不落盘服务器
4. 识别完成后自动同步到钉钉多维表格
5. 保留手动上传识别功能，独立页面 /insurance
6. 数据库从 SQLite 迁移到 MySQL（库名 pdfocr，PooledDB 连接池）

## 数据库变更

**迁移到 MySQL（PooledDB + pymysql）：**
- 原有 SQLite 的 messages、cursor_state、contacts_cache 表全部迁移到 MySQL
- 连接方式从单连接改为 PooledDB 连接池

**新增表：**
- `insurance_records` — 保单识别记录
- `insurance_config` — 保单识别配置（前端可配）

## 代码变更

**新增模块：**
- `insurance/` — 保单识别模块
  - `handler.py` — 队列串行处理器（控制内存，>20MB 走临时文件）
  - `api.py` — Flask Blueprint（/api/insurance/* 全部端点）
  - `db.py` — MySQL 数据库操作
  - `ocr_service.py` — pdfplumber 文本提取（支持 bytes）
  - `baidu_ocr.py` — 百度 OCR 兜底（支持 bytes）
  - `policy_parser.py` — 保单字段解析（50+ 保险公司，1700+ 行）
  - `field_mapping.py` — 字段映射
  - `dingtalk_sync.py` — 钉钉多维表格同步
  - `config/field_mapping.json` — 字段映射规则
  - `config/dingtalk_targets.json` — 钉钉同步目标
- `web/templates/insurance.html` — 保单识别独立前端页面

**修改文件：**
- `main.py` — 初始化 insurance 模块，注册蓝图，MySQL 配置读取
- `core/fetcher.py` — 消息处理后检查是否触发保单识别
- `core/contacts.py` — MySQL 连接池适配
- `core/cos_storage.py` — 新增 upload_bytes 方法（字节流直接上传）
- `sdk/finance_sdk.py` — 新增 get_media_data_bytes 方法（下载到内存）
- `storage/db.py` — 从 SQLite 重写为 MySQL + PooledDB
- `web/api.py` — MySQL 连接池适配
- `requirements.txt` — 新增 pymysql, DBUtils, pdfplumber, openpyxl, requests
- `config.yaml` — storage 配置改为 mysql 配置

## 部署步骤
1. 创建 MySQL 数据库：`CREATE DATABASE pdfocr CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
2. 授权用户：`GRANT ALL ON pdfocr.* TO 'api'@'%';`
3. 修改 `config.yaml` 中的 mysql 配置
4. `pip install -r requirements.txt` 安装新依赖
5. 重启服务，数据库表自动创建
6. 访问 `/insurance` 页面，在设置中配置：
   - 监控群列表
   - 百度OCR（可选，用于扫描件）
   - 钉钉应用凭证
   - 钉钉同步目标文档
