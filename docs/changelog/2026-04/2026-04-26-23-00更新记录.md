# 2026-04-26 监控配置管理页面

## 需求说明

新建独立的监控配置管理页面，支持 CRUD 监控规则。每条监控规则独立绑定：
- 监控来源：群聊（多个）+ 私聊（多个）
- 同步目标：指定钉钉文档
- 数据结构：自定义字段映射（OCR 字段 → 钉钉列名）

同一份 PDF 可匹配多条监控规则，各自独立同步到不同钉钉文档。

## 数据库变更

新增 `monitor_configs` 表：

```sql
CREATE TABLE monitor_configs (
    id               INT PRIMARY KEY AUTO_INCREMENT,
    name             VARCHAR(128) NOT NULL DEFAULT '',
    enabled          TINYINT NOT NULL DEFAULT 1,
    rooms            LONGTEXT,    -- 群聊列表 JSON
    users            LONGTEXT,    -- 私聊列表 JSON
    dingtalk_doc_url VARCHAR(512) DEFAULT '',
    dingtalk_base_id VARCHAR(128) DEFAULT '',
    dingtalk_sheet_id VARCHAR(128) DEFAULT '',
    field_mapping    LONGTEXT,    -- 字段映射 JSON
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_monitor_enabled (enabled)
);
```

启动时自动建表 + 自动从旧 `watch_list` 配置迁移数据。

### API 新增

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/monitor-configs` | 获取全部监控配置 |
| POST | `/api/monitor-configs` | 新增监控配置 |
| PUT | `/api/monitor-configs/<id>` | 更新监控配置 |
| DELETE | `/api/monitor-configs/<id>` | 删除监控配置 |
| PUT | `/api/monitor-configs/<id>/toggle` | 启停监控配置 |

### 页面路由

- `/monitor-config` — 监控配置管理页面

## 部署步骤

1. 拉取最新代码
2. 重启服务（自动建表 + 自动迁移旧配置）
3. 访问 `/monitor-config` 验证页面
4. 旧的 `watch_list` 和 `dingtalk_targets` 配置数据会自动迁移，无需手动操作

## 兼容性

- 旧的手动同步功能（api.py 中的 `batch_sync_dingtalk`）仍使用旧 `dingtalk_targets` 配置，不受影响
- 自动同步逻辑已切换到新 `monitor_configs` 表
- 启动时自动将旧 `watch_list` 数据迁移到新表（仅首次，新表有数据后跳过）
