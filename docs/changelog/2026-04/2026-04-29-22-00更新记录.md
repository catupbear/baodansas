# 2026-04-29 保单预览字段编辑功能

## 需求说明

1. 点击预览时自动显示右侧列表信息面板
2. 右侧列表信息支持点击字段值进行自定义修改
3. 手动修改过的字段显示橙色圆点标记，值以橙色加粗显示

## 数据库变更

- `insurance_records` 表新增 `manual_fields` LONGTEXT 字段，存储手动修改过的字段名列表（JSON 数组格式）
- 该字段在 `init_insurance_tables` 中通过 ALTER TABLE 幂等添加

## 代码变更

### 后端

- **insurance/db.py**
  - `new_columns` 新增 `manual_fields` 字段定义
  - `_JSON_FIELDS` 集合新增 `manual_fields`，确保自动序列化/反序列化

- **insurance/api.py**
  - 新增 `PUT /api/insurance/records/<id>/fields` 接口
    - 接收 `{ fields: { 字段名: 新值 } }` 格式请求体
    - 更新 `parsed_fields` 中的对应字段值
    - 将修改过的字段名追加到 `manual_fields` 列表
    - 自动触发 `display_fields` 重新映射（由 `update_insurance_record` 处理）
  - `get_record` 接口增加 `manual_fields` 的 JSON 反序列化

### 前端

- **web/templates/insurance.html**
  - `previewRecord()` 打开预览时自动设置 `previewShowFields = true`
  - 右侧列表信息面板中，自动识别记录的字段值支持点击进入编辑模式
  - 编辑模式提供输入框 + 确认/取消按钮，支持 Enter 保存、Escape 取消
  - 手动修改过的字段：标签旁显示橙色圆点，值以橙色加粗文字显示
  - 新增 Vue 状态：`editingField`、`editingValue`、`fieldSaving`
  - 新增方法：`startEditField`、`cancelEditField`、`saveEditField`、`isManualField`

## 部署步骤

1. 更新代码：`git pull`
2. 重启服务：`python main.py`（数据库字段会自动添加，无需手动迁移）
