# 2026-04-27 同步通讯录、识别方式筛选、识别成功率

## 需求说明
- 监控页面工具栏添加"同步通讯录"按钮，手动触发刷新所有群/联系人名称缓存
- 监控配置页面弹窗中群聊/私聊下拉框添加"刷新数据"按钮，方便配置时获取最新通讯录
- 保单识别记录页添加"识别方式"筛选（pdfplumber / 百度OCR）
- 保单识别记录页添加识别成功率统计条（总记录、成功、失败、成功率进度条、识别方式分布）
- 修复发送人名称为ID时直接同步到钉钉的问题，同步前二次解析
- COS 文件 URL 支持 CDN 域名，通过 config.yaml 中 `cos.cdn_domain` 配置
- 监控页面支持点击群头像/发送人头像手动编辑名称，解决企微 API 获取失败时的关联问题
- 保单识别页自动识别记录的群名/发送人支持点击编辑，同步更新 insurance_records 表冗余名称
- 自动识别记录文件名支持点击弹窗预览（复用手动上传的预览弹窗），右侧面板显示解析字段
- 自动识别记录新增"重新识别"功能：从 COS 重新下载文件并 OCR，识别完成后自动打开预览确认
- 同步钉钉按钮支持已同步记录的"更新同步"，覆盖原有数据

## 代码变更

### web/api.py
- 新增 `POST /api/contacts/sync` 接口，遍历 messages 表所有 roomid 和 sender，逐个调企微 API 刷新缓存

### web/templates/index.html
- 工具栏新增"同步通讯录"按钮（btn-secondary 样式）
- 新增 `syncContacts()` JS 函数，调用同步接口并显示结果，完成后自动刷新会话列表

### web/templates/monitor_config.html
- 新增/编辑弹窗的"群聊监控"区域添加"刷新数据"按钮
- 点击后先调用 `/api/contacts/sync` 同步通讯录，再重新加载群聊/用户选项列表
- 新增 `refreshOptions()` 方法和 `refreshingOptions` 状态

### web/api.py
- 新增 `POST /api/contacts/update` 接口，手动设置联系人/群名称写入 contacts_cache
- 保存联系人时同步更新 insurance_records 表中的 room_name / sender_name 冗余字段

### web/templates/insurance.html
- 自动识别记录表格的群名/发送人列支持点击弹出编辑弹窗
- 记录详情弹窗的群名/发送人也支持点击编辑
- 新增联系人编辑弹窗（Vue 组件），保存后自动刷新记录列表

### web/templates/index.html
- 新增联系人编辑弹窗（ID/类型/名称），支持 Enter 保存、Esc 关闭
- 会话列表群头像可点击编辑群名
- 聊天消息发送人头像可点击编辑用户名
- 保存后自动刷新会话列表和聊天内容

### core/cos_storage.py
- `CosStorage` 新增 `cdn_domain` 参数，支持 CDN 加速域名
- 新增 `_make_url()` 统一 URL 生成逻辑：有 CDN 域名用 CDN，否则用默认 COS 域名
- 所有 URL 生成统一走 `_make_url()`

### main.py
- COS 初始化传入 `cdn_domain`，从 `config.yaml` 的 `cos.cdn_domain` 读取

### insurance/handler.py
- `_process_message()` 同步钉钉前增加发送人名称二次解析：当 sender_name 仍等于 sender ID 时，重新调用 `contacts.get_name()` 获取真实姓名，并同步更新数据库记录

### insurance/api.py
- 新增 `GET /api/insurance/records/<id>/preview` 代理预览接口，服务端请求 COS 文件后以 `inline` 方式返回，避免浏览器直接下载

### insurance/db.py
- `query_insurance_records()` 新增 `ocr_engine` 参数，支持按识别方式筛选
- `get_insurance_stats()` 新增 `engine_stats` 返回值，按识别方式统计数量

### insurance/api.py
- `GET /api/insurance/records` 新增 `ocr_engine` 查询参数

### web/templates/insurance.html
- 筛选栏新增"识别方式"下拉框（全部 / pdfplumber / 百度OCR）
- `recordFilter` 新增 `ocr_engine` 字段，`loadRecords` 传递该参数
- 筛选栏和表格之间新增识别成功率统计条：总记录/成功/失败/成功率+进度条+识别方式分布
- 新增 `recordStats` 状态和 `loadRecordStats()` 方法，调用 `/api/insurance/stats`
