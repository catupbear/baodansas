# 2026-04-28 18:00 更新记录

## 需求说明
优化保单识别记录列表查询性能 — 列表不再返回 parsed_fields（LONGTEXT），改为使用预计算的 display_fields（TEXT）展示映射后的字段。

## 数据库变更
- `insurance_records` 表新增列：
  - `is_abnormal` TINYINT DEFAULT 0 — 预计算的异常标记（加速列表筛选）
  - `hint` VARCHAR(64) DEFAULT '' — 提示信息（如"保单无投保人"）
  - `display_fields` TEXT — 映射后的展示字段 JSON（如 `{"承保公司":"人保","保单号":"xxx","车牌":"xxx",...}`）
- 新增索引：`idx_insurance_is_abnormal`
- 启动时自动回填已有记录的 `is_abnormal`、`hint`、`display_fields`

## 代码变更

### insurance/db.py
- 新增 import `apply_mapping`（字段映射函数）
- 新增 `_compute_abnormal()` 函数：服务端计算异常状态（逻辑与前端 isRecordAbnormal 一致）
- `save_insurance_record()`: 保存时自动计算 is_abnormal、hint、display_fields
- `update_insurance_record()`: 更新 parsed_fields 时同步更新 display_fields；更新状态相关字段时读取现有数据重新计算异常
- `query_insurance_records()`:
  - 列表 select 精简（去掉 parsed_fields、msg_seq、filesize、dingtalk_target_id、updated_at）
  - 新增 display_fields、company_short、is_abnormal、hint 返回
  - 新增 is_abnormal、company_short 筛选参数
  - doc_category 支持排除模式（如 `!保单`）
- `get_insurance_stats()`: 新增 abnormal_cnt、nonpolicy_cnt 统计

### insurance/api.py
- 列表接口新增 is_abnormal、company_short 查询参数
- 列表返回 display_fields 替代 parsed_fields

### web/templates/insurance.html
- 列表动态字段列改用 `record.display_fields[col]` 展示
- Tab 筛选（成功/异常/非保单）改为服务端参数
- 保司筛选改为服务端 company_short 参数
- Tab 统计数来自服务端 stats API（abnormal_cnt、nonpolicy_cnt）
- 详情弹窗和文件预览改为异步请求详情 API 获取完整 parsed_fields
- 导出功能直接使用列表 display_fields

## 部署步骤
1. 部署代码，重启服务
2. 启动时自动执行 DB migration（加列、加索引、回填 display_fields/is_abnormal）
3. 无需手动操作
