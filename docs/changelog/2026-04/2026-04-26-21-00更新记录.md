# 2026-04-26 模板训练管理前端页面

## 需求说明
新增模板训练管理前端页面（`/training`），包含四个 Tab：
1. **模板训练** — 上传样本 PDF 训练新模板，支持拖拽上传、保司/险种选择、训练结果展示
2. **模板管理** — 查看已注册的模板列表（调用 registry.json）
3. **训练记录** — 历史训练记录（预留，暂显示空列表）
4. **告警中心** — 分页展示结构变动告警，支持筛选和标记已处理

## 数据库变更
无

## 代码变更

### 新增文件
- `web/templates/training.html` — 模板训练管理前端页面，与 insurance.html 保持一致的视觉风格

### 修改文件
- `main.py` — 添加 `/training` 路由
- `insurance/api.py` — 添加 `GET /api/insurance/templates` API，读取 registry.json 返回模板列表

## 部署步骤
1. 拉取最新代码
2. 重启服务 `python main.py`
3. 访问 `/training` 进入模板训练管理页面
