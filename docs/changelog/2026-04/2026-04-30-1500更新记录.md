# 2026-04-30 启动自动补拉历史消息 + 补扫保单 PDF

## 需求说明

监控服务中断期间，回调不会触发消息拉取，导致历史消息和保单 PDF 未被处理。
需要在服务重启时自动补拉中断期间的消息，并对漏掉的保单 PDF 重新触发识别。

## 代码变更

### 1. `core/fetcher.py` — 新增 `rescan_missed_insurance()` 方法

- 查询最近 N 天（默认 7 天）内，在监控群/用户范围中的 PDF 文件消息
- 通过 `LEFT JOIN insurance_records` 排除已有识别记录的消息
- 将遗漏的 PDF 消息重新入队到 `insurance_handler`

### 2. `main.py` — 启动时自动补拉 + 补扫

- SDK 初始化完成、`insurance_handler` 绑定到 `fetcher` 之后
- 启动后台守护线程执行：
  1. `fetcher.fetch_new_messages()` — 从上次 seq 游标继续拉取所有新消息
  2. `fetcher.rescan_missed_insurance(lookback_days=7)` — 补扫遗漏的保单 PDF

## 数据库变更

无

## 部署步骤

1. 拉取最新代码
2. 重启服务即可，补拉逻辑会在启动后自动执行
