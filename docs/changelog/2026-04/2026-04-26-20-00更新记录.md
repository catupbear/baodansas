# 2026-04-26 消息监控页面改版为聊天界面

## 需求说明

将企业微信消息监控页面从表格列表形式改造为类似微信/Slack 的聊天界面，提升消息浏览体验：
- 左侧会话列表，按最后消息时间倒序，支持搜索
- 右侧聊天区，消息统一靠左排列（Slack 风格），不同发送人用不同颜色标识
- 图片在聊天中显示缩略图，点击全屏预览，支持左右箭头切换同会话图片
- PDF 文件支持直接内嵌预览
- 顶部保留工具栏（拉取按钮、统计信息）

## 数据库变更

无数据库结构变更。

## 代码变更

### 后端

1. **storage/db.py**
   - 优化 `get_conversations()`：合并为单条 SQL（JOIN 替代 N+1 查询），消除逐个查询最后一条消息的性能瓶颈
   - 优化 `query_messages()`：只查前端需要的字段（去掉 raw_data），新增 `order`、`conversation_id` 参数
   - 优化 `get_stats()`：新增 10 秒内存缓存，避免频繁 COUNT(*) 全表扫描

2. **web/api.py**
   - 新增 `GET /api/conversations` 端点：返回会话列表，支持 keyword 搜索
   - 修改 `GET /api/messages` 端点：新增 order、conversation_id 参数

3. **core/contacts.py**
   - 新增内存缓存层（5分钟 TTL），减少数据库查询
   - 新增 `_batch_get_cache()` 方法：一次 SQL 批量查询所有联系人缓存，替代逐个 SELECT
   - 优化 `batch_resolve()`：先批量查缓存，只对未命中的才调 API
   - 新增 `find_unresolved()` + `resolve_unresolved()` + `start_auto_resolve()`：后台线程每 5 分钟自动补全未解析的联系人/群名

4. **main.py**
   - 在通讯录模块初始化后启动自动解析线程

### 前端

5. **web/templates/index.html** — 完全重写
   - 布局：顶部工具栏 + 左侧会话列表(280px) + 右侧聊天区
   - 会话列表：搜索框 + 会话项（头像色块、名称、最后消息、时间、消息数）
   - 聊天区：Slack 风格消息展示（头像、昵称、时间、内容），支持时间分隔线（5分钟间隔）
   - 消息类型丰富渲染：文本(含链接解析)、图片缩略图、文件卡片、链接卡片、语音播放器、视频播放器、位置、名片、红包、撤回
   - PDF 文件内嵌 iframe 预览，支持新窗口打开和下载
   - 图片灯箱：全屏预览、左右箭头/键盘导航、计数器
   - 加载更多：聊天区顶部按钮加载更早的消息
   - 30秒自动刷新会话列表和当前聊天

## API 性能优化汇总

| 优化项 | 优化前 | 优化后 |
|--------|--------|--------|
| 会话列表查询 | 1 + N 次 SQL（N=会话数） | 1 次 SQL（JOIN） |
| 联系人缓存查询 | N 次 SELECT（逐个查） | 1 次 SELECT ... IN（批量查） |
| 联系人缓存 | 仅数据库缓存 | 内存缓存(5min) + 数据库缓存(24h) |
| 统计信息 | 每次 COUNT(*) 全表扫描 | 10秒内存缓存 |
| 消息查询字段 | SELECT *（含 raw_data LONGTEXT） | 只查需要的 10 个字段 |

## 部署步骤

1. 更新代码到服务器
2. 重启 Flask 服务：`python main.py`
3. 无需数据库迁移
