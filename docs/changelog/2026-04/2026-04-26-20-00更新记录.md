# 2026-04-26 消息监控页面改版为聊天界面

## 需求说明

将企业微信消息监控页面从表格列表形式改造为类似微信/Slack 的聊天界面，提升消息浏览体验：
- 左侧会话列表，按最后消息时间倒序，支持搜索
- 右侧聊天区，消息统一靠左排列（Slack 风格），不同发送人用不同颜色标识
- 图片在聊天中显示缩略图，点击全屏预览，支持左右箭头切换同会话图片
- 顶部保留工具栏（拉取按钮、统计信息）

## 数据库变更

无数据库结构变更。

## 代码变更

### 后端

1. **storage/db.py**
   - 新增 `get_conversations()` 方法：按 roomid 分组获取会话列表，私聊按 sender 分组，返回每个会话的最后消息摘要、时间、消息数量
   - 修改 `query_messages()` 方法：新增 `order` 参数支持正序/倒序，新增 `conversation_id` 参数支持私聊会话筛选；roomid 筛选改为精确匹配（原为模糊匹配）

2. **web/api.py**
   - 新增 `GET /api/conversations` 端点：返回会话列表，支持 keyword 搜索，自动解析群名/用户昵称
   - 修改 `GET /api/messages` 端点：新增 order、conversation_id 参数透传

3. **core/contacts.py**
   - 新增 `find_unresolved()` 方法：从 messages 表中查找所有未缓存或已过期的 sender/roomid
   - 新增 `resolve_unresolved()` 方法：批量解析未缓存的联系人和群名，每次 API 调用间隔 0.5 秒避免频率限制
   - 新增 `start_auto_resolve()` 方法：启动后台守护线程，每 5 分钟检查一次，自动补全未解析的名称

4. **main.py**
   - 在通讯录模块初始化后启动自动解析线程

### 前端

3. **web/templates/index.html** — 完全重写
   - 布局：顶部工具栏 + 左侧会话列表(280px) + 右侧聊天区
   - 会话列表：搜索框 + 会话项（头像色块、名称、最后消息、时间、消息数）
   - 聊天区：Slack 风格消息展示（头像、昵称、时间、内容），支持时间分隔线（5分钟间隔）
   - 消息类型丰富渲染：文本(含链接解析)、图片缩略图、文件卡片、链接卡片、语音播放器、视频播放器、位置、名片、红包、撤回
   - 图片灯箱：全屏预览、左右箭头/键盘导航、计数器
   - 加载更多：聊天区顶部按钮加载更早的消息
   - 30秒自动刷新会话列表和当前聊天

## 部署步骤

1. 更新代码到服务器
2. 重启 Flask 服务：`python main.py`
3. 无需数据库迁移
