# 2026-04-30 18:00 更新记录

## 需求说明

提取异常的保单记录支持手动标记为正常，标记时需选择原因（如"保单内无投保人数据"），支持撤销标记。

## 数据库变更

### insurance_records 表新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `abnormal_override_reason` | VARCHAR(128) DEFAULT NULL | 手动标记正常的原因，非NULL时强制 is_abnormal=0 |

字段通过 `ALTER TABLE ADD COLUMN` 幂等添加，无需手动迁移。

## 代码变更

### 后端

- `insurance/db.py`
  - 新增 `abnormal_override_reason` 列定义（自动迁移）
  - `_compute_abnormal()` 新增 `abnormal_override_reason` 参数，非空时直接返回正常
  - `update_insurance_record()` 更新异常重算逻辑，支持 override 场景
  - 列表查询 `select_cols` 新增 `abnormal_override_reason` 字段
- `insurance/api.py`
  - 新增 `PUT /api/insurance/records/<id>/mark-normal` — 标记异常记录为正常
  - 新增 `PUT /api/insurance/records/<id>/undo-mark-normal` — 撤销标记

### 前端

- `web/templates/insurance.html`
  - 识别记录操作列新增"标记正常"按钮（异常记录可见）
  - 已标记记录显示"已标记正常"标签 + 撤销按钮
  - 文件名下方显示标记原因提示
  - 新增标记原因选择弹窗，根据缺失字段自动生成快捷原因

## 部署步骤

1. 更新代码并重启服务（数据库字段自动迁移）
2. 无需手动执行 SQL
