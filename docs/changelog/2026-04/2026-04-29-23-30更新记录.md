## 需求说明

### 1. 申能保费提取优化
申能财产保险股份有限公司的保单，保险费需要优先提取"保险费总计"的小写金额，而非"不含税保费"。

示例文本：
```
不含税保费:294.34元 增值税:5.66元
保险费总计： （大写） 叁佰元 小写 300.00元
```
期望提取：300.00（总计），而非 294.34（不含税保费）。

### 2. 紫金被保险人清单提取
紫金财产保险股份有限公司的附录"被保险人清单"表格格式，表头含"被保险人姓名 方案号 证件类型..."，数据行以序号开头。支持多个被保人用"、"拼接。

示例文本：
```
被保险人清单
序号 被保险人姓名 方案号 证件类型 证件号码 职业工种 职业类别（级）
1    钟赛敬       2     身份证   441424... 自由职业人员 4
```

### 3. 安盛天平保费提取优化
安盛天平驾乘险格式，保费区域含"保费/税费/价税合计"三个金额，需优先提取"价税合计"。

示例文本：
```
总保险费(含税价): RMB 保费：￥180.32 税费：￥9.68 价税合计：￥190.00
```
期望提取：190.00（价税合计），而非 180.32（不含税保费）。

### 4. 太平保费提取优化
太平驾乘险格式，"总保��(含税)"与"小写： CNY XXX"跨行，需优先取含税总保费。

示例文本：
```
总保费(含税)：
小写： CNY 599.00（
不含税保费：587.23元，税额：11.77元）
```
期望提取：599.00（含税总保费），而非 587.23（不含税保费）。

### 4b. 太平保费提取优化（另一格式）
太平另一种格式，"小写：RMB855.00元"在"保险费合计"标签之前，需取小写行的 RMB 金额。

示例文本：
```
人民币大写：捌佰伍拾伍圆整，小写：RMB855.00元（
不含税保费：RMB806.60元，税额：RMB48.40元）其中
保险费合计
```
期望提取：855.00（含税总保费），而非 806.60（不含税保费）。

### 4c. 太平保费提取优化（OCR空格格式）
太平另一种格式，OCR将"保险费合计"拆成"保 险 费 合 计"带空格，后接"小写：RMB金额"。

示例文本：
```
保 险 费 合 计 人民币大写：肆仟陆佰叁拾陆圆壹角陆分，小写：RMB4636.16元（其中
不含税保费：RMB4373.73元，税额：RMB262.43元）
```
期望提取：4636.16（含税总保费），而非 4373.73（不含税保费）。

### 5. 平安被保人提取 — 公司名跨行截断修复
平安商业险 OCR 将公司名截断到下一行，如"深圳市义奇和乐科技有限公"在第一行、"司"在下一行，导致被保人提取失败或误提取为"公司"。

示例文本：
```
被保 正式名称: 深圳市义奇和乐科技有限公 证件类型: 统一社会信用代码
险人 司
```
期望提取：深圳市义奇和乐科技有限公司

### 6. 被保人黑名单补充
单独的"公司"二字不应作为有效被保人名。

## 代码变更

### insurance/policy_parser.py
- `_extract_premium()`：
  - 为申能新增优先匹配"保险费总计...小写 XXX元"规则
  - 为安盛天平新增优先匹配"价税合计：￥XXX"规则
  - 为太平新增三条优先规则：跨行"总保费...小写CNY"；"小写RMB...保险费合计"；OCR空格"保 险 费 合 计...小写RMB"
- `_extract_insured_pingan()`：新增跨行公司名拼接逻辑，从"被保 正式名称:"到"证件类型"提取后，若公司名不完整则向下一行查找残余片段拼接
- `_extract_insured()`：新增紫金专用分支，调用 `_extract_insured_zijin()`
- 新增 `_extract_insured_zijin()` 函数：解析"被保险人清单"表格，支持多人用"、"拼接
- `_extract_insured_common()` 中通用表格匹配：放宽表头正则，兼容"方案号/方案/保额"等列头
- `PERSON_BLACKLIST` 新增"公司"，防止单独两字被当作有效被保人
- 保司说明文档补充各保司格式
