# 2026-04-29 账号系统更新记录

## 需求说明

为保单识别系统添加三级账号体系，实现数据权限隔离：

- **超级管理员 (super_admin)**：查看所有数据，管理所有账号
- **企业账号 (enterprise)**：查看该企业下所有子账号的数据
- **员工账号 (employee)**：仅查看自己关联的数据

所有业务 API 加 JWT token 验证，企微回调接口不受影响。

## 数据库变更

### 新增表

**`users` 表**
```sql
CREATE TABLE IF NOT EXISTS users (
    id           INT PRIMARY KEY AUTO_INCREMENT,
    username     VARCHAR(64) NOT NULL UNIQUE,
    password_hash VARCHAR(256) NOT NULL,
    role         VARCHAR(32) NOT NULL DEFAULT 'employee',   -- super_admin / enterprise / employee
    parent_id    INT DEFAULT NULL COMMENT '所属企业账号ID',
    display_name VARCHAR(128) DEFAULT '',
    enabled      TINYINT NOT NULL DEFAULT 1,
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_users_role (role),
    INDEX idx_users_parent (parent_id)
);
```

### 现有表变更

- **`insurance_records`** 新增 `user_id INT DEFAULT NULL` 列 + 索引
- **`monitor_configs`** 新增 `user_id INT DEFAULT NULL` 列 + 索引

> 所有 ALTER TABLE 操作幂等（已存在则跳过），无需手动执行 DDL。

## 部署步骤

1. 安装新依赖：
   ```bash
   pip install PyJWT>=2.8
   ```

2. 重启服务：
   ```bash
   python main.py
   ```
   > 首次启动会自动建表 + 创建默认超管账号

3. 默认超管账号：
   - 用户名：`admin`
   - 密码：`admin123`
   - **请首次登录后立即修改密码**

## API 新增

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/auth/login` | 登录 | 公开 |
| GET | `/api/auth/me` | 当前用户信息 | 登录 |
| POST | `/api/auth/change-password` | 修改密码 | 登录 |
| GET | `/api/auth/users` | 用户列表 | 超管 |
| POST | `/api/auth/users` | 创建用户 | 超管 |
| PUT | `/api/auth/users/{id}` | 更新用户 | 超管 |
| POST | `/api/auth/users/{id}/reset-password` | 重置密码 | 超管 |
