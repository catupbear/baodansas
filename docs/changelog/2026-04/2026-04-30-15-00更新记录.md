# 2026-04-30 15:00 更新记录 — 企业管理模块

## 需求说明
新增独立的企业管理功能，将企业与用户解耦。企业作为独立实体存储在 `enterprises` 表中，用户通过 `parent_id` 关联企业。保单识别记录同时关联 `user_id` 和 `enterprise_id`，权限过滤按企业维度进行。

## 数据库变更
- 新增 `enterprises` 表：
  - `id` — 主键自增
  - `name` — 企业名称（必填）
  - `contact_person` — 联系人
  - `contact_phone` — 联系电话
  - `enabled` — 启用/禁用状态
  - `created_at` / `updated_at` — 时间戳
  - 索引：`idx_enterprises_name`
- `insurance_records` 表新增 `enterprise_id` 列（INT，关联 enterprises.id），索引 `idx_insurance_enterprise_id`
- `monitor_configs` 表新增 `enterprise_id` 列（INT，关联 enterprises.id），索引 `idx_mc_enterprise_id`

## 代码变更
- `auth/db.py` — 新增 `init_enterprises_table()` 及企业 CRUD 函数（list/get/create/update）
- `auth/api.py` — 新增企业 CRUD API（`GET/POST /api/auth/enterprises`、`PUT /api/auth/enterprises/<id>`），用户列表 API 填充 `parent_name`，用户创建 `parent_id` 校验改为 enterprises 表
- `insurance/db.py` — `insurance_records` 新增 `enterprise_id` 列，`query_insurance_records` 和 `get_insurance_stats` 支持 `enterprise_id` 过滤
- `insurance/api.py` — 手动识别自动写入 `enterprise_id`，新增 `_get_enterprise_id_filter()` 按企业过滤，列表和统计 API 均支持企业维度过滤
- `insurance/handler.py` — 自动识别从监控配置取 `enterprise_id` 写入记录
- `insurance/monitor_config_db.py` — `monitor_configs` 表新增 `enterprise_id` 列
- `web/templates/admin_enterprises.html` — 新增企业管理前端页面
- `web/templates/admin_users.html` — 导航加"企业管理"，所属企业下拉改从 enterprises 表取，去掉"企业账号"角色
- `main.py` — 新增 `/admin/enterprises` 路由，启动时初始化 enterprises 表

## 部署步骤
1. 更新代码
2. 重启服务（enterprises 表和新字段会自动创建）
3. 通过"企业管理"页面添加企业
4. 创建员工时选择所属企业
5. 监控配置如需绑定企业，更新配置中的 enterprise_id
