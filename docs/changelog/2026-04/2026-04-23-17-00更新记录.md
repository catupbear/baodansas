# 添加前端消息查看页面

## 需求说明
添加 Web 前端页面，通过浏览器访问同一端口即可查看聊天消息数据。

## 代码变更
| 文件 | 说明 |
|------|------|
| `web/api.py` | 新增 API 蓝图，提供 `/api/messages`（分页查询）和 `/api/stats`（统计）接口 |
| `web/templates/index.html` | 前端页面，消息列表+筛选+分页+详情弹窗+自动刷新 |
| `storage/db.py` | 新增 `query_messages`（分页筛选查询）和 `get_stats`（统计）方法 |
| `main.py` | 注册 API 蓝图和前端首页路由 |

## 功能说明
- 访问 `http://服务器:5000/` 打开消息监控页面
- 支持按消息类型、发送人、群ID、关键词筛选
- 分页浏览，每页50条
- 点击"详情"查看完整消息内容和原始数据
- 30秒自动刷新（可关闭）
- 顶部显示消息总数、当前SEQ、消息类型数统计
