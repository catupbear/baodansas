# 2026-04-29 00:30 更新记录

## 需求说明
接入火山引擎通用文字识别（OCRNormal），作为 OCR 降级链的首选引擎。

降级优先级：`pdfplumber` → `火山引擎 OCR` → `百度 OCR`

## 代码变更
- **新增** `insurance/volc_ocr.py` — 火山引擎 OCR 客户端
  - 自实现 HMAC-SHA256 V4 签名，不依赖重量级 SDK
  - 接口与百度 OCR 保持一致：`recognize_pdf`、`recognize_pdf_multi_pages`、`recognize_image`
  - 多页 PDF 支持逐页拆页识别（依赖 pypdf），遇条款页自动停止
- **修改** `insurance/handler.py`
  - 新增 `_init_volc_ocr()` / `reload_volc_ocr()` / `reload_all_ocr()`
  - `_do_ocr()` 降级链：pdfplumber → 火山引擎 → 百度
  - 手动上传图片识别也支持火山引擎优先
- **修改** `insurance/api.py`
  - `POST /api/insurance/reload-ocr` 升级为重载所有 OCR 引擎
- **修改** `requirements.txt` — 新增 pypdf 依赖

## 配置说明
在 `config.yaml` 中添加：
```yaml
volc_ocr:
  access_key_id: "你的AK"
  secret_access_key: "你的SK"
```

## 部署步骤
1. `pip install pypdf` （或 `pip install -r requirements.txt`）
2. 在 `config.yaml` 中配置 `volc_ocr` 的 AK/SK
3. 重启服务，或调用 `POST /api/insurance/reload-ocr` 热加载
