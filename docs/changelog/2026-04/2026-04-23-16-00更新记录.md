# 企业微信会话内容存档 - 初始实现

## 需求说明
基于企业微信会话内容存档API，实现回调驱动的聊天记录获取与监听服务。
- 通过 Flask 搭建回调接收服务
- 收到 `msgaudit_notify` 回调事件后，调用 C SDK 拉取并解密聊天记录
- 支持多种消息类型解析，数据存入 SQLite

## 数据库变更
- 新建 SQLite 数据库 `data/wxbot.db`
  - `messages` 表：存储解密后的聊天消息
  - `cursor_state` 表：存储 seq 拉取游标

## 代码变更
| 文件 | 说明 |
|------|------|
| `config.yaml` | 项目配置文件（企业信息、回调参数、SDK路径等） |
| `requirements.txt` | Python 依赖（flask, pycryptodome, PyYAML） |
| `main.py` | 入口文件，初始化所有模块并启动 Flask 服务 |
| `callback/crypto.py` | 企业微信回调消息 AES 加解密与签名验证 |
| `callback/server.py` | Flask 路由（GET验证URL + POST接收回调） |
| `sdk/finance_sdk.py` | ctypes 封装官方 C SDK |
| `core/decryptor.py` | RSA + SDK 消息解密 |
| `core/fetcher.py` | 回调触发的消息分页拉取逻辑 |
| `core/parser.py` | 多消息类型解析（文本/图片/语音/视频/文件/链接等） |
| `storage/db.py` | SQLite 存储（消息 + seq游标） |

## 部署步骤
1. 在 Linux 服务器上部署
2. 下载企业微信官方 C SDK（`libWeWorkFinanceSdk_C.so`）放入 `sdk/` 目录
3. 生成 RSA 2048 密钥对，公钥上传至企业微信后台
4. 修改 `config.yaml` 填入企业信息
5. 安装依赖：`pip install -r requirements.txt`
6. 启动服务：`python main.py`
7. 在企业微信管理后台配置回调URL为 `http://your-server:5000/callback`
