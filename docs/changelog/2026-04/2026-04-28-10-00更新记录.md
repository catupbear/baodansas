# 2026-04-28 10:00 更新记录

## 需求说明

1. **支持保司动态统计**：将保单识别页面的"支持保司"列表从前端硬编码改为后端动态统计。根据已识别文档数量自动判断是否支持某保司（默认阈值10次），支持配置保司简称别名。
2. **手动上传记录入库**：手动上传识别的保单每次都记录到数据库，相同保单号的记录自动更新而非重复创建。
3. **上传保单开关**：新增"上传保单到云存储"开关（默认关闭），开启后手动识别的文件同时上传到 COS。

## 数据库变更

无表结构变更。新增 `insurance_config` 配置项：
- `company_threshold` — 保司支持阈值（默认10）
- `company_aliases` — 保司简称别名映射（JSON对象，如 `{"太平洋财险": "太平洋"}`）

## 代码变更

### 后端
- `insurance/db.py`
  - 新增 `get_company_stats()` — 从 `insurance_records` 表统计各保司识别数量
  - 新增 `upsert_insurance_record_by_policy()` — 按保单号去重保存（存在则更新，否则新建）
- `insurance/api.py`
  - 新增 `GET /api/insurance/supported-companies` — 获取保司列表及统计
  - 新增 `PUT /api/insurance/supported-companies/config` — 更新阈值和别名配置
  - 新增 `_save_manual_record()` 辅助函数 — 手动识别记录保存（含可选 COS 上传）
  - 修改 `POST /api/insurance/parse` — 识别成功后自动保存记录，支持 `upload_cos` 参数
  - 修改 `POST /api/insurance/ocr` — 识别成功后自动保存记录，支持 `upload_cos` 参数

### 前端
- `web/templates/insurance.html`
  - 支持保司列表改为从 API 动态加载，显示识别次数，未达标保司半透明展示
  - 新增可折叠的保司配置面板（阈值 + 别名管理）
  - 新增"上传保单到云存储"开关（默认关闭），位于"开始识别"按钮旁
  - 识别请求中传递 `upload_cos` 参数

## 部署步骤

1. 更新代码并重启服务即可，无需手动建表或迁移
2. 首次部署后，保司列表根据历史数据自动生成
3. 如需调整阈值或设置别名，在保单识别页面的"支持保司"区域点击"配置"即可
