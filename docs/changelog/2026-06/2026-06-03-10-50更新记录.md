# 兼容中国大地财产保险「物流责任保险」保费提取

## 需求说明

中国大地财产保险股份有限公司的物流责任保险保单，其保费提取结果错误。

原因：该保单保费区块为表格结构，「保险费」作为列表头单独成行，紧随其后的下一行是**费率**（如 `0.02`），导致通用模式 `(?<!税)总?保险?费[：:\s]*([\d,]+\.\d{2})` 误将费率 `0.02` 当作保费合计。

正确的保费在文末汇总行：
```
总保险费:人民币壹仟壹佰伍拾元整(CNY1,150.00),其中不含税保险费1,084.91元、增值税65.09元。
```
应提取 `1150.00`。

## 数据库变更

无。

## 代码变更

- `insurance/policy_parser.py` — `_extract_premium()` 新增大地专属高优先级模式：
  ```python
  if company_short == "大地":
      patterns.insert(0, r"总保险费[：:]\s*人民币[^（(]*?[（(]CNY\s*([\d,]+\.\d{2})")
  ```
  优先匹配「总保险费…(CNY金额)」格式，避免被表格中「保险费」表头后的费率误取。
  「不含税保费」「增值税额」沿用已有通用逻辑，无需改动。

## 兼容性说明

- 仅对 `company_short == "大地"` 生效，且模式以 `总保险费…(CNY` 为前缀，仅在大地此类 CNY 大写汇总格式下命中；不存在该格式（如大地车险）时不命中，自动回落到通用模式，不影响大地其它险种的历史提取。

## 部署步骤

无数据库/配置变更，重启服务即可生效。

## 验证

```
输入: 总保险费:人民币壹仟壹佰伍拾元整(CNY1,150.00),其中不含税保险费1,084.91元、增值税65.09元。
输出: 保费合计=1150.00, 不含税保费=1,084.91, 增值税额=65.09
```
修复前（含表格表头）误取 `保费合计=0.02`，修复后正确为 `1150.00`。
