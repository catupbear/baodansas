# 2026-06-06 修复安诚财险车牌提取错误

## 需求说明

安诚财产保险（安城）机动车商业险保单识别时，车牌号被错误提取为
`粤BH917RLVSHBFAF8AF146084`（车牌 `粤BH917R` 与 17 位车架号
`LVSHBFAF8AF146084` 粘连）。

### 根因

安诚保单表格被 OCR 成"标签列在前、数据值分行在后"的错位布局：

```
号牌号码
粤BH917R            ← 车牌（完整）
LVSHBFAF8AF146084   ← 车架号
3250811            ← 发动机号
```

`policy_parser._extract_vehicle_info` 中的跨行合并预处理规则
`([A-Z]-?)\s*\n\s*([A-Z0-9])`（用于还原 `粤B-\nCK9833` 这类车牌本身断行的情况）
会把 `粤BH917R` 行尾的 `R` 与下一行车架号行首的 `L` 误合并为
`粤BH917RLVSHBFAF8AF146084`，随后被 `[省份]\S+` 整串吞入车牌字段。

## 代码变更

- `insurance/policy_parser.py`
  - `_extract_vehicle_info` 车牌清理逻辑新增"剥离尾部 17 位车架号"处理：
    合法车牌（含省份汉字）最长 8 字符，若提取结果更长且尾部恰为 17 位字母数字，
    按 `[省份][字母][4~6位] + [17位VIN]` 切分还原车牌，并顺带兜底补充车架号字段。

## 数据库变更

无。

## 部署步骤

无需迁移，重启服务即可。

## 验证

回归测试（正常单行、跨行车牌 `粤B-\nCK9833`、省份跨行 `鄂\nABC123`、
新能源 7 位、安诚错位）全部通过：
- 安诚错位：车牌 `粤BH917R`，车架号 `LVSHBFAF8AF146084` 均正确提取。
