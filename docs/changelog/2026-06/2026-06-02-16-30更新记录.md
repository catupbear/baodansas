# 兼容亚太「家乘无忧2.0」组合产品险种提取

## 需求说明

亚太财产保险「家乘无忧2.0（单交版）」是 **司乘人员意外（驾意险）+ 家庭财产保险（非车险）** 的组合产品。
原解析器对该保单存在两个问题：

1. **险种类型未识别**：`_identify_policy_type` 无对应规则，返回 `None`，险种大类仅靠兜底默认落到「驾意险」，且 `险种类型` 字段为空。
2. **被保险人提取错误**：保单格式为「驾意险被保险人：特定被保险人」+「家财险被保险人：魏吉愉」，合并文本正则误把「家财险」当作被保险人姓名。

## 处理方案

- 险种大类归类：经确认，组合产品按主险（司乘人员意外）归为 **驾意险（accident）**。

## 数据库变更

无。

## 代码变更

### `insurance/policy_parser.py`

1. `_identify_policy_type()`：新增产品名规则 `家乘无忧[\d.]*（…）`，正确捕获 `险种类型 = 家乘无忧2.0（单交版）`。
2. `get_policy_type_code()`：在「家财」规则之前新增 `家乘 / 司乘 → accident（驾意险）` 显式归类，避免组合产品被误归非车险。
3. `_extract_insured_common()`：开头新增高优先级匹配「家财险/财产险被保险人：人名」，优先提取真实人名（魏吉愉），避免被后续合并文本误取为「家财险」。

## 验证结果

| 字段 | 修复前 | 修复后 |
|------|--------|--------|
| 险种类型 | （空） | 家乘无忧2.0（单交版） |
| 险种大类 | accident（兜底） | accident / 驾意险（显式） |
| 被保险人 | 家财险 | 魏吉愉 |
| 保费合计 | 58.00 | 58.00 |

回归测试：家财守护→非车险、驾乘无忧→驾意险、机动车商业保险→商业险、交强险→交强险 均无变化。

## 部署步骤

仅 Python 代码改动，重启服务即可：`python main.py`。
