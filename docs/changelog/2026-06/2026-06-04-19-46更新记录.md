# 备注快捷选择（联动选择器）

## 需求说明

台账记录的「备注」自定义字段，希望按记录的 **经办人 / 投保公司 / 险种** 自动筛出对应的备注话术供快捷点选。话术来源于一张每日重新生成的 Excel 对照表（列：日期/经办人/投保公司/备注信息/险种名称，常含多个时间点 sheet）。

要求：
1. 每日**清空旧选项池、重新导入**。
2. **不影响历史记录已选的备注值**（已选值写在记录字段并计入 `manual_fields`，与选项池两套独立存储）。
3. 交互为**选择器弹窗**：打开时已按本行的经办人/投保公司/险种自动筛好候选，可调整匹配方式（精准/模糊，默认精准）、搜索、选取。

设计/计划文档：
- `docs/superpowers/specs/2026-06-04-备注快捷选择-design.md`
- `docs/superpowers/plans/2026-06-04-备注快捷选择.md`

## 数据库变更

启动时自动建表 / 自动补配置类型，无需手动 DDL。

1. 新表 `insurance_remark_options`（备注快捷选择选项池）：
   - 字段：`scope / scope_id / handler / company / policy_type / remark / batch_no / created_at`
   - 联合索引 `idx_remark_opt_scope (scope, scope_id, handler, company, policy_type)`
   - 按 scope（global/enterprise/user）隔离；导入 = 同事务内 `DELETE` 当前 scope 旧行 + 批量 `INSERT` 新行。
2. `user_field_config` 新增 `config_type='remark_selector'`（`config_key='config'`）存配置：
   - `enabled / target_key / key_handler / key_company / key_policy_type`
   - 按企业/个人 scope 存储，沿用现有 scope 机制。

### 接口说明（前端对接）

- `GET /api/insurance/remark-options/config` → `{config:{...}, stats:{count,last_import}}`
- `PUT /api/insurance/remark-options/config` body `{config:{...}}`
- `POST /api/insurance/remark-options/sheets`（multipart: file）→ `{sheets:[...]}`
- `POST /api/insurance/remark-options/import`（multipart: file, sheet）→ `{count}`
- `GET /api/insurance/remark-options/query?handler=&company=&policy_type=&keyword=&mode=exact|fuzzy` → `{options:[...]}`
- `DELETE /api/insurance/remark-options` → 清空当前 scope

匹配逻辑：mode=exact 三键精确等值（空键不参与过滤）；mode=fuzzy 三键子串包含；keyword 始终按备注子串过滤。

## 部署步骤

1. 拉取代码，重启服务（`python main.py`）—— 启动时自动建表、自动注册配置类型。
2. 进入 `/insurance/settings`「备注快捷选择」卡片：
   - 勾选「启用」；
   - 配置四个字段映射（备注目标字段、经办人字段、投保公司字段、险种字段）——下拉项取自当前「列配置」字段，按实际台账列名选择；
   - 保存配置。
3. 上传当日 Excel → 选择 sheet（默认最后一个时间点）→ 导入；统计条数刷新。
4. 回到 `/insurance` 台账列表，备注单元格出现「选择」按钮，点击弹窗按本行经办人/投保公司/险种筛出候选，点选写回。

## 兼容性

- 纯新增功能：未启用 `remark_selector.enabled` 时台账与原行为完全一致。
- 选项池与记录字段解耦：清空/重导选项池不修改任何记录，满足「不影响历史已选」。
- `target_key` 未配置或不存在时不显示「选择」按钮，不影响其它单元格编辑。

## 待确认默认值（不阻塞，影响默认填充准确性）

- 投保公司在记录里的真实字段名（默认 `承保公司`）—— 设置页可改。
- Excel 投保公司为「东莞平安/佛山平安」等地区分支名，与记录公司字段若对不上可在弹窗切「模糊」匹配。
