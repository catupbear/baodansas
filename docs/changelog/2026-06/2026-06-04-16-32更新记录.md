# 导出 Excel 台账附带「自定义计算公式」

## 需求说明

导出的保单台账此前只写入公式**计算后的静态值**（数字），用户无法在 Excel 中二次编辑联动。
需求：导出时把自定义计算公式（如「合计应付手续费 = 签单保费 × 应付费率」）以 **Excel 活公式**
（如 `=K2*M2`）的形式写入单元格，改动保费/费率后 Excel 自动重算。

约束：
- 只导出「计算公式」（引用了其他字段的公式）。**纯固定值公式**（如设为 `0`、`500` 的常量）
  仍写静态值，不转活公式。
- 活公式引用的「费率列」（如应付费率）必须是真正的百分比数字（单元格存 `0.2`、显示 `20.0%`），
  公式才能正确计算；引用的「金额列」（保费、车船税等）写成数字单元格。

## 数据库变更

无。

## 代码变更

### 1. `insurance/field_config_db.py`

- 新增 `match_fee_formulas(config, fields)`：抽出公式「按公司/险种匹配当前记录」的逻辑，
  返回 `[(目标字段, 公式, is_computed), ...]`。`is_computed` 区分「计算公式」与「常量公式」。
  导出（生成活公式）与 `apply_user_config_to_fields` 共用，避免匹配逻辑重复/漂移。
- `apply_user_config_to_fields` 改为调用 `match_fee_formulas`，行为保持不变（已回归验证）。

### 2. `insurance/api.py`

- 新增三个模块级辅助函数：
  - `_formula_to_excel(formula_display, col_letter_map, row_num)`：把「按字段名引用」的公式
    转成 Excel 单元格引用公式（如 `保费 × 应付费率` → `=K2*M2`）。引用到**未导出的列**时返回
    `None`，调用方回退静态值。
  - `_percent_text_to_decimal("20.0%")` → `0.2`。
  - `_pure_number("2811")` → `2811`（纯数字字符串转 int/float）。
- `export_excel`（成功类型导出）中新增活公式处理：
  - 构建 `col_letter_map`（字段 → 列字母）与 `formula_referenced_cols`（公式引用到的金额列）。
  - 新增内部函数 `_postprocess_row(row_idx, src_fields)`，在每行写入后做三类单元格修正：
    1. 公式目标列 → 写 Excel 活公式（`number_format="0.00"`），失败回退静态值；
    2. 费率列（值形如 `20.0%`）→ 转小数 + 百分比格式（`number_format="0.0%"`）；
    3. 公式引用到的金额列 → 转数字。
  - 普通导出与按车牌合并导出两条写入路径均接入。合并模式行内无险种，多数险种相关公式不匹配，
    自动回退为静态值（费率列仍转百分比数字）。

## 兼容性

- 常量/固定值公式（不引用其他字段）维持原静态值导出，不受影响。
- 公式引用到未勾选导出的列时，自动回退为静态值，不会产生错误公式。
- 「识别记录导出」（`config_applied=true`）与「本次识别结果导出」两条前端路径均生效，无需前端改动。

## 部署步骤

1. 更新 `insurance/api.py`、`insurance/field_config_db.py`。
2. 重启服务：`python main.py`。
3. 无数据库变更，无需迁移。

## 验证

- 单元验证：`合计应付手续费 = 保费 × 应付费率`，商业险（保费 2811、费率 0.2）导出
  `=K2*M2` 即 2811×0.2=562.2；驾意险（保费 550、费率 0.1）→ 55，与静态计算一致。
- 费率列 `20.0%` → 单元格存 `0.2` 且显示 `20.0%`。
- openpyxl 写入/重读校验：公式单元格 `data_type='f'`，文件有效。
