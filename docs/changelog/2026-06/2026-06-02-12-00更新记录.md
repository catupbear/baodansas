# 修复按车牌合并导出时商业险保费/交强险保费为空

## 需求说明

用户反馈：开启「按车牌合并导出」后，导出的 Excel 中「商业险保费」「交强险保费」两列没有数据，保费全部丢失或落到了「非车险保费」列。

## 问题原因

合并导出时，差异字段（如保费）需要按险种拆分到对应前缀列（商业险保费 / 交强险保费 / 非车险保费），拆分依据是 `get_policy_type_code(险种)` 的分类结果。

但导出请求带 `config_applied=True`，数据已在列表 API 中完成别名替换，`险种` 字段此时是**简称**（如「商业险」「交强险」），而 `get_policy_type_code()` 只识别**全称**（如「商业保险」「机动车交通事故责任强制保险」）：

- `get_policy_type_code("商业险")` → 不含「商业保险」→ 落到默认分支 `accident`
- `get_policy_type_code("交强险")` → 不含「交通事故责任强制」→ 落到默认分支 `accident`

`accident` 对应前缀「非车险」，导致保费被写入「非车险保费」列，而「商业险保费」「交强险保费」为空。

## 代码变更

`insurance/policy_parser.py` — `get_policy_type_code()`

在原全称匹配之前，新增险种简称识别：

- 含「交强」→ `compulsory`（交强险）
- 含「商业险」或「商业」→ `commercial`（商业险）
- 含「驾意」→ `accident`（驾乘/意外险）

全称匹配逻辑保留在后，行为不变；货运、责任险等非车险分类不受影响。

## 数据库变更

无。

## 部署步骤

1. 拉取最新代码
2. 重启服务 `python main.py`
3. 验证：开启按车牌合并导出，确认「商业险保费」「交强险保费」列正常输出
