# 2026-06-05 更新记录

## 需求说明

1. **文件名预览按钮**：保单识别「自动识别记录」列表的文件名一直是可点击预览的，但没有任何可视提示，客户不知道能点。在文件名后增加一个带眼睛图标的「预览」按钮，让客户一眼看出可点击预览。
2. **字段数据来源说明**：「保司（带地区）」是系统自动拼接生成的字段，普通用户容易困惑。在「列表」「列表列配置」「导出列配置」三处的该字段后增加一个「?」图标，鼠标悬停即可查看通俗说明。

## 数据库变更

无。

## 代码变更

### `web/templates/insurance.html`
- 「自动识别记录」表格「文件名」列：有 `cos_url` 时，文件名后新增带眼睛图标的「预览」按钮，点击触发 `previewRecord(record)`（与文件名点击同一行为）。
- 列表表头：字段名后渲染 `.field-help-icon`（「?」图标），通过 `:title` 显示数据来源说明。
- 新增 `fieldHelp` 响应式映射（字段名 → 通俗说明），并在 setup 返回值中暴露。
- 新增 `.field-help-icon` 样式。

### `web/templates/field_config.html`
- 「列表列配置」「导出列配置」两个表格的字段名（`col.key`）后，新增 `.field-help-icon`（「?」图标）。
- 新增同一份 `fieldHelp` 映射并在 setup 返回值中暴露。
- 新增 `.field-help-icon` 样式。

> 说明文案（「保司（带地区）」）：系统自动生成，从保单识别承保公司并从保司地址提取城市，拼成"城市+保司"（如"深圳平安"）；无地址时只显示保司名称；设置了保司简称则用简称替换。
>
> 后续如需为更多字段补充说明，只需在两个文件的 `fieldHelp` 中按字段名增加条目即可（字段名需与列配置 `key` 完全一致）。

## 部署步骤

纯前端模板改动，重启服务或刷新页面即可生效，无需数据库迁移。
