# 保单识别列表：超级管理员软删除记录（带确认弹窗）

## 需求说明

在保单识别记录列表的「操作」列，为**超级管理员**增加「删除」按钮，点击后弹出**确认弹窗**，确认后删除该条记录。删除采用**软删除**（打标记，不物理删除，可后台恢复），删除后列表与统计不再展示该记录。

## 数据库变更

`insurance_records` 表新增列（启动时幂等迁移自动添加）：

| 列名 | 类型 | 说明 |
|------|------|------|
| `deleted_at` | DATETIME DEFAULT NULL | 软删除时间，非 NULL 表示已删除 |

## 代码变更

### 后端

- `insurance/db.py`
  - 迁移 `new_columns` 新增 `deleted_at` 列。
  - 新增 `soft_delete_record(db, record_id)`：`UPDATE ... SET deleted_at=NOW() WHERE id=%s AND deleted_at IS NULL`，返回是否成功（幂等）。
  - 列表/统计/下拉/去重检测统一过滤软删除记录：
    - `query_insurance_records`：`conditions` 增加 `r.deleted_at IS NULL`
    - `get_insurance_stats`：`where_parts` 增加 `deleted_at IS NULL`
    - `get_company_stats`：WHERE 增加 `deleted_at IS NULL`
    - `get_record_company_list`：conditions 增加 `deleted_at IS NULL`
    - `check_file_md5_exists`：增加 `deleted_at IS NULL`（软删后允许同一文件重新识别）
- `insurance/api.py`
  - 新增路由 `DELETE /api/insurance/records/<int:record_id>`：仅 `ROLE_SUPER_ADMIN` 可调用（非超管返回 403），调用 `soft_delete_record`，记录操作日志。
  - 从 `.db` 导入 `soft_delete_record`。

### 前端

- `web/templates/insurance.html`
  - 操作列新增「删除」按钮，`v-if="isSuperAdmin"`（仅超管可见，红色样式）。
  - 新增「删除确认弹窗」（展示文件名 + 软删除提示，取消/确认删除）。
  - 新增 `deleteRecordVisible/deleteRecordTarget/deleteRecordSaving` 状态及 `openDeleteRecord/confirmDeleteRecord` 方法；确认后调用 DELETE 接口，成功则刷新列表与统计。
  - 在 setup `return` 中注册上述标识符。

## 权限

- 仅超级管理员（`role === 'super_admin'`）可见按钮、可调用接口；后端二次校验，防止越权。

## 验证

- 真实库验证：`soft_delete_record` 对 3 条记录返回 True，重复删除返回 False；过滤查询后不可见；记录物理仍在且带 `deleted_at` 时间戳（可恢复）。
- 顺带清理了被误拆的「粤BB33720-非车.pdf」3 条记录（id 5073/5074/5075，已软删除）。

## 部署步骤

1. 重启服务：`python main.py`（启动时自动幂等添加 `deleted_at` 列）。
2. 超级管理员在列表「操作」列即可看到「删除」按钮。
