# 2026-06-01 自定义冻结列功能

## 需求说明

保单列表表格支持用户自定义冻结列（类似 Excel 冻结窗口），冻结的列固定在表格左侧，水平滚动时始终可见。支持冻结多列，按用户账号独立配置。

## 数据库变更

无。冻结配置存储在现有 `user_field_config` 表的 `config_value` JSON 中，新增 `frozen` 布尔字段。

## 代码变更

### insurance/field_config_db.py
- `DEFAULT_COLUMNS` 中「文件名」字段新增 `"frozen": True` 默认值
- 已有用户配置通过 `_fix_missing_defaults` 自动兼容（无 frozen 字段视为 false）

### web/templates/insurance.html
- 移除硬编码的 `sticky-col-name` CSS 类
- 新增 `frozen-col` / `frozen-col-last` CSS 类，支持动态冻结列
- 新增 `frozenColStyles` 计算属性，根据冻结列数量动态计算 `left` 偏移
- `visibleListColumns` 计算属性透传 `frozen` 字段
- 表头和数据行均通过 `:class` 和 `:style` 动态绑定冻结样式

### web/templates/field_config.html
- 页面列配置表格新增「冻结」列（checkbox）
- 列头预览区显示冻结列数量和冻结标记（📌）
- 底部提示文字说明冻结列规则

## 部署步骤

1. 更新代码，无需数据库迁移
2. 已有用户的列配置不受影响（frozen 默认为 false）
3. 新用户默认冻结「文件名」列
