# 自定义字段支持「百分比」显式标记

## 需求说明

此前系统判断一个字段是否按百分比处理，靠的是隐式启发式：**字段名包含「率」且该字段本身是某条公式的计算目标**。
这导致用户**手填、被公式引用**的费率字段（如"费率"列）无法被识别为百分比——填 `10` 会被当字面值 10 直接相乘
（`应付手续费 = 保费 × 费率 = 665 × 10 = 6650`），而用户本意是 10%（应为 `665 × 0.1 = 66.5`）。

需求：给自定义字段增加一个**显式「百分比」开关**。勾选后：
- 用户填的数字按百分数解释（填 `10` 即 10%）
- 公式计算时按 `0.1` 参与
- 列表/导出显示为 `10%`
- 导出 Excel 时该列写成小数 `0.1` + 百分比格式，活公式 `=保费*费率` 计算正确

## 约定

**百分比列里用户填的数字就是百分数**：填 `10` = 10%，填 `0` = 0%，填 `150` = 150%。
（不是填小数 0.1。已带 `%` 的值如 `10%` 也兼容，同样还原为 0.1，保证幂等。）

## 数据库变更

无。`is_percent` 作为列对象的一个属性，存进既有 `user_field_config` 表的列配置 JSON
（`save_column_config` 只清理 `_` 前缀的临时键，其余键原样持久化）。

## 代码变更

### 1. `insurance/field_config_db.py`

- 新增 `get_percent_fields(db, user_id, role, parent_id)`：读取**导出列配置**（export_columns）中
  `is_percent=True` 的自定义字段 key 集合。
- `get_effective_config` 末尾注入 `config["percent_fields"]`（仿照已有的 `plate_format_pingan` 注入），
  使 `apply_user_config_to_fields` 的 4 处调用点自动获得该集合，**无需改动调用点**。
- `apply_user_config_to_fields` 内：
  - **公式计算前**（步骤 3.5）：把 `percent_fields` 中的字段由百分数还原为小数（`10 → 0.1`），供公式按 0.1 计算。
  - **显示阶段**：单独一个循环把 `percent_fields` 统一 `×100` 转回 `10%` 显示——**不复用** `rate_fields`
    的 `abs(val)<1` 启发式，避免 `≥100%`（如 1.5）被误判。带 `%` 的值 `float()` 失败时原样保留，与
    `rate_fields` 不冲突且幂等。

### 2. `web/templates/field_config.html`（页面列配置 + 导出列配置 两个 tab）

- **两个 tab** 的表头都新增「百分比」列，自定义字段新增勾选框 `v-model="col.is_percent"`（带悬浮说明）。
- `addCustomCol` 新建列对象默认带 `is_percent: false`。
- `syncCustomFields` 新增「百分比」标记的两侧同步：以当前保存的这一侧为准，把 `is_percent` 同步到另一侧
  的同名自定义字段（保存任一 tab 时，两侧列配置都会写入一致的标记）。
- `syncListToExport`（「同步页面列配置到导出列配置」按钮）重建导出列时，保留 `is_percent`（取页面侧或导出侧已设置的值）。
- 保存沿用既有「保存」按钮 → `saveColumnConfig`（`...col` 展开已包含 `is_percent`，且会同时回写另一侧）。

> 说明：列表显示本身只依赖后端注入的 `percent_fields`，即使只在导出 tab 勾选也已生效；页面列配置 tab
> 加勾选框 + 两侧同步纯粹是为交互一致（在哪个 tab 都能看到/改）。后端 `get_percent_fields` 取两侧并集，
> 任一侧勾上即生效。

### 3. 导出（`insurance/api.py`）

无需改动。`apply_user_config_to_fields` 输出 `费率="10%"` 后，上一版已实现的 `_postprocess_row` 会自动把
`10% → 0.1` 写成百分比格式单元格，活公式 `=B2*C2`（C2=0.1）即 `保费 × 0.1`，结果正确。

## 兼容性

- 既有靠「率」字判断的字段（佣金率、采购费率等，按**小数存储**约定）逻辑保持不变，不受影响。
- `is_percent` 是**附加**机制，仅对勾选了的自定义字段生效；未勾选字段行为完全不变。
- DB 始终存用户填写的原始值（如 `10`），`apply` 每次请求从原始值重新归一化，幂等、无需数据迁移。

## 部署步骤

1. 更新 `insurance/field_config_db.py`、`web/templates/field_config.html`。
2. 重启服务：`python main.py`。
3. 在「字段配置 → 页面列配置 或 导出列配置」中给目标自定义字段（如"费率"）勾选「百分比」并保存（两侧自动同步）。
4. 无数据库变更。

## 验证

- 费率填 `10`：显示 `10%`，`应付手续费 = 保费 × 费率 = 665 × 0.1 = 66.50`；导出活公式 `=B2*C2`（C2=0.1，百分比格式）。
- 费率填 `0`：显示 `0%`，应付手续费 `0`。
- 费率填 `150`：显示 `150%`，`1000 × 1.5 = 1500`（验证 ≥100% 不被误判）。
- 幂等：对已处理结果再次 `apply`，`10%` / `66.50` 保持不变。
