# 兼容华泰驾乘险保费和保险期间提取

## 需求说明
华泰财险"百万驾乘"意外伤害保险保单的保费和保险期间格式与现有规则不匹配，需新增兼容。

## 代码变更

### `insurance/policy_parser.py`
1. **保费提取**：新增华泰驾乘险格式 `保险费 人民币（大写）贰佰元整 （小写）¥200.00`，支持"（小写）¥金额"模式
2. **保险期间提取**：新增华泰驾乘险格式 `自...日00:00:时起（北京时间）至...日24:00:时止（北京时间）`，支持起止日期间包含"（北京时间）"等注释文字
3. 更新华泰特殊说明注释

## 数据库变更
无

## 部署步骤
重启服务即可
