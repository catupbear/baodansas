# 2026-05-28 导出列配置与页面列配置双向自动同步

## 需求说明

导出列配置新增的自定义字段需要自动同步到页面列配置，页面列配置新增或删除也需要同步到导出列配置。实现双向自动同步，减少手动操作。

## 代码变更

### `web/templates/field_config.html`

1. **`addCustomCol()` 函数** — 导出列添加自定义字段时，自动同步到页面列（原来只有页面列→导出列的单向同步）
2. **`removeCustomCol()` 函数** — 删除自定义字段时，自动从另一侧删除同名自定义字段
3. **新增 `syncCustomFields()` 函数** — 保存时对比两侧自定义字段，自动补齐缺失、清理已删除的字段
4. **`saveColumnConfig()` 函数** — 保存一侧配置后，自动同步自定义字段并保存另一侧配置

## 同步规则

- 添加自定义字段：双向自动添加
- 删除自定义字段：双向自动删除（合并字段不受影响）
- 保存配置：自动同步自定义字段到另一侧并一起保存
- 合并字段（merge）只存在于导出列，不参与双向同步删除

## 部署步骤

无数据库变更，前端文件更新后刷新页面即可。
