# 2026-05-19 员工账号绑定发送人功能

## 需求说明
在用户管理中为员工账号绑定企业微信发送人（sender），使该发送人的所有保单记录自动归属到对应员工账号。

## 数据库变更
- 新增 `user_sender_binding` 表，记录用户与企业微信发送人的绑定关系
  - `user_id` → users.id
  - `sender` 企业微信发送人ID
  - `sender_name` 发送人显示名
  - `enterprise_id` 企业ID
  - UNIQUE KEY (sender, enterprise_id)

## 代码变更

### auth/db.py
- 新增 `init_sender_binding_table()` 建表函数
- 新增 `get_bindings_by_user()` 查询用户绑定
- 新增 `get_binding_by_sender()` 按 sender 查绑定用户
- 新增 `set_user_bindings()` 全量设置用户绑定（先删后插）
- 新增 `list_all_bindings()` 列出所有绑定记录

### auth/api.py
- `init_auth_api()` 新增 `insurance_db` 参数（默认与 db 共享）
- `GET /api/auth/users` 返回每个用户的 `bound_senders` 信息
- `POST /api/auth/users` 支持 `bound_senders` 参数，创建用户时绑定+回填
- `PUT /api/auth/users/<id>` 支持 `bound_senders` 参数，更新绑定+回填
- 新增 `GET /api/auth/senders` 从 insurance_records 去重取发送人列表
- 新增 `_backfill_records_by_senders()` 回填历史保单记录

### insurance/handler.py
- `_process()` 方法中获取 config_user_id 后，增加按 sender 绑定关系自动匹配用户

### main.py
- 启动时调用 `init_sender_binding_table(db)` 初始化表

### web/templates/admin_users.html
- 用户列表新增"绑定发送人"列，展示蓝色标签
- 编辑/创建弹窗新增"绑定发送人"区域（标签+下拉选择）
- 下拉显示格式：发送人名称 (N条记录)

## 部署步骤
1. 部署代码后重启服务，`user_sender_binding` 表会自动创建
2. 无需手动执行 SQL
