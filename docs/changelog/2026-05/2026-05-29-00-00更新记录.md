# 2026-05-29 00:00 更新记录

## 需求说明

兼容紫金财产保险的保司公司名称、保司地址和联系电话提取。紫金保险的 OCR 文本存在"标签与值分行"的特殊格式，导致原有正则无法正确匹配。

## 问题分析

紫金保险 OCR 文本中，"公司名称："标签插在公司名的中间位置：
```
紫金财产保险股份有限公司深圳分公司龙岗支
公司名称：
公司
```
实际公司名应为"紫金财产保险股份有限公司深圳分公司龙岗支公司"。

同样，"公司地址："和"联系电话："标签也与值分离在不同行。

## 代码变更

### 1. insurance/policy_parser.py
- `_extract_insurer_info()` 新增紫金等格式兼容：
  - 公司名称：标签后无有效值时，向上查找含保险公司名的行并拼接下方残余
  - 公司地址：标准正则失败时，从标签上下方拼接地址
  - 联系电话：新增"保司联系电话"字段提取

### 2. insurance/field_mapping.py
- `OUTPUT_COLUMNS` 和 `DEFAULT_MAPPING` 新增"保司联系电话"

### 3. insurance/db.py
- 映射、建表、迁移均新增 `insurer_phone` 列

### 4. web/templates/insurance.html
- 前端默认列配置新增"保司联系电话"

## 数据库变更

- `insurance_policy_fields` 表新增列：`insurer_phone VARCHAR(32) DEFAULT ''`
- 迁移幂等，重启自动执行
