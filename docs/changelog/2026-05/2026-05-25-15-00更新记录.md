# 2026-05-25 15:00 更新记录

## 需求说明
1. 修复雇主责任保险保单的两个识别问题：险种无法识别、文档类型被误判为"投保单"
2. 修复投保单文档类型误判：含强保单标记（保险单号/电子保单/保单号）的正式保单不再被误判
3. 修复永安驾乘险投保人提取失败（"投保人信息"表格标题未被识别）
4. 修复永安保费提取失败（"保险费（人民币：元）...￥336.00" 格式未匹配）

## 代码变更

### insurance/policy_parser.py
1. `_identify_policy_type()`：新增雇主责任保险匹配规则
2. `get_policy_type_code()`：新增"雇主"→非车险类型映射
3. `_identify_doc_category()`：将 `_has_strong_policy_markers` 提升为投保单判断的首要排除条件，从根本上避免正式保单被误判为投保单；新增"由投保单"排除
4. `_extract_proposer()`：表格投保人区域标题匹配新增 `'投保人信息'`（原仅匹配 `'投保人'`），修复永安等格式
5. `_extract_premium()`：新增永安保费格式 `保险费（人民币：元）...￥XXX.XX`

## 部署步骤
1. 更新代码：`git pull`
2. 重启服务：`python main.py`
