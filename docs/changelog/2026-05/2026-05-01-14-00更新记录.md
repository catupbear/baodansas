# 2026-05-01 保险报价模块

## 需求说明

新增保险报价模块（quote/），独立于现有保单识别模块。监控企业微信群中的图片和文本消息，自动识别行驶证/身份证，配对后提交保险预报价接口。

核心功能：
- 通过外部接口（wechat-bindings/all）获取监控绑定列表，1分钟缓存
- 监控群内图片消息，百度 OCR 同时尝试行驶证和身份证识别
- 按 (group_id, sender) + 姓名维度管理多套证件配对
- 身份证反面就近归入有正面但无反面的套
- 文本消息通过已识别的姓名/车牌匹配关联（清洗特殊字符后匹配）
- 证件齐全立即提交，否则1分钟超时自动提交 pre-quote 接口
- 图片上传 COS，路径为 quote/{group_id}/{sender_id}/{timestamp}.jpg

## 数据库变更

无。配对数据纯内存管理，提交后丢弃。

## 代码变更

### 新增文件
| 文件 | 说明 |
|------|------|
| `quote/__init__.py` | 模块入口 |
| `quote/binding.py` | BindingService - 绑定关系查询+缓存 |
| `quote/ocr.py` | QuoteOCR - 百度行驶证/身份证 OCR |
| `quote/matcher.py` | QuoteMatcher - 多套证件配对+超时提交 |
| `quote/handler.py` | QuoteHandler - 队列消费主处理逻辑 |

### 修改文件
| 文件 | 说明 |
|------|------|
| `core/fetcher.py` | 新增 `_check_quote_trigger` 方法，监听 image/text 消息 |
| `main.py` | 初始化 QuoteHandler 并绑定到 fetcher |

### 外部接口依赖
- `GET https://riskapi.wuhuxiche.com/insurance/wechat-bindings/all` — 获取监控绑定列表
- `POST https://riskapi.wuhuxiche.com/insurance/pre-quote` — 提交预报价
- 百度 OCR 行驶证识别 API
- 百度 OCR 身份证识别 API

## 部署步骤

1. 拉取最新代码
2. 确保 `config.yaml` 中已配置 `baidu_ocr`（api_key, secret_key）
3. 重启服务即可，无需额外配置
