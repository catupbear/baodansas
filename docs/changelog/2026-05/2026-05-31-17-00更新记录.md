# 2026-05-31 17:00 更新记录

## 需求说明

1. **修复企业模板新增字段被取消勾选的问题**：之前的修复（新增字段在已有模板中默认不勾选）误伤了企业模板，企业管理员主动勾选的字段也被强制取消
2. **车架号和身份证号码加入互补逻辑**：同一辆车的多条保单之间，车架号和身份证号码未做互补，导致部分记录缺失
3. **非合并模式支持导出"交强到期时间"列**：客户需要在不合并车牌时，每一行都能看到该车的交强险到期时间

## 代码变更

### 1. 修复企业模板字段被覆盖（field_config_db.py）
- `_fix_missing_defaults()` 中的一次性修复逻辑增加 `scope == "user"` 条件，仅对个人模板执行，不影响企业/全局模板

### 2. 互补逻辑新增字段（handler.py）
- `SAME_PDF_FILL_FIELDS`：新增 `被保险人身份证号码`、`投保人身份证号码`
- `CROSS_FILL_FIELDS`：新增 `车架号VIN`、`被保险人身份证号码`、`投保人身份证号码`
- `PERSON_FILL_FIELDS`：新增 `车架号VIN`、`被保险人身份证号码`、`投保人身份证号码`
- 新增 `_PERSON_VALIDATE_FIELDS` 集合，区分人名字段和非人名字段的验证逻辑

### 3. 交强到期时间功能（5个文件）
- `insurance/field_mapping.py`：`OUTPUT_COLUMNS` 新增 `交强到期时间`
- `insurance/config/field_mapping.json`：`output_columns` 新增
- `insurance/field_config_db.py`：`DEFAULT_COLUMNS` 新增字段（默认不显示）
- `insurance/db.py`：新增 `find_compulsory_end_dates()` 批量查询交强险终保日期
- `insurance/api.py`：列表和导出两处注入交强到期时间（从同车牌交强险记录取终保日期）

## 部署步骤

1. 拉取最新代码
2. 重启服务即可，无数据库变更
3. 用户需在列配置中手动勾选"交强到期时间"字段才会显示/导出
