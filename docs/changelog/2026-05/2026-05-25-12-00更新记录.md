# 2026-05-25 更新记录

## 需求说明

1. 修复多企业（午虎科技等）保单识别和报价下载失败（错误码 10002）
2. 补扫历史保单支持重试失败记录
3. 重新识别支持 SDK 重新下载过期文件
4. 修复补扫弹窗 checkbox 样式异常

## 代码变更

### 多企业 SDK 下载修复
- `core/fetcher.py` — 所有 enqueue 调用（保单触发、保单补扫、报价触发、报价补扫）传入当前 fetcher 的 `finance_sdk` 和 `sdk_config`
- `insurance/handler.py` — `_download_media()` 优先使用消息携带的 SDK，fallback 到默认 SDK
- `quote/handler.py` — `_process_image()` 优先使用消息携带的 SDK
- `main.py` — 启动时打印各企业 SDK id，方便日志对照

### 补扫支持失败记录重试
- `core/fetcher.py` — `rescan_missed_insurance()` 的 LEFT JOIN 条件改为 `ir.status NOT IN ('failed')`，失败记录不再被排除
- `insurance/api.py` — 补扫 API 遍历所有企业 fetcher（主+额外），各企业使用各自 SDK

### 重新识别支持 SDK 下载
- `insurance/api.py` — `reocr_record()` 无 COS URL 时通过 `_try_sdk_download()` 尝试 SDK 重新下载；下载成功自动上传 COS；下载失败返回 `need_resend: true` 提示用户重新发送文件
- `insurance/api.py` — 新增 `_try_sdk_download()` 辅助函数，根据消息 corpid 查找正确的企业 SDK

### 前端修复
- `web/templates/insurance.html` — 所有失败记录统一显示"重新识别"按钮（不再区分有无 COS URL）
- `web/templates/insurance.html` — `need_resend` 时显示醒目提示"文件已过期，请重新发送"
- `web/templates/index.html` — 修复补扫弹窗 checkbox 尺寸过大的样式问题
