# 2026-05-28 23:00 更新记录

## 需求说明
1. 修复众诚交强险保单中"投保人"字段被误提取为"众诚官微"的问题
2. 所有保单新增提取"保司公司名称"和"保司地址"两个字段（从保单底部"保险人"信息区域提取）

## 数据库变更
- `insurance_policy_fields` 表新增两列：
  - `insurer_name VARCHAR(500)` — 保司公司名称
  - `insurer_address VARCHAR(500)` — 保司地址
- 已有表自动迁移（ALTER TABLE ADD COLUMN，幂等）

## 代码变更
- `insurance/policy_parser.py`：
  - `_is_valid_person()` 人名黑名单正则增加 `官微|官网`，防止微信公众号标签文字被误识别为人名
  - 新增 `_extract_insurer_info()` 函数，提取"公司名称"和"公司地址"字段
  - `_extract_common_fields()` 末尾调用新函数
- `insurance/db.py`：
  - `_OCR_TO_COLUMN` 新增 `保司公司名称→insurer_name`、`保司地址→insurer_address` 映射
  - 建表语句和迁移脚本新增两列
- `insurance/field_mapping.py`：
  - `OUTPUT_COLUMNS` 新增"保司公司名称"、"保司地址"
  - `DEFAULT_MAPPING` 新增对应映射
- `insurance/field_config_db.py`：
  - `DEFAULT_COLUMNS` 新增两列定义（order 21/22），已有用户配置会自动补充
