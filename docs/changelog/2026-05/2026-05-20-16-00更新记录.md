# 2026-05-20 企业级列配置

## 需求说明

Excel 导出列和页面列表列的显示/顺序/名称支持按企业配置，配置后企业内所有人生效。
- 页面列配置（list_columns）：控制保单列表页显示哪些列、列顺序、列名
- 导出列配置（export_columns）：控制 Excel 导出包含哪些列、列顺序、列头名称
- 两套配置独立，互不影响

## 数据库变更

无新建表。复用现有 `user_field_config` 表，新增两个 `config_type`：
- `list_columns` — 页面列配置
- `export_columns` — 导出列配置

每种配置存为一条记录，`config_key = 'columns'`，`config_value` 为 JSON 数组。

## 代码变更

### 后端
- `insurance/field_config_db.py`
  - 扩展 `CONFIG_TYPES` 新增 `list_columns`、`export_columns`
  - 新增 `DEFAULT_COLUMNS` 常量（19 列默认配置）
  - 新增 `get_column_config()` — 按优先级查找列配置（user → enterprise → global → 默认）
  - 新增 `save_column_config()` — 保存列配置
  - 新增 `delete_column_config()` — 删除列配置（恢复默认）

- `insurance/api.py`
  - 新增 `GET /api/insurance/column-config` — 获取列配置
  - 新增 `POST /api/insurance/column-config` — 保存列配置
  - 新增 `DELETE /api/insurance/column-config` — 重置列配置
  - 修改 `list_records` — 响应中返回 `column_config`
  - 修改 `export_excel` — 支持从列配置读取导出列和列头名称
  - 修改 `batch_sync_dingtalk` — 支持从列配置读取字段列表

### 前端
- `web/templates/field_config.html`
  - 新增「页面列配置」tab：可开关列可见性、上下调整顺序、修改显示名称
  - 新增「导出列配置」tab：同上，用于 Excel 导出配置

- `web/templates/insurance.html`
  - 列表表头和数据渲染改为动态列（`visibleListColumns` computed）
  - 从 `list_records` 响应中读取列配置

## 部署步骤

无特殊步骤，正常部署即可。无数据库迁移。

## 兼容性

- 前端导出仍可传 `field_names` 参数，后端优先使用（兼容旧逻辑）
- 未配置列时使用代码内默认 19 列（与原来一致）
