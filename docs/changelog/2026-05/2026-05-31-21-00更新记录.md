# 2026-05-31 21:00 更新记录

## 需求说明

修复"保司（带地区）"字段在保司地址为空时显示为空的问题。

**原逻辑**：必须同时有"保司地址"和"承保公司"两个字段才会生成"保司（带地区）"。
**新逻辑**：只要有"承保公司"就生成该字段。有地址时提取城市前缀拼接公司名（如"深圳平安"），无地址时直接显示公司名（如"平安"）。

## 代码变更

| 文件 | 改动说明 |
|------|----------|
| `insurance/policy_parser.py` | `_build_insurer_with_region()` 函数：去掉 address 为空时直接 return 的逻辑，无地址时直接用公司名 |
| `insurance/field_mapping.py` | `apply_mapping()` 兼容历史记录计算：同步修改，无地址时用承保公司 |
| `insurance/api.py` | 查询接口兼容历史记录：同步修改，无地址时用承保公司 |
| `insurance/field_config_db.py` | 简称替换逻辑：修复无地址时简称不生效的问题 |

## 数据库变更

无

## 部署步骤

1. 更新代码并重启服务即可
2. 历史数据无需迁移，查询时会实时计算补齐
