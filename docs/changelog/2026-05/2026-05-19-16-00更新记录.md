# 2026-05-19 监控配置增加"关联企业"功能

## 需求说明

监控配置页面新增"关联企业"下拉选项，支持直接绑定企业（无需选择具体账号），使该企业下的管理员和员工可查看对应保单记录。

## 数据库变更

无（`monitor_configs` 表已有 `enterprise_id` 列）。

## 代码变更

### 前端
- `web/templates/monitor_config.html`
  - 表单新增"绑定企业"下拉（从 `/api/auth/enterprises` 加载企业列表）
  - 卡片列表新增"关联企业"展示行
  - 选择企业后，绑定账号下拉自动过滤为该企业下的账号
  - 切换企业时，若当前绑定账号不属于新企业则自动清空

### 后端
- `insurance/api.py`
  - 创建/更新监控配置 API 支持 `bind_enterprise_id` 字段
  - 企业绑定优先级：前端直接传入的 `bind_enterprise_id` > 从绑定账号推导的 `parent_id`
  - 企业变更时也触发历史记录回填

## 部署步骤

1. 更新代码并重启服务即可，无需数据库迁移
