# 2026-05-20 车主字段 + 按车牌合并导出

## 需求说明

### 1. 车主字段加入导出
保单 OCR 已有车主提取能力，本次将车主字段加入导出列映射和默认列配置，使其出现在页面列表和 Excel 导出中。

### 2. 按车牌合并导出
导出 Excel 时支持按车牌合并，同车牌的多条保单（交强险/商业险/非车险）合并为一行：
- **共享字段**（不拆分）：承保公司、车牌、投保人、被保人、车主、业务员、跟单人、出单渠道
- **差异字段**（按险种拆分为 3 列）：保单号、保费、签单日期、起保日期、终保日期、佣金率、佣金、采购费率、公司利润、跟单人利润
- **特殊字段**：车船税不拆分，险种不保留

### 开关机制
- 系统设置页「导出列配置」tab：顶部「按车牌合并导出」开关 + 「补充合并字段」按钮
- 导出弹窗：继承设置页默认值，可临时切换

## 数据库变更

无新建表。复用 `user_field_config` 表，合并开关存储为：
- `config_type = 'export_columns'`，`config_key = 'merge_by_plate'`，`config_value = '1'/'0'`

### 前端
- `web/templates/field_config.html` — 导出列配置 tab 新增合并开关和补充合并字段按钮

## 部署步骤

无特殊步骤，正常部署即可。无数据库迁移。

## API 文档

### 获取合并开关
```
GET /api/insurance/merge-config
→ {"code": 0, "data": {"enabled": true/false}}
```

### 保存合并开关
```
POST /api/insurance/merge-config
Body: {"enabled": true/false}
→ {"code": 0, "msg": "已保存"}
```

### 导出 Excel（合并模式）
```
POST /api/insurance/export/excel
Body: {..., "merge_by_plate": true}
```
