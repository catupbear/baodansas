# 2026-05-22 15:00 更新记录

## 需求说明

1. 修复国寿人身意外伤害保险（特定场景B）投保人和被保险人提取失败
2. 业务员提取兼容"业务人员：xxx"格式
3. 新增永安财产保险股份有限公司保单识别支持

## 代码变更

### insurance/policy_parser.py

**国寿人意险被保人/投保人修复：**
- `_extract_insured_guoshou()`：新增优先逻辑，先定位"被保险人"标记位置，在其之后搜索"名称/姓名 + 中文名"，避免误取投保人区域同名字段
- `_extract_proposer()`：新增国寿财产专用逻辑，在投保人区域（被保险人标记之前）查找"名称/姓名"字段
- 原因：国寿人意险表格中"名称/姓名 曹桂举"后跟"性别"等中文字段，原正则要求后跟数字或行尾导致匹配失败

**业务员格式兼容：**
- 业务员提取正则从 `业务员[姓名称]*` 改为 `业务(?:人员|员[姓名称]*)`，兼容"业务人员：辛云兵"格式

**新增永安财产保险识别：**
- `COMPANY_FALLBACK_SIGNALS`：添加 95502/yaic.com/永安保险/永安财产 特征
- 保单号前缀映射：添加 `^3440` → 永安财产保险
- `_extract_insured()`：新增永安商业险被保人提取（处理 OCR 格式"姓名\n王劲辉\n被保\n...险人"）
