# 2026-05-28 20:00 更新记录

## 需求说明

超管可以查看系统中所有账号（企业、员工）的模板配置，并进行代管编辑。

### 功能点
- 超管在模板下拉菜单中看到按 scope 分组的所有模板（全局/企业/员工）
- 点击其他账号的模板进入"代管模式"，可直接编辑并保存到对方配置
- 顶部显示代管提示条，可一键退出代管模式
- 模板管理弹窗在代管模式下操作对方的模板

## 数据库变更

无

## 代码变更

### 后端
- `insurance/field_config_db.py`：新增 `list_all_templates()` 函数，查询所有 scope 的模板并关联企业名/用户名
- `insurance/api.py`：
  - 模板列表 API 对超管额外返回 `all` 字段
  - GET 配置接口支持 `target_scope` + `target_scope_id` 参数
  - 保存配置接口支持 `target_scope` + `target_scope_id` 参数（代管保存）
  - 模板管理接口支持 `target_scope` + `target_scope_id` 参数

### 前端
- `web/templates/field_config.html`：
  - 新增 `adminTarget`、`allTemplatesData` 状态
  - 模板下拉菜单：超管可见企业模板和员工模板分组
  - 新增 `selectAdminTemplate()` 函数进入代管模式
  - `loadConfig`/`saveConfig` 在代管模式下附加 target_scope 参数
  - 顶部代管提示条（黄色横幅，含退出按钮）

## 部署步骤

1. 更新代码并重启服务即可，无数据库迁移
