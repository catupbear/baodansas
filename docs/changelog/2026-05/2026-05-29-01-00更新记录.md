# 2026-05-29 01:00 更新记录

## 需求说明

添加钉钉机器人错误通知功能，当系统发生异常时自动发送告警到钉钉群，包含故障模块、方法/API、错误信息等详情。

## 代码变更

### 新增文件
- `core/notify.py` — 钉钉机器人错误通知模块
  - `DingTalkNotifier` 类：支持加签认证、Markdown 格式消息
  - `notify_error()` 全局函数：异步发送通知，不阻塞业务
  - 自动去重：相同错误 5 分钟内不重复发送

### 修改文件
- `config.yaml` — 新增 `notify` 配置段（webhook_url + secret）
- `config.yaml.example` — 新增 `notify` 配置示例
- `main.py` — 导入并初始化通知模块
- `core/fetcher.py` — SDK 拉取失败、消息解密失败、JSON 解析失败时通知
- `insurance/handler.py` — 保单处理异常、媒体下载失败、OCR 熔断、钉钉同步失败时通知
- `insurance/api.py` — 全局 500 错误处理器，捕获未处理异常并通知
- `callback/server.py` — 回调解密失败、XML 解析失败时通知
- `storage/db.py` — 消息保存失败时通知

## 通知覆盖的故障点

| 模块 | 方法 | 触发条件 |
|------|------|----------|
| 消息拉取 | `_do_fetch` | SDK 拉取消息返回非 0 |
| 消息解密 | `_process_item` | 消息解密失败 |
| 消息解析 | `_process_item` | JSON 解析失败 |
| 回调服务 | `receive_callback` | 回调消息解密/XML 解析失败 |
| 保单识别 | `_consume` | 消费线程未捕获异常 |
| 保单识别 | `_process` | 保单处理流程失败 |
| 保单识别 | `_download_media` | 媒体文件下载失败 |
| OCR引擎 | `_run_ocr_engines` | 火山引擎 OCR 熔断 |
| 钉钉同步 | `_sync_to_dingtalk_v2` | 自动同步钉钉失败 |
| Web服务 | 所有路由 | 500 内部错误 |
| 数据库 | `save_message` | 消息保存失败 |

## 部署步骤

1. 确认 `config.yaml` 中已配置 `notify` 段（webhook_url 和 secret）
2. 重启服务即可生效，无需数据库变更
