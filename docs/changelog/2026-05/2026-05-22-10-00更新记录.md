# 2026-05-22 渤海财险保单识别支持

## 需求说明
渤海财险保单 OCR 文本格式特殊：多列标签在同一行，值在下一行拼接或跨行分布，导致保单号、保险期间、保费、业务员等字段无法提取。

## 代码变更

### insurance/policy_parser.py
1. **保单号提取**：新增渤海专用规则，支持两种 OCR 格式
   - 格式1（pdfplumber）：多列值拼接，通过 `YYYY-MM-DD` 日期模式分隔
   - 格式2（百度 OCR）：保单号在标签后几行内的独立纯数字行
2. **保险期间提取**：新增渤海专用规则
   - 处理 `保险期间:自\n日期1\n日期2` 格式（两个日期在连续行，无"至"分隔符）
3. **保费提取**：增强下一行匹配逻辑
   - 支持 `(¥:1186.15` 无右括号的格式（渤海等）
4. **经办人/制单人提取**：新增跨行匹配规则
   - 支持标签在行末、名字在下一行的格式（如 `经办:\n唐景云`）
   - 支持制单标签单独一行、名字在后续行（跳过英文行如"admin"）
5. **签单日期提取**：新增拼接行兜底规则
   - 从"电子保单生成时间"/"收费确认时间"所在行的下一行提取日期
