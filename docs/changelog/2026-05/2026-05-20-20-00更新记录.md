# 2026-05-20 20:00 更新记录

## 需求说明
跟单人字段实时关联发送者绑定的账号姓名。通过 sender 查找 user_sender_binding 表对应的用户姓名，动态映射到"跟单人"字段。

**特点：**
- 不存储到数据库，查询/导出时实时关联
- 绑定变更或用户改名后自动生效，无需回填
- 历史数据天然支持

## 代码变更

### auth/db.py
- 新增 `get_sender_user_name_map()` 函数：批量查询 sender → 用户姓名映射（JOIN user_sender_binding + users）

### insurance/api.py
- `list_records()`：查询结果返回前，批量注入跟单人到 display_fields
- `get_record()`：单条详情返回前，注入跟单人到 parsed_fields 和 display_fields
