# 2026-05-31 22:00 更新记录

## 需求说明

在模板配置中新增「平安车牌格式化」开关。开启后，平安保单的车牌号会自动添加连字符（如 粤BB446T → 粤B-B446T）。该功能为模板级配置，跟随模板的作用域继承规则。

## 代码变更

### insurance/field_config_db.py
- 新增 `_format_plate_with_hyphen()` 工具函数：在省份简称+字母后插入连字符
- 新增 `get_plate_format_pingan()` / `save_plate_format_pingan()`：读写开关状态（config_key=`plate_format_pingan`）
- `apply_user_config_to_fields()` 新增第 6 步：当开关开启且保险公司包含「平安」时，格式化车牌号字段
- `get_effective_config()` 注入 `plate_format_pingan` 标志到配置字典

### insurance/api.py
- 新增 `GET /api/insurance/plate-format-config`：获取开关状态
- 新增 `POST /api/insurance/plate-format-config`：保存开关状态
- 支持超管代管模式（target_scope / target_scope_id）

### web/templates/field_config.html
- 在导出列配置区域新增「平安车牌格式化」滑块开关（与合并开关同行）
- 新增 `plateFormatPingan` 响应式变量及 `loadPlateFormatConfig` / `savePlateFormatConfig` / `togglePlateFormatPingan` 函数
- 导出列配置保存时同步保存该开关状态

## 数据库变更

无新增表或字段。复用现有 `user_field_config` 表，config_type=`export_columns`，config_key=`plate_format_pingan`。

## 部署步骤

1. 更新代码并重启服务即可
2. 无数据库迁移
