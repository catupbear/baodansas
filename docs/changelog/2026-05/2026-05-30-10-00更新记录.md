# 2026-05-30 10:00 更新记录

## 需求说明
保单导出 Excel 和批量导出保单（PDF下载）每次不能超过 500 条。超过 500 条时弹窗提示，允许用户分批导出/下载。

## 代码变更

### web/templates/insurance.html

**Excel 导出分批：**
- 新增分批导出弹窗 HTML（z-index 60）
- 新增状态变量：`EXPORT_BATCH_LIMIT`(500)、`batchExportVisible`、`batchExportTotal`、`batchExportRanges`、`batchExportAllData`、`batchExportCols`、`batchExportMerge`
- 新增函数：
  - `getManualExportCount(type)` — 获取手动上传各类型数据条数
  - `buildBatchRanges(total)` — 按500条一批生成分批范围（通用）
  - `buildManualExportData(type)` — 构建手动上传导出数据
  - `collectRecordsExportData(selectedCols)` — 收集识别记录导出数据
  - `executeBatchExport(batchIdx)` — 执行某一批Excel导出
  - `sendExportRequest(data, selectedCols, mergeByPlate, labelPrefix)` — 通用导出请求
- 修改 `confirmExport()` — 导出前检查数据量，超过500条弹分批弹窗

**批量下载保单（PDF）分批：**
- 新增分批下载弹窗 HTML
- 新增状态变量：`batchDlVisible`、`batchDlTotal`、`batchDlRanges`、`batchDlAllIds`
- 重构 `batchDownload()` — 拆分为 `collectBatchDownloadIds()`（收集ID）+ `startBatchDownloadTask(ids)`（启动下载），超过500条弹分批弹窗
- 新增 `executeBatchDownload(batchIdx)` — 执行某一批PDF下载

## 部署步骤
1. 更新前端文件 `web/templates/insurance.html`
2. 无需数据库变更
3. 无需重启后端服务（纯前端改动）
