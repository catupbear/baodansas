## 工单一

```
【新增】企业微信消息监控：会话存档查询系统

一、起因
1. 企业需要对微信客户沟通内容进行合规留痕，方便事后追溯和管理
2. 原始消息格式复杂，需要一个统一的可视化查询界面

二、功能说明
1. 系统接收企业微信回调通知，自动拉取并解密最新的聊天记录
2. 支持查看群聊和私聊消息，私聊支持双向消息合并显示
3. 消息列表采用聊天界面样式，支持文本、图片、语音、视频、文件、链接等 25+ 种消息类型展示
4. 支持按会话（群聊/私聊）分类浏览，点击左侧会话列表切换查看
5. 自动解析发送人昵称（内部员工、外部联系人、群聊名称），解析失败的会缓存标记避免重复请求
6. 媒体文件（图片、视频、文件）支持在线预览和下载，存储到腾讯云 COS
7. 提供手动拉取消息按钮，也支持自动增量刷新
8. 系统启动时自动补拉中断期间遗漏的消息
9. 消息监控页面需登录后才能访问
```

## 工单二

```
【新增】AI保单台账系统：保单自动识别与管理

一、起因
1. 业务员在群聊中发送大量保单 PDF，人工录入台账耗时且容易出错
2. 需要一套自动化系统，从 PDF 中提取关键信息生成台账记录

二、功能说明
1. 系统监控指定群聊，群内发送的 PDF 文件自动触发保单识别
2. PDF 文本提取优先使用 pdfplumber，失败时自动降级为百度 OCR（高精度版）
3. 支持识别 50+ 家保险公司的保单，自动提取承保公司、保单号、投保人、被保人、车牌号、保费、签单日期、起保/终保日期、险种类型、业务员等核心字段
4. 一个 PDF 包含多份保单（如交强险+商业险+驾意险）时，系统自动拆分为多条独立记录
5. 同一 PDF 的多份保单之间自动互补基础字段（如车牌号、投保人等共用信息）
6. 非保单文档（电子标志、条款等）自动归类为"非保单"，不混入正常识别结果
7. 保单识别记录列表支持按状态（成功/失败/待处理/非保单/标记正常）分 Tab 查看
8. 列表支持按承保公司、保单号、车牌、投保人、被保人、业务员模糊搜索
9. 列表支持按签单日期、起保日期、终保日期范围筛选
10. 列表支持按保司、文档类型、来源（自动/手动）筛选
11. 支持保单号去重开关，开启后同一保单号只显示最新一条
12. 列表中点击字段值可直接内联编辑并保存
13. 点击记录可打开预览弹窗，左侧显示 PDF 原件（支持 loading 状态），右侧显示识别结果
14. 预览弹窗内字段也支持编辑保存
15. 同一 PDF 的多份保单之间可通过下拉菜单切换查看，切换时自动跳转到对应起始页
16. 预览弹窗内可点击"重新识别"按钮，重新识别后自动更新同 PDF 的所有关联记录
17. 识别异常的记录可标记为"正常"（需填写原因），也可取消标记
18. 标记正常原因合并多个缺失字段为一条，用顿号分隔显示
```

## 工单九

```
【优化】保单识别引擎：50+ 保险公司兼容适配

一、起因
1. 不同保险公司的保单格式差异巨大，OCR 提取文本中经常出现空格、换行、特殊格式等干扰
2. 需要持续适配各家保司的特殊格式，确保字段提取准确率

二、功能说明
1. 兼容平安保单：业务员兜底取经办值、新车车牌"鄂A-*"格式、车牌跨行提取、经办字段紧跟日期的情况、同类型保单多保单拆分
2. 兼容太平洋保单：业务员"渠道"值替换为制单人、制单人以"渠道"开头时也检查
3. 兼容华农保单：兼容"车家无忧"综合险和"道路危险货物承运人责任险"、业务员兜底取销售机构
4. 兼容紫金保单：保费 OCR 空格格式、保费金额在标签上一行且与数字粘连、驾乘险无签单日期提示
5. 兼容国任保单：中文年月日格式的保险期间提取
6. 兼容中华联合：驾乘人员意外险识别、销售渠道名称兜底为业务员
7. 兼容安盛天平：出单代理提取业务员、签单日期英文标签、电子标志过滤、OCR 汉字空格
8. 兼容众诚保单：保单号去除粘连电话、非车险保险单险种标题提取
9. 兼容浙商保单：按险种类型区分交强险/商业险提取保单号
10. 兼容鼎和保单：保费跨行 CNY 格式
11. 兼容安诚保单：新增安诚保司识别支持
12. 兼容国寿商业险：被保险人"姓名/名称 XXX"格式识别
13. 兼容人保保单：交强险标题格式"强制保险单"匹配
14. 兼容合同条款格式的险种类型提取
15. 签单日期兼容 OCR 空格（如"2026 - 04-27"自动修正）
16. 投保人/被保人提取使用 jieba 词性标注判断人名/公司名，替代正则黑名单
17. 代理人字段过滤增加保险公司名关键词，避免误提取为业务员
18. 车船税提取排除"保险费合计"行，避免误提取保费合计
19. 多保单自动检测兜底——通过多个不同保单号自动发现多保单
```
