# 2026-05-28 22:00 更新记录

## 需求说明

修复人保多险种合并PDF（交强险+商业险+驾乘险）被保人提取错误的问题。

### 问题描述
- PDF左侧边栏/页脚的服务提示文字（如"若对查询结果有异议,请通过以上三种渠道联系本公司"）在OCR提取时被错误识别为公司名
- `_is_valid_person` 因文本包含"公司"二字且长度≤30，误判为有效公司名
- 同PDF互补逻辑取最长值，导致错误值覆盖所有保单的正确被保人

### 修复方案
在 `_is_valid_person` 公司名验证中增加两层过滤：
1. 排除含服务提示/通知类用语的句子（查询、异议、渠道、联系、客服、拨打等）
2. 排除含中文标点符号的值（公司名不含逗号、句号等标点）
