# 2026-05-29 11:00 更新记录

## 需求说明

页面列配置中自定义字段添加「固定值」设置功能。用户可以为自定义字段设置一个固定值，当保单记录中该字段无数据时，自动填充该固定值。固定值针对当前账号生效。

## 代码变更

### 1. insurance/field_config_db.py
- 新增 `extract_fixed_values()` 函数：从列配置中提取自定义字段的固定值映射
- `apply_user_config_to_fields()` 新增第5步：固定值填充，在公式计算之后执行，仅在字段无值时填充

### 2. insurance/api.py
- 导入 `extract_fixed_values`
- 列表查询接口：加载列配置后提取固定值注入 `user_config`，复用已加载的列配置避免重复查询
- 导出接口：同样提取导出列配置中的固定值注入 `user_config`

### 3. web/templates/field_config.html
- 页面列配置表格（Tab 4）：新增「固定值」列，自定义字段行显示输入框
- 导出列配置表格（Tab 5）：新增「固定值」列，自定义字段行显示输入框（合并字段除外）
- 添加自定义字段时初始化 `fixed_value` 属性
- 同步自定义字段到另一侧时携带 `fixed_value`
- 更新底部提示文案

## 数据库变更

无。固定值存储在现有的 `user_field_config` 表的 JSON 配置中（列配置的 `fixed_value` 属性）。
