# 2026-05-29 11:00 更新记录

## 需求说明

页面列配置中自定义字段添加「固定值」设置功能。用户可以为自定义字段设置一个固定值，当保单记录中该字段无数据时，自动填充该固定值。

**固定值独立于模板，始终按用户个人存储。** 即使使用企业模板（列配置只读），员工仍可设置自己的固定值。

## 代码变更

### 1. insurance/field_config_db.py
- 新增 `get_user_fixed_values()` 函数：从 `user_field_config` 表读取用户个人的固定值（config_type=custom_fixed_values，scope=user）
- 新增 `save_user_fixed_values()` 函数：保存用户个人的固定值
- `apply_user_config_to_fields()` 新增第5步：固定值填充，在公式计算之后执行，仅在字段无值时填充

### 2. insurance/api.py
- 导入 `get_user_fixed_values`, `save_user_fixed_values`
- 列表查询接口：从用户个人配置读取固定值注入 `user_config`
- 导出接口：同样从用户个人配置读取固定值注入 `user_config`
- 新增 `GET /api/insurance/fixed-values`：获取当前用户的固定值
- 新增 `POST /api/insurance/fixed-values`：保存当前用户的固定值

### 3. web/templates/field_config.html
- 页面列配置表格（Tab 4）和导出列配置表格（Tab 5）：新增「固定值」列
- 固定值输入框不受模板只读限制，始终可编辑
- 固定值独立加载/保存（`loadFixedValues` / `saveFixedValues`），修改后自动保存
- 更新底部提示文案：说明固定值为个人设置

## 数据库变更

无需手动建表。固定值使用现有 `user_field_config` 表，新增 config_type=`custom_fixed_values` 记录，首次保存时自动插入。
