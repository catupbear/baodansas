# 2026-05-07 系统设置（字段配置）功能

## 需求说明

新增系统设置功能，支持用户自定义保单字段的显示和计算规则：
- 多模板管理：创建/编辑/删除/切换配置模板
- 简称映射：承保公司和险种的全称↔简称映射（双文本框批量编辑）
- 日期格式：按字段独立配置日期显示格式（签单日期/起保日期/终保日期）
- 自动计算公式：按具体公司+具体险种配置佣金率、佣金、采购费率、公司利润、跟单利润的计算公式
- 企业管理员可设置模板对员工可见，员工可选用企业模板（只读）
- 导出 Excel 时自动应用用户配置

## 数据库变更

新增两张表（服务启动时自动创建，无需手动迁移）：

### user_field_config
用户字段配置表，支持多模板 + 三级作用域（global/enterprise/user）

### user_active_template
用户当前启用的配置模板，每用户一条记录

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/insurance/settings` | 系统设置页面 |
| GET | `/api/insurance/field-config/templates` | 获取模板列表 |
| PUT | `/api/insurance/field-config/templates/manage` | 管理模板（重命名/可见性/删除） |
| GET | `/api/insurance/field-config` | 获取指定模板配置 |
| POST | `/api/insurance/field-config/save-and-apply` | 保存并应用模板 |
| POST | `/api/insurance/field-config/apply` | 切换启用模板 |
| POST | `/api/insurance/field-config/formula/validate` | 验证公式 |
| GET | `/api/insurance/field-config/defaults` | 获取系统默认值 |
