# AI保单台账系统 — 用户使用手册


## 1. 登录系统

打开系统网址：https://wxbot.wuhuxiche.com/ 后进入登录页面。

操作步骤：

1. 输入管理员分配的手机号
2. 输入密码（点击右侧眼睛图标可查看输入内容）
3. 如需下次免输密码，勾选「记住密码」
4. 点击「登录」按钮

登录成功后自动跳转到保单台账主页。

> 如忘记密码，请联系超级管理员通过"账号管理"重置密码。


## 2. 保单台账 — 查看识别记录

登录后默认进入「识别记录」页面，这是系统的核心功能区，展示所有自动识别和手动上传的保单数据。

### 2.1. 了解页面布局

页面从上到下分为三个区域：

- 筛选栏：提供丰富的条件筛选，帮助快速定位记录
- 状态标签栏 + 操作按钮：按状态分类查看，以及导出、批量操作
- 记录列表：保单数据表格，支持翻页

### 2.2. 筛选保单记录

#### 2.2.1. 基础筛选

筛选栏提供以下常用条件，选择或输入后列表自动刷新：

| 筛选项 | 使用方式 |
|--------|----------|
| 来源 | 下拉选择"群聊"、"私聊"或"手动上传"，查看对应来源的记录 |
| 群名 | 选择来源为"群聊"后出现，可选择具体群聊 |
| 联系人 | 选择来源为"私聊"后出现，可选择具体联系人 |
| 保单号 | 直接输入保单号（支持模糊搜索，输入部分即可匹配） |
| 车牌 | 输入车牌号模糊搜索 |
| 投保人 | 输入投保人名称模糊搜索 |
| 保司 | 下拉选择保险公司 |

如需重置所有筛选条件，点击右侧「× 清空筛选」。

#### 2.2.2. 日期筛选

在筛选栏下方可按识别日期筛选：

- 点击快捷按钮：今天 / 近3天 / 近7天 / 近30天 / 本月 / 上月
- 如需精确范围，点击「自定义」后选择起止日期
- 点击「× 清除」取消日期筛选

#### 2.2.3. 高级搜索

点击右侧「高级搜索」展开更多筛选条件：

| 筛选项 | 说明 |
|--------|------|
| 按保单号去重 | 开启后，相同保单号只显示最新一条，避免重复查看 |
| 文档类型 | 按"保单"、"电子标志"等文档类型筛选 |
| 承保公司 | 模糊搜索承保公司名称 |
| 被保人 | 模糊搜索被保险人 |
| 业务员 | 模糊搜索业务员 |
| 签单日期 | 按保单签订日期范围筛选 |
| 起保日期 | 按保险起始日期范围筛选 |
| 终保日期 | 按保险到期日期范围筛选 |

> 提示：超级管理员还可以按"识别方式"（PDF提取/百度OCR/火山引擎）筛选。

### 2.3. 按状态查看

记录列表上方有状态标签页，每个标签后面的数字是该状态的记录数量：

| 标签 | 含义 |
|------|------|
| 全部 | 所有记录 |
| 已识别 | 识别成功，已提取出保单字段 |
| 异常 | 识别成功但存在缺失字段或可疑数据，需要人工检查 |
| 失败 | 识别过程出错，可尝试重新识别 |
| 处理中 | 正在进行识别，请稍候 |

点击对应标签即可切换查看。

### 2.4. 查看记录列表

列表中每一行是一条保单记录，主要列说明：

| 列 | 说明 |
|----|------|
| 勾选框 | 用于批量操作（导出保单、批量重新识别），首行可全选 |
| 文件名 | 保单PDF文件名。橙色文字可点击打开预览 |
| 文档类型 | 绿色标签"保单"、黄色标签"电子标志"等 |
| 保单字段列 | 保单号、承保公司、车牌号、投保人、保费等，具体列由管理员配置 |
| 状态 | 绿色"已识别"、黄色"处理中"、红色"失败" |
| 时间 | 识别完成时间 |
| 群名 | 保单来源的群聊名称 |
| 发送人 | 在群中发送保单的人 |
| 操作 | 预览、详情、重新识别等操作按钮 |

特殊标记说明：
- 「多保单 1/3」：表示该PDF文件包含多张保单，系统已自动拆分，当前是第1张，共3张
- 「第2-5页」：表示该保单位于PDF的第2到第5页
- 「已标记正常」：该记录曾被检测为异常，但已由人工确认为正常

#### 2.4.1. 翻页

列表底部显示分页信息：
- 左侧显示"共 XX 条，第 X / X 页"
- 右侧点击页码或前后箭头翻页

### 2.5. 直接在列表中编辑字段

发现识别结果有误时，可以直接在列表中修改：

1. 点击需要修改的字段值（如保单号、车牌号等）
2. 字段变为输入框，直接输入正确值
3. 按 Enter 键保存，或按 Esc 键取消
4. 也可以点击输入框旁的 ✓ 保存或 ✕ 取消

> 提示：列表上方有蓝色提示条"点击列表数据，可进行修改"。


## 3. 保单预览

预览功能可以同时查看保单原文件和识别结果，是核实和修改数据最方便的方式。

### 3.1. 打开预览

有两种方式打开预览：
- 在列表中点击橙色的文件名
- 在列表中点击操作列的「预览」按钮

### 3.2. 预览界面说明

预览以全屏方式打开，分为左右两个区域：

左侧 — 保单原文件：
- 显示保单PDF原文件，可滚动查看完整内容
- 图片格式的保单同样可以查看

右侧面板（通过顶部按钮切换显示）：

| 按钮 | 功能 |
|------|------|
| 查看列表信息 | 显示所有识别出的字段及其值，可点击编辑 |
| 查看原文 | 显示OCR提取的完整文本内容（可复制），方便与原文件逐项比对 |

### 3.3. 在预览中编辑字段

1. 点击顶部「查看列表信息」打开右侧字段面板
2. 面板中有橙色提示"识别有误？点击需要修改的数据，即可修改"
3. 点击任意字段值，该字段变为输入框
4. 输入正确值后点击「保存」，或按 Enter 保存
5. 点击「取消」或按 Esc 放弃修改
6. 已手动修改的字段旁会显示一个橙色小圆点标记

### 3.4. 在预览中重新识别

如果识别结果整体不理想，可以点击顶部的「重新识别」按钮，系统会重新对该保单进行OCR和字段提取。识别过程中右侧面板会显示加载动画，完成后自动刷新结果。

### 3.5. 多保单文档切换

如果一个PDF包含多张保单，预览顶部会显示「查看其他保单 (N)」按钮：
1. 点击该按钮展开下拉菜单
2. 列表显示所有保单的序号、险种类型和页码范围
3. 当前保单标记为"当前"
4. 点击任意一条即可切换到对应保单的识别结果

### 3.6. 关闭预览

点击右上角 × 按钮关闭预览，返回列表。


## 4. 记录详情

### 4.1. 打开详情

在列表操作列点击「详情」按钮，打开详情弹窗。

### 4.2. 详情弹窗内容

弹窗中包含以下信息：

基本信息：
- 文件名（有云存储链接的可点击跳转）
- 群名、发送人（可点击编辑名称）
- 识别时间
- 状态标签

识别字段列表：
- 逐行显示所有提取出的保单字段
- 每个字段可点击编辑

异常信息（如有）：
- 显示异常原因
- 可直接标记为正常


## 5. 保单异常处理

### 5.1. 什么是异常记录

系统识别完成后会自动检查数据完整性，如果存在以下情况会标记为异常：
- 关键字段缺失（如保单号为空、车牌号为空）
- 数据格式不符合预期

异常记录在列表中以红色/黄色状态标签提示，方便及时发现和处理。

### 5.2. 标记为正常

确认异常记录实际上数据是正确的（比如某些特殊保单确实不含某字段），可以将其标记为正常：

1. 在列表中点击操作列的「标记正常」按钮（也可在预览弹窗中操作）
2. 弹出标记原因弹窗
3. 选择快捷原因按钮（如"该字段无需填写"、"数据正确无需修改"），或手动输入原因
4. 点击「确认标记」

标记后，该记录会显示绿色"已标记正常"标签，附带标记原因。

### 5.3. 撤销标记

如果误操作标记了正常，可以撤销：
- 在列表中点击"已标记正常"旁的 × 按钮
- 或在预览弹窗中点击「取消标记为正常」按钮


## 6. 批量操作

### 6.1. 选择记录

- 单选：点击每行左侧的勾选框
- 全选：点击表头的勾选框，选中当前页所有记录
- 勾选后列表上方出现提示栏，显示已选数量，点击「清除选择」可取消全部

### 6.2. 导出Excel

点击「导出Excel」按钮，将当前筛选条件下的所有记录导出为Excel表格文件。

> 注意：导出的是当前筛选条件下的全部数据，不仅仅是当前页，也不受勾选影响。

### 6.3. 批量导出保单PDF

将多个保单的PDF原文件打包下载：

1. 勾选需要导出的记录（按钮上会显示已选数量）
2. 点击「批量导出保单」按钮
3. 屏幕右下角出现下载进度浮窗，显示：
   - 当前正在下载的文件名
   - 进度条和完成比例
   - 成功/失败数量统计
4. 全部下载完成后自动打包为ZIP文件并下载到本地

> 如果不勾选任何记录，将导出当前筛选条件下的全部保单文件。

### 6.4. 批量重新识别

对多条记录重新进行OCR识别：

1. 勾选需要重新识别的记录
2. 点击「批量重新识别」按钮
3. 屏幕右下角出现进度浮窗，显示处理进度
4. 完成后列表自动刷新

> 适用场景：系统识别规则更新后，批量重新识别旧记录以获得更准确的结果。


## 7. 手动上传识别

当收到纸质保单或通过其他渠道获得保单文件时，可以手动上传进行识别。

### 7.1. 切换到上传页面

点击顶部导航的「手动上传」标签。

### 7.2. 查看支持的保险公司

页面顶部展示系统当前支持识别的保险公司列表，每个保司标签后有识别次数统计。颜色较浅的保司表示识别次数较少，准确率可能偏低。

### 7.3. 上传文件

有两种上传方式：

方式一：拖拽上传
- 直接将文件从电脑文件夹拖拽到页面中央的虚线框区域
- 拖入时边框变为橙色高亮

方式二：点击选择
- 点击虚线上传区域，弹出文件选择窗口
- 支持按住 Ctrl/Cmd 多选文件

支持的格式：PDF、JPG、PNG

### 7.4. 管理已选文件

上传后文件以卡片形式展示：
- PDF文件显示红色图标，图片文件显示绿色图标
- 点击文件卡片可预览文件内容
- 鼠标悬停文件卡片，右上角出现红色 × 可删除单个文件
- 点击「清空」按钮可删除所有已选文件

### 7.5. 开始识别

1. 确认文件列表无误后，点击「开始识别」按钮
2. 按钮变为"识别中..."，系统逐个处理文件
3. 如需将保单文件同步存储到云端，开启旁边的「上传保单到云存储」开关

### 7.6. 查看识别结果

识别完成后，结果以表格形式显示在下方：

- 序号和文件名两列固定在左侧，横向滚动时始终可见
- 后续列为识别出的保单字段（保单号、承保公司、车牌号、投保人等）
- 识别失败的文件以红色底色标注
- 一个PDF中如包含多张保单，会自动拆分为多行

#### 7.6.1. 在结果表格中编辑

- 点击任意字段单元格可直接修改
- 修改后按 Enter 保存

#### 7.6.2. 预览原文件

- 点击操作列的「预览」按钮，打开全屏预览界面
- 预览中同样支持查看识别字段和OCR原文


## 8. 编辑群名和联系人名称

系统通过企业微信接口自动获取群名和联系人名称，但有时可能显示为ID或名称不准确，可以手动修改。

### 8.1. 在保单台账中编辑

在记录列表中，群名和发送人列的内容可以点击修改：

1. 点击群名或发送人名称（显示为可点击的橙色文字）
2. 弹出编辑弹窗，显示当前ID和名称
3. 在「名称」输入框中输入正确名称
4. 点击「保存」或按 Enter 确认

修改后该群或联系人在所有记录中都会显示新名称。


## 9. 业绩看板（企业管理员）

> 企业管理员可用（限时免费）。员工账号能看到入口，但需联系企业管理员开通权限后才能使用。

点击顶部导航的「业绩看板」进入，看板基于保单台账数据自动生成，包含三个页签：看板、看板配置、目标管理。

### 9.1. 看板页

进入后默认显示**今日**数据，顶部可切换时间范围：今日 / 昨日 / 本周 / 本月 / 上月 / 本季度 / 今年 / 自定义。

页面从上到下依次为：

| 区块 | 说明 |
|------|------|
| 指标卡 | 汇总数字，如总保费、总佣金、保单量 |
| 目标完成 | 各业绩目标的进度条和完成率（按目标自身周期统计，见 9.3） |
| 保费趋势图 | 趋势粒度自动跟随时间范围：月内按日、季度按周、更长按月；选单天（今日/昨日）时不显示趋势图 |
| 保司保费占比 | 环形图，展示全部保司的保费构成 |
| 险种保费分布 | 条形图；「驾意险」计入「非车险」展示 |

> 提示：每个数字旁都有「!」图标，鼠标悬停可查看该数字的数据来源、统计范围和计算公式。数字对不上时先看「!」里的统计范围。

### 9.2. 看板配置

看板默认使用系统模板，企业可自定义，保存后生成本企业专属配置，随时可「恢复默认模板」。

**新增指标卡**：名称 + 统计方式（求和/计数/平均）+ 统计字段 + 筛选条件（可叠加多个）。

- 统计字段来自本企业页面配置中启用的列（含费率公式产出的计算字段），以及按险种拆分的「商业险保费 / 交强险保费 / 非车险保费」
- 筛选条件示例：字段选「保费」+ 条件「险种 包含 车险」= 车险保费合计
- 不加条件则统计时间范围内的全部保单

**图表配置**：趋势图可配指标和粒度（默认「自动」跟随时间范围）；占比图/分布图可配维度和指标。

### 9.3. 目标管理

可设置企业整体目标或带筛选条件的条件目标：目标名称 + 统计口径（同指标卡）+ 周期 + 目标值。

- 周期为「当月 / 本季度 / 今年」时是**滚动周期**，自动按当前自然周期起算，每月（季/年）自动进入新周期
- 自定义起止日期的目标为一次性目标

> 注意：目标进度按**目标自身的周期**统计，与看板顶部的时间筛选无关。例如目标周期是「当月」，即使页面选了「今日」，目标进度仍显示整月累计——所以目标数字和图表数字可能不同，这是正常的。

### 9.4. 常见疑问

- **目标进度显示 0%**：先检查目标值是否设置过大（实际值 ÷ 目标值四舍五入后不足 0.1% 会显示 0%）；再悬停「!」核对统计字段和范围。
- **目标和图表数字对不上**：两者时间口径不同，见上方「注意」。


## 10. 监控配置管理（管理员）

> 仅超级管理员可访问此功能。

点击顶部导航的「设置」按钮进入。

### 10.1. 查看监控配置

每条监控配置以卡片形式展示，包含：
- 配置名称和启用状态
- 监控的群聊和用户（以标签形式列出）
- 绑定的钉钉多维表格链接
- 关联的员工账号
- 字段映射数量

### 10.2. 新增监控配置

1. 点击页面右上角「新增监控」按钮
2. 在弹窗中填写以下信息：

| 项目 | 说明 |
|------|------|
| 名称 | 为该配置起一个易辨识的名称，如"车险一组" |
| 群聊监控 | 搜索并选择需要监控的企业微信群聊，可多选 |
| 私聊监控 | 搜索并选择需要监控的特定联系人，可多选 |
| 钉钉文档链接 | 粘贴钉钉多维表格URL，识别结果自动同步到该表格 |
| 绑定账号 | 选择关联的员工账号 |
| 字段映射 | 配置哪些字段需要同步到钉钉，以及钉钉列名 |

3. 点击「保存」

> 提示：如果群聊列表中找不到需要的群，点击「刷新数据」按钮同步最新通讯录。

### 10.3. 管理已有配置

- 启用/禁用：点击卡片上的开关，可暂停或恢复该配置的自动监控
- 编辑：点击卡片上的编辑按钮修改配置
- 删除：点击删除按钮，确认后移除该配置


## 11. 字段映射配置（管理员）

> 仅超级管理员可访问此功能。

在「手动上传」页面，点击顶部的「字段映射」按钮打开配置弹窗。

### 11.1. 什么是字段映射

字段映射决定了OCR识别的原始字段如何对应到最终展示和导出的列名。例如：
- OCR识别出的"保险单号" → 导出列显示为"保单号"
- OCR识别出的"被保险人" → 导出列显示为"被保人"

### 11.2. 编辑默认映射

默认映射对所有保险公司生效：

1. 打开字段映射弹窗，确认「当前编辑」为"默认映射（所有保司）"
2. 表格中每行有：
   - 导出列名：可点击修改，修改后影响列表和导出中的列标题
   - OCR字段：映射的原始识别字段名
3. 修改完成后点击「保存」

### 11.3. 为特定保司设置专属映射

不同保险公司的保单格式可能不同，可为特定保司设置专属映射：

1. 在输入框中输入保司简称（如"人保PICC"），点击「新增保司映射」
2. 在「当前编辑」下拉框中选择该保司
3. 编辑专属映射规则
4. 点击「保存」

未单独配置的保司自动使用默认映射。


## 12. 常见问题

### 12.1. 为什么有些记录显示"异常"？

系统在识别后会自动检查数据完整性。如果关键字段（如保单号、车牌号）为空或格式异常，会标记为异常提醒您复核。如果确认数据无误，可以点击"标记正常"消除异常提示。

### 12.2. 识别结果不准确怎么办？

1. 直接修改：在列表或预览中点击错误字段值直接编辑
2. 重新识别：点击"重新识别"按钮让系统重新处理
3. 查看原文比对：在预览中点击"查看原文"，对照PDF原文件检查

### 12.3. 群名显示为一串ID怎么办？

点击群名，在弹窗中手动输入正确的群名称并保存。也可以联系管理员点击"同步通讯录"批量更新。

### 12.4. 一个PDF包含多张保单，系统能识别吗？

可以。系统会自动检测并拆分，每张保单生成独立的记录。在列表中会显示"多保单 1/3"标签，在预览中可通过"查看其他保单"按钮切换查看。

### 12.5. 如何导出数据给其他同事？

- 导出表格数据：使用"导出Excel"按钮，导出筛选后的全部记录
- 导出保单原件：勾选记录后使用"批量导出保单"按钮，打包下载为ZIP

### 12.6. 手动上传支持哪些文件格式？

支持 PDF、JPG、PNG 格式。扫描件和拍照件会自动调用OCR引擎识别。
