# AI保单台账系统 — 产品功能说明书

## 一、产品概述

AI保单台账系统是一款面向保险中介/代理机构的智能保单管理工具。系统自动监控企业微信群聊中发送的保单PDF文件，通过AI识别技术提取保单关键信息（保单号、车牌号、投保人、保费等），生成结构化台账数据，支持人工复核、编辑、导出，并可自动同步至钉钉多维表格，帮助业务团队高效管理保单数据。

---

## 二、用户角色

| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 全部功能：系统设置、监控配置、字段映射、用户管理、企业管理、保单台账 |
| 企业管理员 | 保单台账查看与编辑、手动上传识别 |
| 普通员工 | 保单台账查看与编辑、手动上传识别（仅查看关联监控配置下的数据） |

### 模块二：保单台账（核心功能）

**入口**：登录后默认页面，顶部导航标签"识别记录"

保单台账是系统的核心功能模块，展示所有通过自动监控或手动上传识别出的保单记录，支持丰富的筛选、编辑、导出功能。

#### 2.1 筛选与搜索

##### 基础筛选栏
- **来源**：下拉选择"全部 / 群聊 / 私聊 / 手动上传"
- **群名**：来源为群聊时可按具体群筛选
- **联系人**：来源为私聊时可按具体联系人筛选
- **保单号**：模糊搜索
- **车牌**：模糊搜索
- **投保人**：模糊搜索
- **保司**：下拉选择已有保险公司
- **清空筛选**：一键重置所有筛选条件

##### 日期筛选栏
- **识别日期**：支持快捷选项（今天、近3天、近7天、近30天、本月、上月、自定义）
- **自定义日期**：选择起止日期范围

##### 高级搜索（可折叠展开）
- **去重开关**：按保单号去重，相同保单号只显示最新一条
- **文档类型**：筛选保单、电子标志等不同文档类型
- **识别方式**（仅超管可见）：按 PDF提取 / 百度OCR / 火山引擎 筛选
- **承保公司**：模糊搜索
- **被保人**：模糊搜索
- **业务员**：模糊搜索
- **签单日期**：起止日期范围
- **起保日期**：起止日期范围
- **终保日期**：起止日期范围

#### 2.2 状态标签页

记录列表上方有状态分类标签，每个标签显示对应数量：
- **全部**：所有记录
- **已识别**：识别成功的记录
- **异常**：识别结果有缺失字段或异常数据的记录
- **失败**：识别失败的记录
- **处理中**：正在进行OCR识别的记录

#### 2.3 记录列表

每条记录显示以下信息：

| 列名 | 说明 |
|------|------|
| 勾选框 | 支持多选，用于批量操作 |
| 文件名 | 保单PDF文件名，可点击预览原文件；多保单文档显示"多保单 1/3"标签；有页码范围标签 |
| 文档类型 | 保单、电子标志等，以彩色标签展示 |
| 动态字段列 | 根据字段映射配置动态显示的保单字段（如保单号、承保公司、车牌号、投保人、保费等） |
| 识别方式 | 仅超管可见；显示 PDF提取 / 百度OCR / 火山引擎 |
| 置信度 | 仅超管可见；以百分比和颜色区分识别置信度（绿色≥75%、黄色≥50%、红色<50%） |
| 状态 | 已识别（绿色）/ 处理中（黄色）/ 失败（红色） |
| 时间 | 识别时间 |
| 群名 | 来源群聊名称，可点击编辑 |
| 发送人 | 保单发送人，可点击编辑 |
| 操作 | 见下方操作说明 |

**列表内直接编辑**：点击任意字段列的值，可直接在列表中修改字段内容，按回车保存或按ESC取消。

#### 2.4 记录操作

每条记录支持以下操作：

- **预览**：弹窗内查看保单PDF原文件
- **详情**：打开详情弹窗，查看所有识别字段和OCR原文
- **重新识别**：对已识别或失败的记录重新进行OCR和字段提取
- **重试**：对失败且无云存储文件的记录，从企业微信重新下载后识别
- **标记正常**：对异常记录标记为正常，需选择或输入原因（如"该字段无需填写"、"数据正确无需修改"等快捷选项）
- **撤销标记**：对已标记正常的记录撤销标记

#### 2.5 批量操作

- **批量勾选**：支持全选/单选
- **已选提示栏**：勾选后顶部显示已选数量，可一键清除选择
- **导出Excel**：将当前筛选条件下的记录导出为Excel文件
- **批量导出保单**：将勾选的保单PDF原文件批量下载为ZIP压缩包，下载过程有进度浮窗显示（当前文件名、进度条、成功/失败统计）
- **批量重新识别**：将勾选的记录重新进行OCR识别，有进度浮窗显示处理进度

#### 2.6 分页

- 底部分页器显示总记录数、当前页码、总页数
- 支持上一页、下一页、跳转到指定页

### 模块三：手动上传识别

**入口**：顶部导航标签"手动上传"

#### 3.1 支持保司展示

页面顶部展示系统支持识别的保险公司列表，每个保司标签显示已识别次数。超级管理员可展开配置面板：
- **支持阈值**：设置最低识别次数，低于阈值的保司标记为不支持
- **简称别名**：将不同名称合并为同一保司（如"人保" → "中国人民保险"）

#### 3.2 文件上传

- **拖拽上传**：将PDF/JPG/PNG文件拖拽到上传区域
- **点击上传**：点击上传区域选择文件，支持批量多选
- **文件列表**：已选文件以卡片网格展示，PDF文件红色图标、图片文件绿色图标
- **文件预览**：点击文件卡片可预览文件内容
- **单个删除**：悬停文件卡片右上角出现删除按钮
- **全部清空**：一键清空已选文件

#### 3.3 识别操作

- **开始识别**：点击后逐个处理已选文件，按钮变为"识别中..."
- **上传保单到云存储**：开关控制，开启后将保单PDF同步上传到腾讯云COS

#### 3.4 识别结果

识别完成后以表格展示结果：
- 序号列和文件名列固定在左侧（冻结列），横向滚动时始终可见
- 动态字段列根据字段映射配置显示
- 每个字段单元格可点击编辑
- 识别失败的文件以红色底色标注
- 多保单文档自动拆分为多行

## 四、自动化流程说明

### 保单自动识别流程

1. 企业微信群聊中有用户发送PDF文件
2. 系统通过回调通知感知到新消息
3. 后台自动拉取并解密消息内容
4. 检测到PDF文件消息后，判断是否在监控群/监控人范围内
5. 符合条件的PDF自动加入识别队列
6. 系统下载PDF文件，上传至云存储
7. 调用OCR引擎提取文本（火山引擎为主，百度OCR兜底）
8. 智能解析保单字段（基于50+保险公司的识别规则）
9. 将结果写入台账记录
10. 如配置了钉钉同步，自动将数据推送到钉钉多维表格

### 异常检测机制

识别完成后系统自动检测以下异常情况：
- 关键字段缺失（如保单号、车牌号为空）
- 保费金额异常
- 日期格式或逻辑异常
- 识别置信度偏低

异常记录在列表中单独标注，提醒用户人工复核。

### 模块十一：字段配置管理

**入口**：保单台账页面右上角"字段设置"按钮，跳转至独立配置页面 `/insurance/settings`

字段配置管理允许用户自定义保单数据的展示规则，包括公司/险种简称映射、日期显示格式、费用自动计算公式。支持多模板管理和三级权限作用域（全局/企业/个人）。

#### 11.1 模板管理

- **模板列表**：左侧展示当前用户可用的所有模板（个人模板 + 企业共享模板）
- **新建模板**：创建个人配置模板，输入模板名称
- **切换模板**：点击模板即切换启用，当前启用模板高亮显示
- **模板操作**：
  - 重命名：修改模板名称
  - 删除：需二次确认，删除后立即从列表消失
  - 可见性设置（仅企业管理员）：控制企业模板是否对员工可见

#### 11.2 简称映射配置

配置保单字段值的简化显示名称，分为两个子项：

##### 承保公司简称映射
- 左侧文本框输入保险公司全称（每行一个）
- 右侧文本框输入对应简称（每行一个，行数须一致）
- 示例：`中国人民财产保险股份有限公司` → `人保`
- **从数据库导入**：一键导入系统中已有保单记录的保司名称，自动填充到映射列表

##### 险种名称简称映射
- 操作方式与承保公司映射一致
- 示例：`机动车交通事故责任强制保险` → `交强险`

#### 11.3 日期格式配置

为日期类字段配置统一的显示格式：

- **可配置字段**：签单日期、起保日期、终保日期
- **支持格式**：
  - `YYYY-MM-DD`（如 2026-05-08）
  - `YYYY/MM/DD`（如 2026/05/08）
  - `YYYY年MM月DD日`（如 2026年05月08日）
  - `MM-DD-YYYY`（如 05-08-2026）
  - `DD/MM/YYYY`（如 08/05/2026）
  - `YYYYMMDD`（如 20260508）
- **一键统一**：将所有日期字段统一设为相同格式

#### 11.4 自动计算公式配置

为费用类字段配置自动计算公式，支持按承保公司和险种设置差异化规则：

##### 可配置计算字段
- 佣金率
- 佣金
- 采购费率
- 公司利润
- 跟单利润

##### 公式编辑器
- 支持引用其他保单字段作为变量（如"保费合计"、"佣金率"）
- 支持运算符：加（+）、减（-）、乘（×）、除（÷）、括号
- 支持输入常量数值
- 实时预览公式显示效果
- 公式合法性验证

##### 条件化配置
- 可指定公式仅对特定承保公司生效
- 可指定公式仅对特定险种生效
- 未指定条件时作为默认公式应用于所有记录

##### 特殊说明
- "率"类字段（佣金率、采购费率）在公式中以小数参与计算，显示时自动转换为百分比
- 公式计算在导出Excel或同步钉钉时自动触发

#### 11.5 权限与作用域

字段配置采用三级作用域体系，高优先级覆盖低优先级：

| 作用域 | 操作角色 | 说明 |
|--------|----------|------|
| 全局（global） | 超级管理员 | 系统默认配置，所有用户生效 |
| 企业（enterprise） | 企业管理员 | 企业级配置，覆盖全局配置；可设置是否对员工可见 |
| 个人（user） | 所有用户 | 个人配置，仅自己可见，优先级最高 |

- 员工可查看企业管理员创建的共享模板（只读）
- 员工可基于企业模板创建自己的个人模板
- 个人模板仅对创建者可见
