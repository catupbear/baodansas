# 保单PDF身份证号码格式分析报告

> 分析日期：2026-05-31
> 样本来源：4个批次共2000个训练保单PDF
> 实际分析样本：约80个PDF，覆盖20+保司

## 一、概述

当前系统 `policy_parser.py`（2103-2110行）仅有一个简单的"证件号码"提取规则，未区分投保人和被保险人。本报告分析各保司PDF中身份证号码的出现格式和上下文规律，为新增 `投保人身份证号码` 和 `被保险人身份证号码` 字段提供依据。

### 关键发现

1. **被保险人身份证号码** 在绝大多数保单中都有出现，格式较为统一
2. **投保人身份证号码** 仅在部分险种（驾意险/个意险/非车险）中出现
3. **纳税人识别号** 是另一个身份证号，通常是行驶证车主的，不应与投保人/被保险人混淆
4. 投保人和被保险人的身份证号在很多保单中是同一个人，但交强险中常出现不同（纳税人识别号 ≠ 被保险人身份证号码）

## 二、各保司身份证号码格式详细分析

### 1. 平安财险（交强险）

**被保险人身份证号码** — 在交强险页面中明确标注：

```

```

或：

```

```

**纳税人识别号** — 在交强险底部代收车船税区域，通常是行驶证车主的身份证号（可能与被保险人不同）：

```

```

**标签变体**：
- `被保险人身份证号码(组织机构代码) 身份证:XXXXXXXXXXXXXXXXXX`

## 三、投保人 vs 被保险人身份证号的区分规律

### 3.1 核心规律

| 规律 | 说明 |
|------|------|
| **被保险人身份证号码** | 几乎所有交强险/商业险保单都有，使用 `被保险人身份证号码` 或 `被保险人证件号码` 标签 |
| **投保人身份证号码** | 主要出现在驾意险/个意险/非车险中，使用 `投保人证件号码` 或 `投保人信息...证件号码` 标签 |
| **纳税人识别号** | 交强险底部必有，是行驶证车主的身份证号，与被保险人可能不同 |
| **同一页面内的区分** | 通过前面最近的"投保人"或"被保险人"标签来判断归属 |

### 3.2 交强险中被保险人身份证号码的标签变体

按出现频率排序：

1. `被保险人身份证号码(组织机构代码)` — 平安
2. `被保险人身份证号码（组织机构代码）` — 平安（全角括号）
3. `被保险人身份证号码（统一社会信用代码）` — 大家/华安/国任
4. `被保险人身份证号码(统一社会信用代码)` — 平安新版
5. `被保险人身份号码（组织机构代码）` — 太平（注意无"证"字）
6. `被保险人身份证号（组织机构代码）` — 中华联合（注意无"码"字）
7. `被保险人证件号码` — 众诚/国寿/申能
8. `被保险人证件号码` — 众诚

### 3.3 商业险中的标签变体

1. `证件号码: XXXXXXXXXXXXXXXXXX` — 平安商业险（前面有"被保 姓 名: XXX 证件类型: 身份证"）
2. `被保险人 XXX 证件号码 XXXXXXXXXXXXXXXXXX` — 国寿
3. `被保险人证件号码 XXXXXXXXXXXXXXXXXX` — 众诚
4. `名称 XXX 证件号码 XXXXXXXXXXXXXXXXXX` — 平安/国寿
5. `被保险人名称: XXX ... 被保险人证件号码: XXXXXXXXXXXXXXXXXX` — 申能

### 3.4 驾意险/个意险中投保人和被保险人的区分

**模式1 — 表格并列（平安驾意险）**：

```
1、投保人信息
投保人姓名 证件类型 证件号码
XXX 身份证 XXXXXXXXXXXXXXXXXX
2、被保险人信息
被保险人姓名 证件类型 证件号码
YYY 身份证 YYYYYYYYYYYYYYYYYY
```

**模式2 — 独立行（太平洋驾意险）**：

```
投保人名称： XXX
投保人证件类型： 身份证 投保人证件号码： XXXXXXXXXXXXXXXXXX
```

**模式3 — 前海联合/国寿驾意险**：

```
投保人 ： XXX
证件类型 ：居民身份证 证件号码 ： XXXXXXXXXXXXXXXXXX
被保险人姓名：YYY
证件类型 ：居民身份证 证件号码 ： YYYYYYYYYYYYYYYYYY
```

**模式4 — 大家/国任驾乘险**：

```
投保人信息
姓名/名称： XXX 证件类型： 身份证 证件号码： XXXXXXXXXXXXXXXXXX
被保险人信息
```

**模式5 — 阳光/亚太/华农**：

```
投保人信息
...证件类型 身份证 证件号码 XXXXXXXXXXXXXXXXXX
被保险人信息
...证件类型 身份证 证件号码 YYYYYYYYYYYYYYYYYY
```

## 四、需要排除的"伪身份证号"

以下场景中的18位数字不是投保人/被保险人的身份证号码，需要排除：

1. **纳税人识别号** — 交强险底部车船税区域的身份证号（属于行驶证车主）
2. **条款注册编号** — 如 `C00001432312022062812681`，虽然不完全符合身份证格式，但部分片段可能被匹配
3. **流水号** — 如 `83550126196311033015BD` 中包含的数字
4. **保单号** — 部分保单号包含18位数字
5. **POS参考号/支票号/确认码** 中的数字

## 五、建议的正则表达式提取规则

### 5.1 被保险人身份证号码

```python
# 规则1：交强险中的被保险人身份证号码（覆盖所有保司变体）
# 匹配：被保险人身份证号码(组织机构代码)、被保险人身份号码（组织机构代码）、
#       被保险人身份证号码（统一社会信用代码）、被保险人身份证号（组织机构代码）
m = re.search(
    r'被保险人身份[证]?号[码]?[（(](?:组织机构代码|统一社会信用代码)[)）]\s*(?:身份证[：:]?)?\s*'
    r'([1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx])',
    text
)

# 规则2：商业险/通用格式 — "被保险人 XXX 证件号码 XXXXXXXXX" 或 "被保险人证件号码 XXXXXXXXX"
# 注意：需要确保前面上下文是"被保险人"而不是"投保人"
m = re.search(
    r'被保险人[^\n]*?证件号码[：:\s]*'
    r'([1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx])',
    text
)

# 规则3：平安商业险表格格式 — "被保 姓 名: XXX 证件类型: 身份证 证件号码: XXXXXXXXX"
m = re.search(
    r'被保[险\s]*[人]?\s*姓\s*名[：:]\s*\S+\s*证件类型[：:]\s*身份证\s*证件号码[：:]\s*'
    r'([1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx])',
    text
)

# 规则4：申能格式 — "被保险人证件类型： 居民身份证 被保险人证件号码： XXXXXXXXX"
m = re.search(
    r'被保险人证件[类型]*[：:\s]*(?:居民)?身份证\s*被保险人证件号码[：:\s]*'
    r'([1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx])',
    text
)
```

m = re.search(

### 5.3 建议的合并提取函数

```python
ID_PATTERN = r'([1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])\d{3}[\dXx])'

def extract_id_numbers(text, fields):
    """提取投保人和被保险人身份证号码"""
    
    # === 被保险人身份证号码 ===
    
    # 优先级1：交强险中明确的"被保险人身份[证]?号[码]?"标签
    m = re.search(
        r'被保险人身份[证]?号[码]?[（(](?:组织机构代码|统一社会信用代码)[)）]\s*(?:身份证[：:]?)?\s*' + ID_PATTERN,
        text
    )
    if m:
        fields["被保险人身份证号码"] = m.group(1)
    
    # 优先级2：商业险中"被保险人...证件号码"
    if "被保险人身份证号码" not in fields:
        m = re.search(
            r'被保险人[名称\s]*[：:]*\s*\S+[\s\S]{0,50}?证件号码[：:\s]*' + ID_PATTERN,
            text
        )
        if m:
            fields["被保险人身份证号码"] = m.group(1)
    
    # 优先级3：平安商业险 "被保 姓 名: XXX 证件类型: 身份证 证件号码:"
    if "被保险人身份证号码" not in fields:
        m = re.search(
            r'被保[险\s]*[人]?\s*姓\s*名[：:]\s*\S+\s*证件类型[：:]\s*身份证\s*证件号码[：:]\s*' + ID_PATTERN,
            text
        )
        if m:
            fields["被保险人身份证号码"] = m.group(1)
    
    # 优先级4：众诚/申能格式 "被保险人证件号码"
    if "被保险人身份证号码" not in fields:
        m = re.search(r'被保险人证件号码[：:\s]*' + ID_PATTERN, text)
        if m:
            fields["被保险人身份证号码"] = m.group(1)
    
    # === 投保人身份证号码 ===
    
    # 优先级1：太平洋格式 "投保人证件类型：身份证 投保人证件号码："
    m = re.search(
        r'投保人证件类型[：:\s]*(?:居民)?身份证\s*投保人证件号码[：:\s]*' + ID_PATTERN,
        text
    )
    if m:
        fields["投保人身份证号码"] = m.group(1)
    
    # 优先级2：投保人信息块（太平/阳光/亚太/大家等）
    if "投保人身份证号码" not in fields:
        m = re.search(
            r'投保人(?:信息|姓名)[：:\s]*[\s\S]{0,200}?证件号码[：:\s]*' + ID_PATTERN,
            text
        )
        if m:
            fields["投保人身份证号码"] = m.group(1)
    
    # 优先级3：平安驾意险表格 "投保人姓名 证件类型 证件号码\nXXX 身份证 XXXXXXXX"
    if "投保人身份证号码" not in fields:
        m = re.search(
            r'投保人姓名\s+证件类型\s+证件号码[\s\S]{0,50}?身份证\s+' + ID_PATTERN,
            text
        )
        if m:
            fields["投保人身份证号码"] = m.group(1)
    
    # 优先级4：众安/华农格式 — "投保人\n投保人 XXX 证件类型 身份证\n证件号码 XXXXXXXXX"
    if "投保人身份证号码" not in fields:
        m = re.search(
            r'投保人[^\n]*证件类型\s*(?:居民)?身份证[\s\S]{0,30}?证件号码[：:\s]*' + ID_PATTERN,
            text
        )
        if m:
            fields["投保人身份证号码"] = m.group(1)
```

## 六、重要注意事项

### 6.1 纳税人识别号的处理

交强险中的 `纳税人识别号` 是行驶证车主的身份证号码，**不是**被保险人或投保人的。在以下场景会不同：

- 投保人≠车主时（如公司车辆个人投保）
- 行驶证车主已变更但保单未更新时

**建议**：可单独提取纳税人识别号作为参考字段，但不要混入投保人/被保险人身份证号码。

```python
# 纳税人识别号（行驶证车主）
m = re.search(r'纳税人识别号[：:\s]*' + ID_PATTERN, text)
if m:
    fields["纳税人识别号"] = m.group(1)
```

### 6.2 企业投保人

当投保人是企业时，证件号码是统一社会信用代码（18位字母数字混合），不是身份证号码。正则表达式已通过限制首位为1-9、中间包含出生日期格式来排除企业代码。
