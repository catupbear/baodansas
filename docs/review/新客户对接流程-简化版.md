# 新客户对接流程（简化版）

> 原文档：《【保险台账系统】新客户对接流程》简化整理

# 1. 初步沟通

本阶段目标：了解客户基本信息，一次性收集配置所需的全部信息。

## 1.1 拉客户服务群

群名格式：企业简称｜午虎AI台账客户服务群TZ005（编号递增）

群成员：客户 + 客服号 + 技术服务号 + 罗总

内部登记客户来源渠道

## 1.2 介绍系统

提前了解客户是通过什么渠道联系到我们的，掌握对方了解程度，后续沟通节奏可调整。不管客户是否了解系统，统一发送以下内容：

直接复制发送：

> 您好！我来简单介绍一下我们的保单台账系统：保单 PDF 发到午虎AI保单台账识别群，系统自动识别保单号、车牌、保费、险种等字段，直接导出标准台账 Excel。目前已支持 50 多家保险公司。发您几个资料方便了解：
>
> 📹 系统介绍视频：
> 🌐 官网：https://wxbot.wuhuxiche.com/
> 📖 使用手册：https://docs.wuhuxiche.com/help.pdf
>
> 现在可以免费使用2个月，稍后，我发个信息收集表给您填一下，这边就能给你开通系统账号，进行使用了。

## 1.3 发送对接信息表

直接复制发送：

> 【对接信息表】麻烦您填写后发给我就行：
>
> 1、企业全称：
> 2、联系人姓名 + 手机号：
> 3、贵公司每月大约处理多少份保单？（帮您推荐合适套餐）
> 4、常投保的保险公司是哪几家？（3-5 家即可）
> 5、需要开通系统账号的人员名单（姓名 + 手机号），并标注谁是管理员（可看全公司数据）、谁是员工（只看自己的数据）：
> 6、贵公司现有的台账 Excel 模版能否发一份给我？我照着配导出格式。没有的话用系统默认格式，后续随时可改。
> 7、保险公司名称需要简写吗？比如"中国人民财产保险股份有限公司"显示为"人保"。（需要/不需要）
> 8、险种名称需要简写吗？（需要/不需要）
> 9、导出的 Excel 需要自动计算佣金吗？如需要请告诉我计算方式，比如"商业险保费 × 30%"，不同保司不同比例也可以。（需要并附公式/不需要）
> 10、日期格式有要求吗？比如 2026/05/07 或 2026-05-07。（写具体格式/用默认的就行）
>
> 以上信息填好发给我，我就开始帮您配置了～

## 1.4 根据客户回复的③判断套餐

标准版：月费 ¥299 / 年费 ¥2999 / 3000份每月

企业版：月费 ¥999 / 年费 ¥9999 / 无限

免费试用 2 个月，功能与正式版完全相同

套餐从开通当天起算，1份 PDF = 1个计量单位

## 1.5 根据客户回复的④判断是否需要训练

对照系统已支持的保司列表（手动上传页面可查看）

识别量 > 200 → 正常，直接开通

识别量少 → 请客户提供 500-1000 份历史保单，约 3 个工作日完成训练

# 2. 系统配置（需内部超管账号操作）

## 2.1 创建企业

路径：顶部导航栏 → 服务企业管理 → + 添加企业

## 2.2 开通套餐

路径：服务企业管理 → 找到企业 → 操作栏「开通」

根据客户选择的套餐设置时间

## 2.3 建保单对接微信群

群名格式：企业简称|午虎AI保单台账识别群TZ001-1（企业编号-群序号）

群成员：
- 客户方：所有要发保单的人
- 我方：客服（你）+ 技术客服（**必须拉入**）+ 罗总

建议提前备 10 个群

## 2.4 配置群聊监控

路径：服务企业管理 → 监控配置 → 新增监控

获取群 ID：打开 https://wxbot.wuhuxiche.com/monitor（密码 wuhu2025）

在对接群里随便发一条消息 → 左侧找到群 → 点头像 → 复制 ID

回监控设置页，粘贴群 ID + 选择企业 → 绑定完成

## 2.5 开通用户账号

两种角色：
- 员工：只能看自己发的保单
- 企业管理员：可看整个企业的保单

### 方式一：内部手动创建

路径：服务企业管理 → 人员管理 → 创建用户

填写手机号/密码/企业/角色

绑定发送人 ID（在监控页面点击用户头像复制）

### 方式二：用户自注册后激活

路径：服务企业管理 → 未分组账号 → 激活 → 编辑（设企业/角色/发送人ID）

## 2.6 模板设置

路径：系统设置 → 找到企业默认模板

导出列配置：设置 Excel 表头字段和顺序，可让客户发样例模板参照

别名设置：简化保司/险种名称（如"中国人民财产保险股份有限公司" → "人保"）

佣金计算公式：按客户提供的公式自动计算（可选）

日期格式：自定义导出日期显示格式（可选）

# 3. 验收测试

让客户在对接群发 1-2 份真实保单 PDF

等待系统识别完成

登录系统查看识别结果，核对关键字段：
- 承保公司：名称正确，别名正确
- 保单号：与 PDF 一致
- 车牌号：正确提取
- 险种：商业险/交强险区分
- 保费：金额正确
- 投保人/被保人：正确提取

导出 Excel，检查字段顺序/别名/佣金/日期

发给客户确认：OK → 正式使用；需调整 → 修改模板后重新测试

# 4. 售后跟进

## 4.1 第 1 周（每天）

查识别记录，主动告知成功率

## 4.2 第 2 周（隔天）

主动问使用情况

## 4.3 之后（每周一）

查上周数据，关注新保司识别效果

## 4.4 异常处理标准

失败率 < 10% → 正常，继续观察

失败率 10%-30% → 联系技术排查

失败率 > 30% → 升级处理，可能需要专项训练
