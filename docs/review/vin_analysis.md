```python

]:
```

## 三、未匹配的失败模式详解

### 模式A：识别代码(车架号) + 水印数字粘连（22个文件）

**保司**：人保（PICC）交强险等带水印的保单

**现象**：PDF含有动态水印，pdfplumber提取文本时水印中的数字粘连到标签和VIN之间。

```
原始PDF文本提取结果：
识别代码（车架号）0 LGBL4AE09KD009848 0
                  ^                    ^
              水印数字              水印数字
```

**失败原因**：当前规则 `识别代码\s*（车架号）\s*([A-Z0-9]{17})` 要求标签后紧跟VIN，但中间夹了水印数字 `0`。

**受影响文件示例**：
- `贺委奇 粤B08A6F  交强险.pdf`

---

### 模式B：识别代码(车架号) + VIN首字母与后续被空格分隔（16个文件）

**保司**：太平洋交强险

**现象**：VIN的第一个字符（如 `W`）紧跟在 `)` 后面，但与后续16位之间有空格。

```
原始PDF文本提取结果：
识别代码(车架号)W DDUG6FB5EA030790
               ^
           VIN首字母紧跟括号，但后续有空格
实际VIN：WDDUG6FB5EA030790
```

**失败原因**：当前规则匹配的是连续17位 `[A-Z0-9]{17}`，但实际提取文本中VIN被空格断开为 `W` + `DDUG6FB5EA030790`。

**受影响文件示例**：
- `粤B5WT83+机动车交通事故责任强制保险（保单）.pdf`

---

### 模式C：VIN出现在"识别代码（车架号）"标签的上方（16个文件）

**保司**：太平洋交强险（表格式PDF布局）

**现象**：PDF表格中，发动机号码和VIN在上一行，标签在下一行。pdfplumber按行提取后，VIN和标签分属不同行。

```
原始PDF文本提取结果：
9023030 LFMA180C3G0011057          <- VIN在这一行
发动机号码 识别代码（车架号）        <- 标签在下一行
```

**失败原因**：所有当前规则都假设VIN在标签之后，但此格式中VIN在标签之前。

**受影响文件示例**：
- `粤B7A80D_交强_20590A44030226000BW1_1.pdf`
- `粤B71L36_交强_20590A44030226000C55.pdf`

---

### 模式D：车架号/VIN号（15个文件）

**保司**：浙商财产保险（驾意险）

**现象**：标签使用了 `车架号/VIN号` 格式。

```
核定载客/载客量 5 车架号/VIN号 HLX32B14XS1062081
```

**失败原因**：当前规则 `VIN码?/?车架号` 匹配的是 `VIN码/车架号` 或 `VIN/车架号` 的顺序，不匹配 `车架号/VIN号`。

**受影响文件示例**：
- `P00374C0422026001848942  粤BFM0577  驾意险.pdf`
- `粤BAL8200_深圳市明球实业有限公司_驾意险.pdf`

---

### 模式E：车架号/VIN码：（6个文件）

**保司**：鼎和财险（驾意险）

**现象**：标签使用了 `车架号/VIN码：` 格式。

```
号码号牌： 粤BCV0021 车架号/VIN码： LGXCE4CC8P0409193
```

**失败原因**：当前规则 `VIN码?/?车架号` 只匹配 `VIN码/车架号` 而非反转的 `车架号/VIN码`。规则2 `车架号[：:\s]*` 本应匹配，但 `车架号` 后紧跟 `/VIN码：` 而非直接跟VIN。

**受影响文件示例**：
- `粤BCV0021+驾乘人员意外伤害保险（保单）.pdf`
- `粤BF23857+驾乘人员意外伤害保险（保单）.pdf`

---

### 模式F：驾意险表格中车架号与VIN被多行分隔（2个文件）

**保司**：安诚财险（驾意险）

**现象**：驾意险表格使用特殊排版，"车架号"是列标题，VIN在同列的下方行中，且VIN前有水印数字粘连。

```
序号 车牌2号码 车辆种类 使用性质 核定载客人数 2车架号 发动机号 2
...多行数据...
徐海波 时 2粤B08A6F 非营业 5 时 2LGBL4AE09KD009848 488202Y 时 2
                                  ^
                              VIN前有水印数字"2"
```

**失败原因**：车架号标签和VIN值不在同一行，且中间隔了多行表格数据。即使在同行，VIN前有水印数字粘连（如 `2LGBL4AE09KD009848`）。

**受影响文件示例**：
- `贺委奇 粤B08A6F  驾意险.pdf`
- `江梓健 粤B81QE7  驾意险.pdf`

---

### 模式G：车架号/VIN码（无冒号）（全量扫描新增发现）

**保司**：大地保险等

**现象**：标签使用 `车架号/VIN码` 但后面无冒号，直接跟VIN。

```
险 车架号/VIN码 LHGRC4840M8024776 行驶证车主 郑廷钦
```

**失败原因**：当前规则 `车架号[：:\s]*` 匹配时，`车架号` 后面紧跟 `/VIN码` 导致不匹配。

---

### 模式H：车架号/VIN（无"码"/"号"后缀）

**保司**：阳光保险等新能源车险

**现象**：标签使用 `车架号/VIN` 格式，VIN后面不带"码"或"号"。

```
保险 车架号/VIN 发动机/电动机号 核定载质量
车辆
情况 使用性质 车辆种类 初登日期
```

**失败原因**：此格式中VIN标签后面紧跟的是另一个列标题"发动机/电动机号"，而非实际的VIN值。VIN值在后续行中，与标签分离。这属于表格列标题与数据行分离的情况。

---

### 模式I：车架号或发动机号（非车险保单）

**保司**：前海人寿等非车险

**现象**：非车险保单中使用 `车架号或发动机号` 标签。

```
车辆所有人 车牌号码 车架号或发动机号 车辆使用性质 车辆类型
刘础行 粤B7A80D LFMA180C3G0011057 家庭自用 5
```

**失败原因**：标签 `车架号或发动机号` 不匹配当前任何规则。VIN在下一行数据中。

---

### 模式J：车架号码（无"/"分隔）

**保司**：中银保险等

**现象**：标签使用 `车架号码` 而非 `车架号`。

```
车架号码 LBV31DU00NS390635
```

**失败原因**：当前规则 `车架号[：:\s]*` 可以匹配 `车架号码`（因为"码"会被当作VIN的一部分），但实际上 `车架号码` 后面跟的VIN只有16位可见（因为"码"被吃掉了一位）。需要单独处理。

---

### 模式K：识 别 代码(车架号)（标签文字有空格）

**保司**：人保部分交强险

**现象**：pdfplumber提取时标签文字间有空格。

```
识 别 代码(车架号) LNADHAB18P1100090
```

**失败原因**：当前规则使用 `识别代码` 作为完整匹配，无法匹配 `识 别 代码`。

---

### 模式L：识别代码(车架号 + 噪声字符) + VIN

**保司**：人保部分交强险

**现象**：括号内的"车架号"后面混入了噪声字符。

```
识别代码(车架号 L ) LJ11R9DE4H3504402 I
```

**失败原因**：当前规则要求精确匹配 `(车架号)` 或 `（车架号）`，但实际括号内有额外字符。

---

### 模式M：VIN码/车架号后面被空格断开

**保司**：太平洋等商业险

**现象**：标签后VIN被空格断成两段。

```
VIN码/车架 LDC943X20C1342871
```

注意标签本身也被截断（`车架` 而非 `车架号`）。

---

### 模式N：驾意险表格中车架号列标题 + 数据行分离（含英文双标题）

**保司**：众安保险等

**现象**：表格有中英文双标题行，VIN在下方数据行。

```
序号 车牌号 车架号 发动机号 核定座位数 份数 保费(RMB)
Serial Car No VIN Engine No SeatNum PHR Premium
1 粤BAM9439 ...
```

---

### 模式O：众安保单文本中VIN在正文段落中

**保司**：众安保险

**现象**：车架号出现在保单正文描述中，非结构化。

```
保单中载明车辆（车牌号：粤AB00R2，车架号：LDCP11U44K4011914，发动机号0001602...
```

注意：VIN `LDCP11U44K4011914` 是18位而非17位，后面的 `4` 可能是逗号前的粘连字符。

## 五、建议补充的正则表达式

### 5.1 直接新增规则（在现有for循环列表中追加，可修复约21个文件）

```python
# 车架号/VIN
for p in [
    r"VIN码?/?车架号[：:\s]*([A-Z0-9]{17})",
    r"车架号[：:\s]*([A-Z0-9]{17})",
    r"VIN[：:\s]*([A-Z0-9]{17})",
    r"车辆识别代[号码][：:\s]*([A-Z0-9]{17})",
    r"识别代码\s*(?:\(车架号\)|（车架号）)\s*([A-Z0-9]{17})",
    r"识别代码[：:\s]*([A-Z0-9]{17})",
    # === 新增规则 ===
    # 模式D：车架号/VIN号（浙商财险驾意险，15个文件）
    r"车架号/VIN号[码]?\s*([A-Z0-9]{17})",
    # 模式E/G：车架号/VIN码（鼎和/大地财险，含或不含冒号，6+个文件）
    r"车架号/VIN码[：:\s]*([A-Z0-9]{17})",
    # 模式J：车架号码（中银保险等）
    r"车架号码[：:\s]*([A-Z0-9]{17})",
    # 模式K：识 别 代码(车架号)（标签文字有空格）
    r"识\s*别\s*代码\s*[（\(]车架号[）\)]\s*([A-Z0-9]{17})",
    # 模式I：车架号或发动机号（非车险表格，VIN在下一行）
    r"车架号或发动机号[：:\s]*([A-Z0-9]{17})",
    # 模式O：车架号：VIN（正文段落中，众安保单）
    r"车架号[：:]\s*([A-Z0-9]{17})",
]:
```

### 5.2 兜底逻辑（在for循环后追加，可修复约57个文件）

```python
# 兜底1：识别代码(车架号) + 水印数字或噪声字符干扰（22个文件）
if "车架号VIN" not in fields:
    m = re.search(
        r"识别代码[（\(]车架号[）\s\w]*[）\)]\s*\d?\s*([A-HJ-NPR-Z][A-Z0-9]{16})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)

# 兜底2：识别代码(车架号) + VIN首字母与后续被空格分开（16个文件）
if "车架号VIN" not in fields:
    m = re.search(
        r"识别代码[（\(]车架号[）\)]([A-Z])\s+([A-Z0-9]{16})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1) + m.group(2)

# 兜底3：VIN在"识别代码(车架号)"标签的上一行（16个文件）
if "车架号VIN" not in fields:
    m = re.search(
        r"([A-HJ-NPR-Z][A-Z0-9]{16})\n发动机号码\s+识别代码[（\(]车架号[）\)]",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)

# 兜底4：VIN码/车架号但标签被截断（如"VIN码/车架"）
if "车架号VIN" not in fields:
    m = re.search(
        r"VIN码?/?车架\s+([A-Z0-9]{17})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)

# 兜底5：车架号或发动机号 + 表格下一行数据
if "车架号VIN" not in fields:
    m = re.search(
        r"车架号或发动机号.*?\n.*?([A-HJ-NPR-Z][A-Z0-9]{16})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)

# 兜底6：驾意险表格 - 车架号列标题 + 数据行中VIN前有水印数字
if "车架号VIN" not in fields:
    m = re.search(
        r"车架号\s+发动机号.*?\n(?:.*?\n){0,3}.*?\d([A-HJ-NPR-Z][A-Z0-9]{16})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)

# 兜底7：众安驾意险表格 - 中英双标题 + 数据行
if "车架号VIN" not in fields:
    m = re.search(
        r"车架号.*?VIN.*?\n.*?\n.*?([A-HJ-NPR-Z][A-Z0-9]{16})",
        text
    )
    if m:
        fields["车架号VIN"] = m.group(1)
```

### 5.4 预期效果

- 当前匹配率：92.8%（1854/1998）
- 新增规则后预期匹配率：约96.7%（1854+78=1932/1998）
- 剩余41个仍无法匹配的文件大多属于：
  - 保单中VIN在表格数据行（需跨行解析）
  - PDF提取质量差（水印严重干扰）
  - 保单格式极特殊（如阳光新能源车险表格布局）

## 六、注意事项

1. **VIN标准格式**：17位大写字母+数字，不包含 I、O、Q 三个字母（防止与1、0混淆）。当前规则使用 `[A-Z0-9]{17}` 过于宽泛，理论上应使用 `[A-HJ-NPR-Z0-9]{17}`，但考虑OCR可能识别错误，保持现有宽泛匹配更安全。

2. **水印干扰**：安诚财险的驾意险PDF含有动态时间戳水印（秒/分/时/日/月/年），pdfplumber提取时水印文字会混入正文，导致标签和数据之间出现无关字符。此类问题难以完全通过正则解决，后续可考虑在pdfplumber提取前进行水印过滤。

3. **表格布局差异**：部分保司（特别是太平洋）使用表格布局，pdfplumber提取时列的顺序可能与视觉不同，导致VIN出现在标签的上方而非下方。兜底规则C可处理此问题。

4. **驾意险特殊性**：驾意险保单中车架号格式最不统一，使用了 `车架号/VIN号`、`车架号/VIN码：`、表格列标题等多种变体，是规则遗漏的重灾区。

5. **VIN码/车架号 被截断**：太平洋商业险中发现 `VIN码/车架` 后面直接跟VIN值（`车架号` 的 `号` 字被pdfplumber截断到下一列）。

6. **仍无法匹配的41个文件**中，主要分布在以下类型：
   - 安诚驾意险（水印+表格分离）：约15个
   - 众安驾意险（表格分离）：约8个
   - 前海人寿非车险（跨行表格）：约6个
   - 阳光新能源车险（列标题分离）：约4个
   - 其他特殊格式：约8个
