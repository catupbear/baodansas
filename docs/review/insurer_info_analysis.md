## 一、当前提取逻辑概述

`_extract_insurer_info` 函数（policy_parser.py 第706-857行）使用5种模式：

1. **签单公司信息** — `签单公司信息\s+公司名`
2. **公司名称标签** — `公司名称[：:]\s*公司名`
3. **紫金跨行格式** — 公司名在"公司名称："标签上方，残余在下方
4. **公司地址标签** — `公司地址[：:]\s*地址`
5. **紫金跨行地址** — 地址在"公司地址："标签上下方拼接

## 三、汇总：需要新增的提取模式

| 序号 | 新增模式 | 适用保司 | 影响文件数 | 优先级 |
|------|---------|---------|-----------|--------|
| 1 | `签单公司[：:]` + 公司名 | 申能驾意险、平安小微 | 高 | P0 |
| 2 | `签单公司地址[：:]` + 地址 | 申能驾意险、平安小微 | 高 | P0 |
| 3 | `保险人地址[：:]` + 地址 | 前海联合驾乘、华农 | 中 | P1 |
| 4 | `授权签单机构[：:]` + 公司名 | 前海联合驾乘 | 低 | P1 |
| 5 | `承保机构[：:]` + 公司名（跨行） | 安诚驾意 | 低 | P1 |
| 6 | `业务归属机构[：:]` + 分公司名 | 太平意外 | 低 | P2 |
| 7 | `鉴于投保人向XXX公司` | 平安小微 | 中 | P1 |
| 8 | `签\s*单\s*公\s*司[：:]`（字间空格） | 平安小微 | 中 | P1 |
| 9 | 释义中 `保险人：指...的XXX公司` | 华泰驾意、太平意外（兜底） | 低 | P2 |
| 10 | `签单公司信息：` + 非公司名（部门名） → 需从条款提取 | 阳光驾乘 | 低 | P2 |

## 四、建议的代码修改方案

在 `_extract_insurer_info` 函数中，建议在现有5种模式之后，依次添加以下补充模式：

### 补充模式A：签单公司标签（P0）

```python
# 申能驾意险、平安小微等：签单公司：XXX公司
if "保司公司名称" not in fields:
    for src in [text, text_merged]:
        m = re.search(r'签\s*单\s*公\s*司[：:]\s*([一-鿿（()）\w]+公司)', src)
        if m:
            val = m.group(1).strip()
            if val and len(val) >= 4 and re.search(r'保险', val):
                fields["保司公司名称"] = val
                break
```

### 补充模式B：签单公司地址标签（P0）

```python
# 签单公司地址：XXX
if "保司地址" not in fields:
    for src in [text, text_merged]:
        m = re.search(r'签单公司地址[：:]\s*(.+?)(?:\s{2,}|\n|$)', src)
        if m:
            val = m.group(1).strip()
            if val and len(val) >= 4:
                fields["保司地址"] = val
                break
```

### 补充模式C：保险人地址标签（P1）

```python
# 华农、前海联合驾乘等：保险人地址：XXX
if "保司地址" not in fields:
    for src in [text, text_merged]:
        m = re.search(r'保险人地址[：:]\s*(.+?)(?:\s+（保险人|\s{2,}|\n|$)', src)
        if m:
            val = m.group(1).strip()
            if val and len(val) >= 4:

```

### 补充模式D：授权签单机构 / 承保机构（P1）

```python
# 前海联合驾乘：授权签单机构：XXX公司
# 安诚驾意：承保机构：XXX公司（可能跨行）
if "保司公司名称" not in fields:
    for src in [text, text_merged]:
        m = re.search(r'(?:授权签单机构|承保机构)[：:]\s*([一-鿿（()）\w\s]+?公司)', src)
        if m:
            val = re.sub(r'\s+', '', m.group(1).strip())  # 去除OCR空格
            if val and len(val) >= 4 and re.search(r'保险', val):
                fields["保司公司名称"] = val
                break
```

### 补充模式E：鉴于投保人向XXX公司（P1）

# 平安小微：鉴于投保人向中国平安财产保险股份有限公司 深圳 分公司

## 五、特别标注

### 无法提取的场景（需人工处理或从其他来源获取）

1. **平安个意险/驾意险**：保单中完全没有分公司名称和地址，只有条款中的总公司名。需要：
   - 从文件名推断
   - 或通过保单号前缀规则推断分公司
   - 或在数据库中维护保单号 → 分公司的映射表

2. **华泰驾意险**：同上，只有总公司名"华泰财产保险有限公司"，没有分公司名和地址。

3. **人保驾乘险**：保单中只有"出单机构"（如"修理厂业务二部"），没有标准的公司名称和地址。
