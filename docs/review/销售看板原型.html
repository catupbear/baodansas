总体设计

前端请求
/dashboard/data→ 解析配置
enterprise → global 兜底→ 查询台账记录
时间范围 + 本企业 + 已完成→ 应用字段配置
费率公式 / 手动值（复用现有引擎）→ 内存聚合
cards / charts / ranking / targets→ 返回结果
含 explain 说明文案
· 选择后端内存聚合而非 SQL 聚合：台账字段存于 display_fields JSON 列，且提成等公式字段在应用层计算，SQL 无法下推；单企业数据量（数千条/年）内存聚合为毫秒级
· 权限：仅 enterprise（本企业）与 super_admin（可带 enterprise_id 切换企业）；employee 返回 403，前端不显示入口
· 前端：不新建页面，在 insurance.html 顶部页面级 Tab 新增「销售看板」，内部二级 Tab：看板 / 看板配置 / 目标管理

数据库表（首次启动自动建表）

表用途
dashboard_config看板配置。scope=global 为超管维护的系统默认模板；scope=enterprise 为企业自定义（微调后生成，可删除恢复默认）。唯一键 (scope, scope_id)
dashboard_targets业绩目标。企业整体 / 条件目标 / 员工目标共用一张表，按 target_type 区分。唯一键 (enterprise_id, target_type, name, employee_name)
 
-- 看板配置
CREATE TABLE dashboard_config (
    id INT AUTO_INCREMENT PRIMARY KEY,
    scope VARCHAR(16) NOT NULL,          -- global=系统默认模板 / enterprise=企业自定义
    scope_id INT DEFAULT NULL,           -- enterprise 时为企业ID
    config_json LONGTEXT,                -- 看板配置JSON（cards/charts/ranking，结构见下）
    enabled TINYINT DEFAULT 1,           -- 超管可按企业开关看板
    updated_by INT DEFAULT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_scope (scope, scope_id)
);

-- 业绩目标（企业/条件/员工目标共用）
CREATE TABLE dashboard_targets (
    id INT AUTO_INCREMENT PRIMARY KEY,
    enterprise_id INT NOT NULL,
    target_type VARCHAR(16) NOT NULL,    -- enterprise=企业整体 / condition=条件目标 / employee=员工目标
    name VARCHAR(64) NOT NULL,           -- 目标名称；员工目标中同名记录=同一目标项
    metric_agg VARCHAR(8) DEFAULT 'sum', -- sum/count
    metric_field VARCHAR(64) DEFAULT '保费',
    filters_json TEXT,                   -- 筛选条件（条件目标/员工目标均可带）
    employee_name VARCHAR(64) DEFAULT NULL, -- 员工目标：NULL=全员统一值，有值=按人覆盖
    period_type VARCHAR(16) NOT NULL,    -- month/quarter/year=滚动周期 / custom=固定区间
    period_start DATE DEFAULT NULL, period_end DATE DEFAULT NULL,
    target_value DECIMAL(14,2) NOT NULL,
    enabled TINYINT DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    KEY idx_ent (enterprise_id, target_type),
    UNIQUE KEY uk_target (enterprise_id, target_type, name, employee_name)
);

API 设计（挂 insurance Blueprint，复用现有 JWT 鉴权）

接口方法权限说明
/api/insurance/dashboard/dataGETenterprise / super_admin返回聚合结果。参数 date_start date_end；超管可带 enterprise_id。每个指标/目标/排行列附 explain（统计字段、聚合、条件、范围、公式来源），供前端「?」悬停展示
/api/insurance/dashboard/configGET / PUTenterprise（本企业）
super_admin（任意企业+global）		读取/保存看板配置。GET 返回 {config, source: "enterprise"|"global"}；企业 PUT 写 enterprise scope；reset=1 删除企业自定义恢复默认模板；超管可维护 global 模板与按企业 enabled 开关
/api/insurance/dashboard/targetsGET / POST / PUT / DELETEenterprise / super_admin目标增删改查。员工目标「全员统一」写 employee_name=NULL 记录，「单独设置」按人写记录（同目标项内个人值优先）
/api/insurance/dashboard/fieldsGET同上可选统计字段（数字类）与维度字段列表，来源于现有字段配置（含公式字段）
/api/insurance/dashboard/salesmenGET同上本企业台账「业务员」字段去重名单（员工目标设置下拉用）
聚合与完成率规则
· 统计范围：本企业 status='done' 且未删除的记录；时间按配置的 time_field（默认签单日期）过滤，金额文本复用现有数字清洗逻辑
· 滚动周期：month/quarter/year 目标始终按「当前自然月/季/年」计算实际值，自动跨期重新起算；custom 为固定区间一次性目标
· 完成率 = 周期内按目标条件聚合的实际值 ÷ 目标值；员工目标按「业务员」字段匹配到人
